# 05. 화면별 시연 시나리오

**작성 근거:** UI·입력·씬 전환 소스. 이번 작업에서 화면을 직접 조작하거나 시연 성공을 확인하지 않았습니다. 클릭 위치는 해상도에 따라 바뀌므로 버튼 이름과 화면 내 상대 위치로 안내합니다. 최종 시연 담당자가 아래 기대 결과를 실제로 확인하고 체크합니다.

## 준비

- Windows PC 2대, 같은 게임 버전·같은 백엔드 환경, 키보드/마우스. AI 시연 시 호스트 마이크 준비.
- 두 PC의 닉네임은 `탐사대A`, `탐사대B`처럼 구분. 최대 12자.
- 발표 전 게임/AI 파일을 설치해 대용량 다운로드 대기를 줄임. 첫 설치 과정은 별도 설명.
- 운영 중 재배포·릴레이 재시작·최소 버전 변경을 하지 않음.
- 기본 키를 변경했다면 설정에서 실제 키를 확인. 아래는 기본 매핑.

## A. 웹·런처·메인 화면

| 순서 | 화면·클릭 위치 / 행동 | 기대 결과 |
| --- | --- | --- |
| 1 | 브라우저에서 서비스의 `/play/` 접속 | 소개, 트레일러, 갤러리 미디어 정상 표시 |
| 2 | 페이지의 다운로드 버튼 클릭 | `NotThisPlanetLauncher.exe` 수신. HTML 오류 페이지가 다운로드되지 않음 |
| 3 | 쓸 수 있는 전용 폴더에 런처를 두고 실행 | 게임 manifest 확인 → 파일 다운로드/검증 → 게임 시작 |
| 4 | 게임 타이틀 좌측 메뉴 확인 | `혼자 하기`, `함께 하기`, `설정`, `우주선 연습실`, `랭킹`, `종료하기` 표시 |
| 5 | `설정` 클릭, 음량/그래픽/입력 확인 후 저장 | 설정 적용, 메뉴 복귀 후 입력 가능 |

런처와 게임 버전은 별도입니다. 다운로드에 실패하면 네트워크·권한·manifest 해시 오류를 확인하고, `game/` 폴더 일부만 다른 버전으로 수동 덮어쓰지 않습니다. 사이트가 받게 하는 파일의 크기와 게임 전체 설치 용량도 구분해 설명합니다.

## B. 혼자 하기·외형·연습실

| 순서 | 행동 | 기대 결과 |
| --- | --- | --- |
| 1 | 타이틀 `우주선 연습실` 클릭 | PracticeLobby 진입, 이동/점프/도구 조작 연습 |
| 2 | Esc 메뉴에서 로비 복귀 항목 선택 | 타이틀로 돌아오고 커서 조작 가능 |
| 3 | `혼자 하기` 클릭 | 캐릭터 커스터마이저 진입 |
| 4 | 외형·색을 선택하고 하단 `저장하고 탐사 시작` 클릭 | 선택 외형 저장, 1장 진입 흐름 시작 |
| 5 | 게임 화면에서 WASD/마우스/Space 확인 | 이동·시점·점프 정상. Tab을 눌러 태블릿 안내 확인 |

소스 근거: `LobbyHud.DrawMainMenu`, `CustomizerBootstrap`, `LobbyTransition.BeginSolo/BeginPractice`. 연습실과 게임 시작은 서로 다른 진입입니다.

## C. 2인 협동 입장

| 순서 | 조작자 | 화면·행동 | 기대 결과 |
| --- | --- | --- | --- |
| 1 | A/B | 타이틀 `함께 하기` → 외형 선택 → 하단 `저장하고 팀 합류하기` | 멀티플레이 UI 진입 |
| 2 | A/B | 닉네임 입력란에 각각 다른 이름 → 그 아래 `게스트 로그인` | 로그인 후 서버 연결, 방 생성/입장 화면 |
| 3 | A | 패널의 `새 방 만들기` 클릭 | 방 코드, 방장 표시, 명단 표시 |
| 4 | A | 방 코드 오른쪽 `복사` 클릭 후 B에게 전달 | 코드 복사 안내 |
| 5 | B | `방 코드로 입장` 입력란에 코드 입력 → `방 입장` 클릭 | A와 B가 같은 명단/방 코드를 봄 |
| 6 | A/B | 명단 아래 `준비` 클릭 | 각자의 준비 상태 반영. 다시 누르면 `준비 취소` |
| 7 | A | 모두 준비되면 오른쪽 `게임 시작` 클릭 | 두 PC가 같은 게임/컷신 흐름에 진입 |
| 8 | A/B | 서로 이동·점프·파츠 조작을 관찰 | 상대 위치/운반/상태가 두 화면에서 일치 |

참가자에게 방장 동작을 요구하지 않습니다. 로그인 성공만으로 WSS나 UDP 성공을 판단하지 않습니다. 방에는 들어가지만 게임에 못 들어가면 `RELAY_PUBLIC_ADDRESS`, UDP 17778, 릴레이 제어 접근, 같은 버전/환경인지부터 점검합니다.

## D. 1장 Astra: 탐색·운반·용접·탈출

| 순서 | 행동 | 설명/기대 결과 |
| --- | --- | --- |
| 1 | 진입 연출 후 Tab으로 태블릿 열기 | 최초 안내를 넘겨 조립/진행 상태 확인. 좌우 화살표 또는 A/D로 페이지 이동 |
| 2 | 맵의 안내 빛/진행 표시에 따라 파츠 위치로 이동 | 파츠 발견 상태가 바뀌며 협동 인원이 같은 목표를 봄 |
| 3 | 파츠 고정 해제 후 마우스 좌/우 버튼으로 잡기·운반 | 잡은 손/물체 상태, 다른 플레이어 화면의 위치 일치 |
| 4 | 작업 구역으로 이동해 필요한 부위 배치, 용접 도구 장착 후 접합부에 주 기능 사용 | 용접 진행과 태블릿 조립 상태가 반영됨. 구체 조작은 화면 도구 안내를 따름 |
| 5 | 동료가 운반·용접하는 동안 다른 인원이 운석 방어 시연 | 도구별 조작 안내·방어 피드백 확인 |
| 6 | 동료가 기절한 상황에서 접근 후 G 유지 | 구조 진행과 회복이 양쪽에 반영됨. 운반과 구조 입력 구분 |
| 7 | 요구 파츠 조립과 게임이 표시하는 출발 조건 완료 | 1장 종료 연출 진입 |
| 8 | 종료 연출 완료까지 기다림 | 호스트가 2장 전환을 진행하고 참가자도 Stage2_Earth로 이동 |

진행 중 Esc는 로컬 메뉴입니다. 네트워크 게임이 전체 일시정지된다고 설명하지 않습니다. Tab, 도구 사용, 구조, 메뉴를 번갈아 사용할 때 이전 입력이 남지 않는지도 봅니다.

## E. 2장 Earth: 크레인·체결·제독

근거: `Stage2Hud.DrawGuide`와 2장 전환 코드. Tab의 작업 태블릿을 열어 현재 목표와 조작 안내를 함께 보여줍니다.

1. 준비 구역에서 상부 뚜껑을 열고 큰 인양 고리에 훅을 연결합니다.
2. 승강기로 조종석에 올라 회전·반경·높이를 조작합니다. 참가자는 접합면 근처에서 정렬을 확인합니다.
3. 사다리를 평평한 바닥에 설치하여 다음 접합 높이에 접근합니다. 다른 플레이어가 사용 중일 때 이동시키지 않습니다.
4. 렌치를 장착하고 볼트를 조준한 뒤 **좌클릭 유지 + 마우스 원형 이동**으로 3곳을 체결합니다.
5. 와이어를 내리고 큰 고리를 향해 E로 연결을 해제합니다. 태블릿 체결 상태가 두 PC에서 일치하는지 봅니다.
6. 첫 체결 후 오염 상황을 시연합니다. 분사기 좌클릭으로 동료를 제독하고 기절한 동료는 제독 후 G로 구조합니다. 솔로는 파란 고정 샤워를 사용합니다.
7. 유실된 파츠는 준비 구역의 복구 패널을 사용합니다. 복구 후 양쪽 화면에서 중복/누락이 없는지 확인합니다.
8. 모든 체결 완료, 훅 분리, 크레인 후퇴 후 발사대에 모여 출발합니다. 완료 연출과 로비 복귀를 확인합니다.

## F. 선택 시연: AI 동료

1. A가 방장인 대기실에서 명단 아래 `AI 동료 추가`를 누릅니다. 인원 합계는 최대 4자리입니다.
2. 설치가 필요하면 안내 팝업에서 설치를 진행합니다. manifest/ZIP 다운로드·검증·실행기 준비가 완료될 때까지 상태를 확인합니다.
3. 설치 중 뒤에 있는 게임 시작/방 나가기 버튼이 눌리지 않는지 확인합니다. 취소·재시도도 한 번씩 확인합니다.
4. 게임 진입 후 AI가 있는 자리 번호 **1~4**를 눌러 대상을 고르고 **V를 누른 채** “나 따라와”처럼 허용된 명령을 말합니다.
5. 인식/행동 결과와 실제 AI 이동을 보여줍니다. 마이크가 없는 PC나 다른 프로세스가 포트를 차지한 경우 오류 안내 후 사람만 플레이가 가능한지 확인합니다.
6. 게임을 종료하고 전용 실행기가 정리되는지 확인합니다. 일반 사용자의 다른 Ollama 작업을 종료하지 않습니다.

AI는 설치 완료만으로 행동까지 검증된 것이 아닙니다. 호스트 실행 상태, 명령 전달, 실제 행동과 참가자 화면을 함께 확인합니다.

## 기본 조작 요약

| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 / Space / Shift | 이동 / 시점 / 점프 / 달리기 |
| 좌·우 마우스 | 손 잡기 또는 현재 장비의 주·보조 기능 |
| Q / E | 장비 놓기·충전 투척 / 상호작용·탑승·하차 등 현재 대상 안내 |
| Tab / ←·→(A·D) | 태블릿 / 이전·다음 페이지 |
| G 유지 | 동료 구조 |
| Z / Alt / Ctrl | 엎드리기 / 자유 시점 / 팔 올리기 |
| F / T 유지 | 저중력장 / 끼임 탈출(현재 상태의 게임 안내 확인) |
| Esc | 메뉴·커서 조작 |
| 1~4 / V 유지 | AI 자리 선택 / 음성 명령 |
