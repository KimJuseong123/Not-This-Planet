## 바로 시작하기

1. `01`의 도구와 Git LFS 준비를 마치고 **Unity 6000.5.4f1**로 `METAGAME/`을 엽니다.
2. 게임만 확인하려면 개발 빌드를 만들고 `혼자 하기`를 실행합니다.
3. 멀티플레이를 인수하려면 MySQL → 백엔드 → 릴레이 → nginx/TLS 순으로 구성합니다.
4. 런처·웹사이트·AI 추가팩은 별도 산출물입니다. Git 클론만으로 운영 다운로드 파일까지 복원되지 않습니다.
5. `04`에 따라 실제 DB를 백업하고 별도 DB에서 복원 검증합니다.
6. `05`의 2인 시연 및 회귀 점검표를 완료한 뒤 운영 전환합니다.

## 완료 조건

- [ ] 운영·개발 비밀값을 별도 보안 경로로 인계하고 두 환경의 JWT/DB 비밀이 서로 다른지 확인
- [ ] 최신 운영 덤프, 생성 시각, SHA-256, 테이블 행 수, 복원 결과를 `db/`에 반영
- [ ] 서버의 실제 OS/nginx/Docker/MySQL 패치 버전과 IDE 버전 기록
- [ ] `/play/`, `/builds/`, `/ai-packs/`, `/dev/`, WSS, UDP 릴레이 검증
- [ ] Unity 빌드, 백엔드 테스트, 2인 게임, AI 선택 기능의 최종 검증

**제한:** 운영 서버 접속·배포·DB 추출과 화면 직접 조작은 수행하지 않았습니다. 확인하지 않은 동작을 성공으로 표기하지 않았습니다. 인계 자료는 `exec/`에 모았으며, 실행 도구·설정이 리뷰를 받도록 `.gitlab-ci.yml`의 AI 리뷰 경로도 보완했습니다. 게임·백엔드의 동작은 변경하지 않습니다.
