# 최신 DB 덤프 인계 자리

상태: **미제공 / 운영 DB 추출·복원 검증 미실시** (2026-09-28)

저장소에서는 `.sql`, `.sql.gz`, `.dump` 최신 백업을 찾지 못했습니다. 운영 접근 정보 없이 예시 데이터를 최신 덤프로 만들지 않았습니다.

운영 담당자가 [백업·복원 절차](../04-database.md)를 수행하여 이 폴더에 아래를 추가합니다.

1. `metagame-<UTC시각>.sql.gz`
2. 같은 파일명의 `.sha256`
3. 아래 기록을 작성한 `backup-metadata.md`

```text
환경: prod 또는 dev
백업 생성 UTC:
원본 서버 / DB:
MySQL 버전:
배포 버전 / 커밋:
파일명 / 바이트 / SHA-256:
users 행 수:
run_records 행 수:
복원 대상(운영과 분리):
복원 검증 UTC / 담당자:
스키마·행 수 대조 결과:
로그인·랭킹 검증 결과:
```

운영 데이터의 제출/저장 허용 범위를 확인한 뒤 지정된 인수 경로로 전달합니다. 인수용 데이터가 익명화되었다면 그 사실과 원본 생성 시각을 기록합니다. SQL 파일이 있다는 것만으로 정상 복원을 확인한 것으로 처리하지 않습니다.
