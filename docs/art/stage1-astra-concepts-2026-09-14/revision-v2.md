# 중앙 조립대까지의 수동 운반 보완

내장 image_gen으로 기존 컨셉 3장을 수정. A 자유 접근과 D 협동 굴리기 상세 아트는 유지한다.

## 설계 의도

- B: 돌부리 점프로 정상 도착 → 정상에서만 초기 잠금 해제 → 파츠를 화물대에 밀어 싣기 → 탑승자가 수동 브레이크로 중력 하강 제어 → 지면과 높이가 같은 하역장 → 평탄한 길 → 중앙 조립대.
- 화물대는 레일 안내식이며 견인 장치가 아니다. 자기 잠금 브레이크, 고정 쐐기, 접이식 연결판은 신규 제안이다. 혼자 정지·하역을 번갈아 수행하거나 여러 명이 나눠 수행한다. 초기에는 정상에 잠겨 있어 점프 접근을 우회하지 못한다.
- C: 퍼즐 해결로 외부 발판 출현 → 동료가 발판을 계속 누름 → 지렛대와 이동식 롤러로 파츠 반출 → 파츠 전체가 문 밖 대기 공간에 도착 → 발판 담당 합류 → 중앙까지 수동 운반. 원안의 최소 2인 협동 조건을 유지한다.
- 모든 반출로와 중앙 조립대 진입부의 계단·문턱을 없애고, 파츠와 양옆 작업자 공간 및 코너 회전 공간을 확보한다. 경사에서는 정지·재출발이 가능해야 한다.
- A와 D도 기존 상세 컨셉에서 나오는 출구 이후에는 수정 조감도의 연속 운반로를 따른다.

## 구현 전 확인

그림은 치수 도면이 아니다. 실제 파츠별 충돌체·무게·돌출부를 기준으로 1인 밀기 힘, 브레이크 유지력, 문 폭, 회전 여유, 롤러 재배치 가능성, 경사 정지, 바닥 단차를 검증해야 한다. 최종 적층·용접 방식은 이번 반출 동선 컨셉의 범위 밖이다.
