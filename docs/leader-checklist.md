### 3.2 Epic 담당자(검증 책임 파트원) 지정
Epic 9개 모두 담당자가 비어 있습니다. 컨벤션상 Epic 담당자 = 최종 검증 책임자, 보고자 = 팀장. 담당자가 정해지면 R1이 하위 Task의 보고자를 그 사람으로 자동 지정하기 시작합니다. [Infra]가 입력합니다.

## 4. 팀 공지 (스크럼 때 1분)

- 이슈 제목은 `[파트] 제목`, 담당자 필수 — 어긋나면 `needs-fix`가 자동으로 붙고 댓글이 달립니다
- 진행 중은 이슈 화면 **브랜치 만들기**로만, 완료는 MR 머지로만 — 카드를 끌면 되돌아옵니다
- 새 이슈는 백로그에 생기고, 스프린트에 넣으면 기한이 자동으로 채워집니다
- 클론 후 `git config core.hooksPath .githooks`, `git lfs install` 1회
