## 범위와 판단

저장된 Stage1_Astra 씬, FBX를 참조하는 프리팹, FBM BaseColor, 저장된 실제 모델/씬 미리보기를 확인했다. Unity Editor 실시간 화면이나 새 FBX 렌더를 생성한 작업은 아니다. 게임 씬에 대한 수정 없이 컨셉 이미지와 설명만 작성했다.

- **기존 요소 8종:** 긴 보행로 0~4, 관측대 연결판, 4단 계단 조립체, 공용 관측 센서. 반복 인스턴스를 별도 모델로 늘리지 않았다.
- **추가 제안 2종:** 접점용 이음판과 절벽 측 난간. 구조 접점과 가장자리의 시각적 설명을 보강하기 위한 선택 요소다.
- **재사용:** HoverObservatory 본체, Part_2, 기존 볼라드/비콘, 자연 바위·버섯·식생은 신규 제작하지 않는다. 지지대·연석·방향 표지는 이미 제작된 HangarRelated 에셋을 우선 재사용한다.
- 씬의 그룹 이름에 'lift shortcut'이 있지만 이름만으로 작동하는 승강기를 확인할 수 없어 이번 신규 제작 목록에는 넣지 않았다.

## 뷰·치수 읽는 법

모든 시트의 배열은 위쪽 **CONCEPT / FRONT / RIGHT**, 아래쪽 **LEFT / TOP / BACK**이다. 한국어로 전체 컨셉 / 정면 / 오른쪽 / 왼쪽 / 위 / 뒤에 해당한다.

제작 기준 정면은 로컬 -Z, 뒤는 +Z, 오른쪽은 +X, 왼쪽은 -X이다. L01~L06은 짧은 접속 끝을 정면으로 보고, L07은 낮은 계단 쪽, L08은 점검구, L10은 보행면을 향하는 넓은 면을 정면으로 본다. 이미지 TOP 패널 중 일부는 가독성을 위해 가로 배치되어 있으므로 위쪽이 항상 +Z라는 뜻은 아니다.

시트는 **외형 컨셉이며 정밀 정투상 도면은 아니다.** 일부 정면·측면에는 상면이 조금 보이고, 뷰 사이 패널 수·화살표 위치·너비 비례가 완전히 일치하지 않는다. 최종 모델링에는 아래 치수, 씬 배치값, 단일 3D 모델로 만든 정투상 검증이 우선한다. 특히 L04 화살표와 패널 분할은 아래 설명대로 정리한다. L09의 조절 기능은 형상 제안이며 검증된 기구 설계가 아니다.

치수 단위는 m. 일반 표기는 폭(X) × 높이(Y) × 길이(Z). 위치는 씬에 저장된 **로컬 좌표**로, 원본 부모 계층을 유지하는 기준이다. 이미지의 소품 크기를 픽셀로 재서 치수로 사용하지 않는다.

지면 쪽에서 긴 보행로로 들어가는 시작 구간. 흰 외곽 프레임과 청록 화살표로 진입 방향을 보여준다. 큰 라벤더 패널과 낮은 체결부를 사용해 관측대의 시설 언어로 연결한다.

- **씬 대응:** Long walking trail 0
- **규격:** 4.4 × 0.6 × 13.810682 m
- **배치 기준:** (34, 0.55, -4.5), 상승 약 7.45°
- **제작 참고:** 보행 면은 연속 평면으로 유지한다. 씬의 기존 회전이 상승 경사를 만들므로 모델 자체에 경사를 중복 적용하지 않는다. 원래 폭 4.4m 안으로 장식이 과하게 침범하지 않게 한다.

### L09 · 방향 전환 이음판

직선 보행로가 서로 다른 방향으로 만나는 접점을 정돈하는 얇은 연결 덮개. 겹치는 패널과 낮은 외곽 프레임으로 이음부를 표현한다. 실제 틈이나 충돌 결함을 확인했다는 뜻은 아니며, 접점별 필요성을 확인한 뒤 사용한다.

- **씬 대응:** 신규 제안
- **규격:** 제안 치수 4.4 × 0.2 × 2.4; 접점마다 조절 m
- **배치 기준:** 미배치. 보행로 0↔1, 1↔2, 2↔3, 3↔4 접점의 필요 위치만 검토
- **제작 참고:** 접점별 방향·상면 높이를 먼저 확인한다. 낮은 덮개 상면을 기존 보행면과 맞추며 네 접점에 일괄 설치하지 않는다.

![방향 전환 이음판](09-adjustable-trail-junction.png)

- **씬 대응:** 신규 제안
- **규격:** 제안 치수 2.0 × 1.0 × 0.18 m
- **배치 기준:** 미배치. 상부 보행로의 절벽 측 외곽에 선택 적용
- **제작 참고:** 난간 발은 보행면 바깥에 둔다. 실제 적용 전 파츠 운반 폭, 낙하·점프 동선, 카메라 시야를 확인한다.

## 재사용 및 배치 우선순위

1. L01~L05로 기존 다섯 통로의 외관을 통일하고 원래 길이·회전·충돌 통로를 기준으로 맞춘다.
2. L06으로 정상 연결부를 마무리하고, L07·L08로 관측대 주변의 블록형 요소를 정리한다.
3. 접점이 시각적으로 어색한 곳에만 L09를 적용한다. 충돌 문제가 있다는 결론은 아니다.
4. 낙차가 큰 외곽에 L10을 선택 적용한다. 전체를 폐쇄형 복도로 만들지 않는다.
5. 필요한 하부 지지는 기존 `HangarRelated/12-adjustable-deck-support`, 낮은 연석은 `10-modular-edge-curb`, 안내 표지는 `13-route-wayfinding-beacon`를 검토한다. 안전 볼라드와 Part_2 비콘을 대체하는 별도 목표물은 추가하지 않는다.

## 제작·검토 기록

- 내장 이미지 생성 도구로 10종을 각각 생성했다. 최종 이미지 10장 모두 전체 컨셉·정면·오른쪽·왼쪽·위·뒤의 여섯 패널과 라벨을 눈으로 확인했다.
- L01 정면/후면 투시를 보정했고, L02·L09의 어두운 배경을 밝게 보정했으며, L06을 짧고 넓은 연결판 비례로 보정했다.
- 색상·실루엣의 컨셉 검토를 완료했다. 뷰 간 완벽한 기하 정합, 실제 충돌, 조립 가능성, Play Mode 검증은 이번 이미지 작업에 포함되지 않는다.
- 씬 배치 근거는 `scene-evidence.json`에 14개 오브젝트와 검사 시점의 씬 SHA-256을 보존했다. 작업 중 공유 씬 파일이 외부에서 갱신되어 줄 번호 대신 오브젝트 ID를 기록했다. 본 작업에서는 Unity 에셋·씬·스크립트를 수정하지 않았다.
- 프롬프트와 보정 이력은 `prompts.md`, 최종 파일과 생성 원본 경로는 `asset-catalog.json`에 있다.
