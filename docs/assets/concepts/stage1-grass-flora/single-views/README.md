# Astra 식생 — 개별 4방향 이미지

9종 × 정면·왼쪽·오른쪽·후면 = 총 36개 PNG입니다. 각 파일에는 식생 한 종류의 한 방향만 담았습니다.

모든 이미지는 내장 이미지 생성 도구로 제작했습니다. 정면을 기준 이미지로 사용해 측면과 후면을 생성했습니다. 모델링용 컨셉 참고 자료이며, 하나의 3D 메시를 회전해 렌더링한 결과는 아니므로 방향 간 세부 잎·표면무늬에는 차이가 있습니다.

왼쪽·오른쪽은 정면 이미지에서 보이는 대상을 기준으로 카메라를 해당 측면으로 옮긴 방향입니다.
