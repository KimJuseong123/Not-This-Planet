## 미술 방향
기존 외부 관측대 FBX와 연결된 FBM BaseColor, 저장된 모델 배치 스크린샷에서 확인한 펄 화이트·저채도 라벤더·청록 발광부를 계승했다. 격납고의 티타늄/화이트 프레임과도 맞춘다. 작은 바닥 직사각형 유도등을 낮은 교체형 조명 모듈로 재해석했다.

- 부드러운 챔퍼 외장, 상면에 끊기지 않는 확산 렌즈 1개(현재 이미지에서는 청록 예시), 코너 나사 4개.
- 좌우 끝판은 동일한 라벤더 구조. 전면은 2개 슬롯의 사다리꼴 인서트, 후면은 작은 매립 점검판.
- 하단은 짙은 티타늄/고무 가스켓. 과한 발광 번짐과 복잡한 기계 장식은 줄인다.
- 높은 볼라드, 원거리 수직 비콘과 구분되는 낮은 바닥 조명이다.

## 발광 색상 변경을 고려한 제작 기준
2026-09-16 사용자 요청 반영: 현재 이미지의 청록은 예시이며 최종 광색은 미확정이다. 기본등과 보조 에셋 모두 다른 광색으로 바꿀 수 있도록 제작한다.

- 외장 팔레트와 발광부 색을 독립적으로 취급한다. 기본 외장은 펄 화이트·저채도 라벤더·티타늄으로 유지하되 최종 광색과의 조화는 씬에서 확인한다.
- 렌즈의 색상 텍스처에는 청록을 고정해서 굽지 않는다. 중립 흰색/회색 렌즈 텍스처와 별도 흑백 emission mask를 사용하고 재질에서 광색과 발광 강도를 각각 조절하도록 한다.
- 꺼진 렌즈의 기본색과 켜진 발광색도 별도로 조절할 수 있게 한다. 외장 텍스처에 특정 광색의 번짐을 고정해서 그리지 않는다.
- 기존 씬 문서의 Ion cyan, Route amber, Route lime, Signal orchid를 색상 후보로 참고한다. 이는 후보 목록이며 새 바닥등의 구역별 의미나 최종 색상을 확정한 것은 아니다.
- 기본등·화살표·계단등은 같은 색상 설정을 공유할 수 있게 구성한다. 모듈 형태를 다시 만들지 않고 광색을 바꾸는 것을 목표로 한다.
- 최종 색은 보라 식생과 지면, 밝은 데크, 어두운 배경에서 구분되는지 확인하고 고른다. 색만으로 방향·경로를 구분하지 않고 화살표 형태와 배치도 함께 활용한다.
- 기존 PNG 9장은 청록 적용 예시로 유지한다. 다른 색상 이미지나 실제 Unity 재질을 추가 제작한 상태는 아니다.
## 모델링 기준 제안
아래 치수는 새 에셋 제작용 제안이며 FBX 실측값이 아니다.

- 기본등: X 너비 350mm × Z 깊이 120mm × Y 높이 35mm.
- 좌표: Unity 기준 Y 위, 정면 -Z, 후면 +Z, 왼쪽 -X, 오른쪽 +X. TOP은 화면 위쪽 +Z.
- 피벗은 하단 중앙. 지면/데크와 맞닿는 기준을 먼저 정하고 삽입 깊이를 조절한다.
- 외장, 렌즈, 하단을 분리하고 emission mask를 별도로 만들어 광색을 변경할 수 있도록 한다.
- 렌즈는 선택한 광색이 유지되는 밝기로 시작하며 실제 씬 노출/Bloom에서 조정한다.
- 좌우 이미지는 같은 형태를 별도 생성한 참고도이다. 03/04에는 상단 챔퍼와 나사가 일부 보이며, 06은 전면 인서트가 가장자리에서 조금 돌출돼 보인다. 정확한 정투상도나 완전히 정합된 3D 렌더 세트는 아니다. 모델링 시 기본 치수와 01의 형상, 06의 상면 배치를 우선하고 좌우를 대칭으로 통일한다.
- 뷰별 그림의 픽셀 크기는 물리적 스케일이 아니다.
