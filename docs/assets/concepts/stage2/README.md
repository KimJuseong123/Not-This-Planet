## 최신 맵 방향 — v2

![컨테이너와 유독 가스가 있는 발사장](v2/stage2-containers-gas.png)

[v2 상세 안내와 프롬프트](v2/README.md): 파츠 컨테이너 개방 후 인양, 조종석 승강기 후보, 이동식 사다리, 수동 공구, 유독 가스와 방독면 아이디어를 담았습니다.

그림에 추가된 인원·컨테이너 수는 게임 규칙이 아닙니다. 크레인 훅 위치, 회전부와 승강장 연결, 분사 명중 대상은 제작 시 수정·검증해야 합니다. 엘리베이터와 방독면의 세부 규칙은 기획서의 제안·미정 구분을 따릅니다.

## 아직 없는 개별 시안

컨테이너, 조종석 승강기, 이동식 사다리, 수동 몽키스패너, 방독면·보관대는 v2 장면에만 표현했습니다. Tripo용 단일 물체 이미지와 규격 도면은 후속 제작 대상입니다. 장면 전체를 넣고 모든 물체가 게임용 에셋으로 분리되어 나온다고 가정하지 않습니다.

## 보관·제작 기준

- PNG 원본 10장을 Git LFS로 보관합니다. 중복 ZIP·생성 캐시·모델 다운로드는 넣지 않습니다.
- 이 묶음은 2D 초안입니다. 신규 Tripo 요청·크레딧 사용·3D 생성·Unity 변경은 이번 정리 작업에 없습니다.
- 외형보다 기획서의 기능 방향이 우선입니다. v1은 삭제하지 않고 이전안으로 명시해 디자인 변경 이유를 남깁니다.
- 기존 캐릭터와 에셋을 참고했습니다. 세부 출처·제작 프롬프트·오차는 각 버전 README를 확인합니다.
