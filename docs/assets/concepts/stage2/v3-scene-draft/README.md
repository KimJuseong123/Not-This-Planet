## 디자인 기준
- 폐허가 된 **지구**의 산업 발사장. 외계 발광 식물 대신 잡초·덩굴·이끼가 시설 가장자리로 침투한다.
- 아이보리 로켓, 청록 장비, 황토색 안전 부위, 회색 콘크리트와 적갈색 녹. 파란 준비 동선·황색 조립 동선을 유지한다.
- 귀여운 캐릭터와 굵은 장비 실루엣을 유지한다. 이미지의 세밀한 녹·잡석은 실제 게임에서 밀도를 줄여 가독성을 우선한다.
- 고정 하단 + 인양 파츠 3개, 컨테이너 3개, 크레인, 고정 조종 발코니와 승강기, 이동식 사다리, 수동 렌치, 동료 제독과 고정 샤워를 기준으로 한다.
- 가스는 손상 설비 주변의 국소 위험이다. 식생 자체의 독성, 방독면 필수 진행, 고정 로켓 작업 타워는 추가하지 않는다.

## 제작 인계
PNG는 2D 외형 참고다. 여러 물체가 있는 시트를 그대로 단일 3D 생성 입력으로 쓰기보다 대상 하나를 정하고 앞·뒤·옆 구조를 추가 설계한다. 식생은 충돌 없는 장식 또는 낮은 충돌로 처리하고, 불필요한 알파 오버드로·재질 수를 줄인다. 크레인 트롤리·회전부·훅·승강기·컨테이너 지붕·사다리 가동부는 분리 제작한다.

이미지 검수에서 전경의 비물리적 부유 파츠를 수정했다. 나머지 기구학·스케일·체결 위치 차이는 위 표에 기록했다. 3D 모델 생성이나 씬 아트 교체는 수행하지 않았다.
