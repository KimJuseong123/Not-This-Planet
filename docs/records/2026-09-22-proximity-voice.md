# 근접 음성 채팅 + V AI 명령

## 동작
- 기본 오픈 마이크. 게임에 접속하고 조작 가능한 동안 하나의 마이크를 공유한다.
- ESC/태블릿 등 커서 해제, 포커스 상실, 사망, 컷신/엔딩에는 녹음과 송신을 중지한다. 메뉴에서 다른 사람의 음성 수신은 유지한다.
- 일반 음성은 3m부터 감쇠하며 20m 밖에서는 서버가 수신자에게 전달하지 않는다. 벽 차음은 없음. 높이도 포함한 3D 거리.
- V 시작 시 서버 위치 기준 20m 안의 AI와 명령 리비전을 저장. V 종료 시 그 후보에 대해서만 STT/LLM 명령 실행. 말하는 동안 접근한 AI는 추가하지 않고, 멀어진 후보는 이미 들은 명령을 수행할 수 있다.
- 대상 없는 경우 모델 호출 없음. 일반 대화는 모델에 전달하지 않는다. V 발화도 주변 플레이어에게 들린다.
- AI 팩이 없는 참가자도 음성 채팅 가능. AI는 기존 방장 팩을 사용.
- ESC에 마이크 음소거, V-only 옵션, 음성 수신 음량, 참가자별 음소거 추가. 기존 UI/설정/태블릿 유지.
- 녹음/대화 파일 저장 없음. 음성은 현재 매치의 서버 및 근처 플레이어에게만 전달. 별도 음성 서비스/API/다운로드 없음.

## 구현
- `ProximityVoice.cs`: 마이크 단일 소유, 16kHz mono 40ms 프레임, 고역통과 필터·적응형 하향 확장·에너지 VAD와 240ms 유지. V 구간은 VAD로 잘라내지 않음.
- 잡음 처리는 기본 DSP이며 RNNoise/WebRTC급 음성 분리나 AEC가 아님. 키보드 충격/큰 주변 대화 제거는 보장하지 않음. 헤드셋 권장.
- 8-bit mu-law 패킷 640bytes × 25fps = 발화 중 약 16KB/s(128kbps), 헤더 제외. Opus보다 대역폭이 크지만 추가 바이너리 의존성 없음.
- `NetPlayer.ProximityVoice.cs`: 기존 Mirror 소유권 Command, unreliable 송신, 길이/순서/초당 빈도 제한, 서버 거리 검증 후 대상 RPC. 원거리에는 데이터 자체를 보내지 않음.
- 수신: 최대 약 240ms 큐, 80ms 시작 버퍼, 오래된 순서 패킷 폐기, 무신호/범위 밖/음소거 시 큐 비움. 지터/손실 품질은 실제 네트워크 검증 필요.
- `AiVoiceControls.cs`: 공유 프레임 중 V 구간만 최대 8초 모아 기존 AI 음성 업로드 사용.
- `AiGroupOrders`의 거리 제한은 음성 경로에서만 사용. 기존 직접 테스트 API와 작업 실행 중 이동에는 범위 제한을 추가하지 않음.
- `VoiceRules.Range`가 공통 거리 설정. 초기 20m는 테스트 수치이며 Stage2 크레인 높이를 포함해 조정 필요.

## 검사
- 최종 Unity 컴파일 및 검사 28개 통과, 실패 0. `METAGAME/Logs/proximity-voice-final.xml` / `.log`. 거리 스냅샷·기존 그룹 명령은 실제 호스트/AI를 생성하는 EnterPlayMode fixture로 확인.
- 실제 마이크는 자동 테스트에서 열지 않음. 합성 샘플/코덱/VAD/설정 복제/거리 경계 및 Unity 네트워크 fixture 사용.
- 실사용 마이크 품질, 2PC 음성 송수신/지터/스피커 반향은 미검증. 기존 exe에는 반영되지 않으므로 재빌드 필요. AI 추가팩 재포장은 불필요(게임 코드만 변경).

## 수동 확인 순서
1. 헤드셋 두 PC, 동일한 새 빌드로 같은 방 접속. AI 팩 없는 참가자도 대화 확인.
2. 가까이 말하기 → 멀어지면서 음량 감소 → 20m 밖에서 안 들림 → 다시 접근하면 정상.
3. 마이크 음소거/수신 음량/상대 음소거, ESC/다른 창 전환 때 내 송신 정지 확인.
4. 일반 대화에는 AI 무반응. V 따라와 명령에는 주변 AI만 반응.
5. 주변 AI 없을 때 안내와 모델 처리 생략 확인. 다들 명령도 근처 AI만 수행.
6. V 시작 후 AI가 멀어져도 기존 후보 유지, 뒤늦게 접근한 AI는 명령 대상이 아닌지 확인.
7. 방 재입장/장면 전환/호스트 재연결 뒤 마이크 중복/오래된 음성 재생 여부 확인.

## 남은 개선
- 전문 잡음 억제/AEC, Opus 압축, 실제 패킷 손실 보간은 별도 고도화.
- 현재 V-only 옵션은 AI 명령 키와 공유하므로 일반 PTT 전용 키가 필요한 사용자는 추후 키 설정 확장 필요.
- 음성 채팅은 게임 내 NetPlayer 생성 이후 제공하며 HTTP 방 대기 화면 자체의 음성 채팅은 포함하지 않음.
