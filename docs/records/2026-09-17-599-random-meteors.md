# 599 무작위 운석 생성

- 브랜치: `S15P21B202-599-level`, 기준 커밋 `56794cd0`.
- 워크트리: `.local-worktrees/599`, Unity 프로젝트: `METAGAME`.

## 동작과 조절

`MeteorSpawner`는 생성 묶음마다 `기준 간격 + Random(-오프셋, +오프셋)`을 새로 계산한다.
공세 전은 3 ± 1초(2~4초), 공세 후는 1 ± 0.5초(0.5~1.5초)이다.
물리 틱 단위로 실행하므로 실제 생성은 최대 한 틱 늦을 수 있다.
Inspector에서 `Spawn Interval Seconds`, `Spawn Interval Offset`,
`Assault Spawn Interval Seconds`, `Assault Spawn Interval Offset`을 조절한다.
잘못된 설정도 간격이 0.05초 아래로 내려가지 않도록 제한한다.
기존 시간대별 간격 및 묶음 내부의 순차 생성 간격은 더 이상 사용하지 않는다.
시간대별 운석 수량·중형 확률과 후반 인원수 보정은 유지한다.

초반에는 솔로를 포함해 묶음마다 1~2개가 동시에 떨어진다.
공세 중 수량은 기존의 2배, 최소 3개이며 Inspector의
`Assault Count Multiplier`, `Assault Min Meteors`로 조절한다.
공세 시작 직후에는 강화된 첫 묶음을 즉시 생성한다.
이미 알린 공세 전 묶음이 있으면 그 수량도 첫 묶음에 포함한다.
반복 공세 요청은 첫 묶음을 중복 생성하지 않는다.

기본 목표는 지정 영역 무작위 지면과 플레이어 주변 낙하의 혼합이다.
`Random Area Near Player Chance` 기본값 0.3으로 플레이어 주변 후보를 선택한다.
`Player Target Min Radius`/`Player Target Max Radius` 기본값은 1m/3m이며 Inspector에서 조절한다.
확률을 0으로 두면 기존 전체 영역 무작위 낙하만 사용한다.
기절한 플레이어와 직전 대상으로 선택한 플레이어는 제외하며, 대상이 없으면 영역 무작위로 돌아간다.
착탄 지점은 생성 시 확정하므로 경고가 표시된 뒤 플레이어를 따라 움직이지 않는다.
`Random Area Targets`를 끄면 기존 가중치 목표 선택을 사용할 수 있다.
실제 실행의 최초 시드는 매번 다르며, `Configure(seed)`와 `ResetRun()`은 재현 가능하다.
착탄 경고 시간과 낙하 속도 계산·대각선 진입·방망이 타이밍은 유지한다.

`Stage1Sequence`는 대기/입장 중에만 생성을 막는다. 탐색에서는 느린 생성이 실행되고,
공세 트리거가 연출을 시작하는 즉시 강화 간격으로 전환한다.
기존 연출의 입력 잠금과 완료 시간은 유지한다.
호스트/솔로의 `MeteorClockBridge`가 실제 생성을 담당한다.
`WorldSync`는 경고 및 운석 자세 묶음이 비신뢰 채널의 패킷 크기를 넘으면
분할 가능한 신뢰 채널로 전체를 전송한다. 두 경로는 같은 수신/순번 검사를 공유한다.
기존의 전송 개수 잘라내기를 제거해 공세 중 누락을 방지한다.
씬·프리팹 수정 및 추가 Inspector 연결은 필요 없다.
