# Astra 대관람차·대포·TNT

대상: `METAGAME/Assets/Scenes/Stage1_Astra_ver2.unity`.

## 배치와 조작

- **대관람차:** 서남쪽 중심 (-36, 13, -31), 반지름 9m. 초당 6도, 약 60초에 한 바퀴를 돈다. 8개 좌석은 수평을 유지한다. 문이나 조작 버튼 없이 항상 열린 동쪽 입구로 승강장에서 올라탄다. 좌석 바닥은 실제 움직이는 kinematic Rigidbody이며 기존 플레이어의 바닥 추종을 사용한다.
- **대포:** 남쪽 (3, 지면 높이, -32). 파란 입구 표시를 기존 잡기 입력으로 잡으면 한 명이 탑승한다. 다른 플레이어가 뒤쪽 주황 점화 손잡이를 잡으면 도화선이 줄어들고 불씨가 대포 쪽으로 이동한다. **3초 후** 탑승자를 전방 위쪽 30도 방향으로 발사한다. 초기 속도는 25m/s, 초기 1.1초 동안 보행 제어가 발사 속도를 지우지 않도록 중력을 반영한 속도를 유지한다. 기절·다른 탑승·위치 복귀 시 남은 추진을 중단한다. 점화 없이 30초 기다리면 자동으로 옆에 내려주어 탑승 상태에 갇히지 않는다.
- **TNT 보급실:** 동쪽 (37, 지면 높이, 18) 입구를 바위가 막고 있다. (38, 지면 높이, 10)의 붉은 TNT 묶음을 잡아 바위 앞에 내려놓고, (42, 지면 높이, 7)의 원격 기폭 손잡이를 잡는다. 연결 케이블이 TNT와 스위치의 관계를 보여 준다. TNT가 바위 중심에서 3.5m 이내에 있을 때 폭발하면 바위의 그림과 충돌이 함께 사라진다. 섬광과 파편은 잠시 표시되며, 안에는 추가 연료통 두 개가 있다. 다른 곳에서 폭발시키면 입구는 열리지 않고 4초 후 TNT를 시작 위치에 보충한다. 다른 플레이어가 TNT를 잡고 있으면 기폭하지 않는다.

TNT는 이 보급실 바위를 여는 전용 기믹이다. 임의의 Terrain을 파내거나 다른 맵 구조물·플레이어를 폭발 피해로 파괴하지 않는다. 기존 네 파츠, 안내 조명, 고정못·끈, 퍼즐, 놀이 도구와 운반 길은 유지한다.

## 구현과 검증 범위

`AstraFerrisWheel`, `AstraPlayerCannon`, `AstraBlastGate`를 추가했다. 대포는 기존 `TryBoardShip` / 좌석 복원 / `EjectFromShip`을 재사용한다. 추가 런타임 입력 키나 전역 물리 설정 변경은 없다. 편집 도구는 `Stage1AstraAttractionsBuilder`이며 이미 확장 루트가 있는 씬에는 중복 적용을 거부한다.

대관람차 회전 위상, 대포 점화·점유·남은 시간, TNT 폭파·통로 상태는 기존 WorldSync의 기구 스냅샷에 포함한다. 대포 좌석과 TNT는 기존 고정 목록의 물체 추적에 포함한다. 실제 탑승·점화·폭파 결정은 서버에서만 수행한다. 로컬 플레이어 두 명으로 대포 동작을 검증하는 것은 별도 프로세스의 네트워크 협동 검증과 다르다. 실제 다중 클라이언트·지연·늦은 참가 검증은 미실시다.

검증 증거: `docs/records/validation/astra-attractions/`. Unity에서 촬영한 그림: `docs/art/stage1-astra-attractions-2026-09-14/`. 전체 프로젝트 테스트나 제품 빌드를 통과했다는 의미는 아니다.

Unity 6000.5.4f1의 격리 프로젝트에서 관련 EditMode 테스트 **63/63**, Play Mode 확인 **22개**, 기존 파츠 크기에 따른 고정 장애물·바닥 지지 검사 **451개 지점**을 통과했다. 대관람차의 실제 좌석 바닥에 올라선 플레이어는 약 2초에 (0, 0.15, 1.89)m 이동했다. 대포 입구·뒤쪽은 플레이어 두 명의 잡기 입력으로 검증했으며, 점화 3초 이전에는 탑승 상태가 유지되고 이후 발사되어 약 (0, 8.25, 15.92)m 이동했다. TNT의 잘못된 배치·재보충·잡기·원격 점화·바위 충돌 제거·파편 소멸 이후 개방 유지도 확인했다. 마지막 외형 검증에서 누락된 바위 재질 경로를 수정했고, 메타파일 및 씬 참조를 함께 반영했다.
