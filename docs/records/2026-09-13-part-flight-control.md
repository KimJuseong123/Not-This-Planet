# 1번 파츠의 본체 보존과 물리 비행

## 적용

- 고정못 해제 시 본체 Transform, 원래 Collider, 소켓, 비드 및 부모 계층을 유지한다. 루트에 직접 붙은 BoxCollider도 복제하지 않는다. 기존 `VehicleHull_*` 생성과 비드 컨테이너 재부모화 경로를 제거했다.
- 견인빔만 별도 자식 `TractorBeamOrigin`의 아래 방향을 사용한다. 물체 자체의 위쪽은 계속 로컬 Y축이다.
- 미탑승 시 회전을 잠그지 않는다. 탑승 시 부양력을 0.8초에 걸쳐 켜고, 자세 오차와 각속도를 이용한 회전력으로 수평 및 조종 방향을 회복한다. 본체 위치/회전을 직접 보간 대입하지 않는다.
- 운석 충격 후 0.8초 동안 충격 회전을 허용한 뒤 부양과 자세 제어를 재개한다. 회복 시작 시 현재 고도를 기준으로 삼으며 이전 위치로 복귀시키지 않는다.
- 천장 탐사는 뒤집힌 기체도 월드 위쪽을 기준으로 수행한다. 실제 이동과 회전은 물리 충돌 해결을 따른다.
- 좌석은 몸체 충돌 형상을 본체 좌표계에서 측정해 배치하므로 기울어진 상태로 탑승해도 동일한 위치에 있다. 카메라 기울기는 12도로 제한한다.
- 배치/조립 상태, 다른 파츠와의 연결 또는 바닥 용접이 있으면 단독 탑승을 막는다. 원격 kinematic 본체에는 비행 힘을 적용하지 않는다.
- §14.2의 2026-09-10 팀 합의를 유지한다. 하차하면 저중력장을 끄고 중력으로 착륙한다. 무인 호버를 새로 도입하지 않았다.
- 기존 독립형 견인 장치의 동작은 유지한다. 파츠에는 독립형 장치용 `PlaceOnGround` 재배치를 적용하지 않는다.

## 검증

- Unity 6000.5.4f1, 별도 `outputs/tractor-tests` 사본에서 화면 조작 없이 EditMode 및 `Physics.Simulate` 실행.
- 정상/75도/180도 초기 자세 각각: 충돌체 동일성, 해제 시 자세 보존, 미탑승 자유 회전, 탑승 순간 위치/자세 보존, 부양 및 수평 회복, 공중 운석 피격 후 누적 회전, 카메라 기울기 제한, 재안정화 및 탑승 유지 검사 통과.
- 천장 관통 방지, 하차 시 저중력장 꺼짐 및 중력 착륙, 배치 상태 탑승 제한 검사 통과.
- 기존 비드 생성/절단/보존, 견인, 하차, 운석 검사 포함 총 139개 중 138개 통과. `ActivatedPart1_IsRegisteredAsTransportInteractionTarget` 1개는 앞선 원본 비교에서도 동일하게 실패했던 기존 검사다.
- 결과: `.local-validation/part-flight-landing-final.xml`, 로그: `.local-validation/part-flight-landing-final.log`. 해당 Unity 컴파일에서 C# 오류 없음. `git diff --check` 통과.
- 실제 Main 씬의 조종 감각 및 실시간 호스트/참가자 접속은 직접 조작하지 않았다. 실제 파츠 크기와 장애물 밀도에 따른 부양/회복 속도 조율은 플레이 검증이 필요하다.
