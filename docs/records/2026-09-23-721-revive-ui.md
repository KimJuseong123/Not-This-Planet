## 남은 실제 멀티플레이 검수

실제 두 프로세스 네트워크 플레이 및 해상도별 화면 렌더링은 실행하지 않았다. 같은 서버 진행도를 사용하지만 수신 시점 차이로 화면 사이에 네트워크 지연은 남을 수 있다. 무오류 보장이나 전체 플레이어 빌드 검증으로 해석하지 않는다.

1. 호스트/참가자 역할을 번갈아 쓰러진 동료를 사거리 안에서 조준하면 `G 살리기`가 보이는지 확인한다.
2. G를 누르면 구조자에게 키 안내와 진행 게이지 2개, 대상에게 살아나는 중 게이지가 표시되는지 확인한다.
3. 절반에서 G를 놓으면 대상 UI가 사라지고 구조자에게 누적 진행도가 남는지, 다른 사람이 이어받아도 서버 누적량에서 계속되는지 확인한다.
4. 부활 완료·대상 퇴장·구조자 기절 후 오래된 표시가 남지 않는지 확인한다.
5. 고정못 잡기/해제, 쓰러진 동료 운반, 기절 카메라, 여러 UI 배율에서 겹침 여부를 확인한다.
