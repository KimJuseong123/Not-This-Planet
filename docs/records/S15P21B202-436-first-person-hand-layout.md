# 1인칭 손 하단 배치 및 빌드 자동 적용

- 이슈: S15P21B202-436
- 기준: develop 76b5053, Unity 6000.5.4f1
- 범위: 로컬 1인칭 표시만. 물리 손, 네트워크, 원격 아바타, 도구 로직은 변경하지 않음.

## 변경

- 손 위치: 좌/우 X ±0.34, Y -0.24, Z 0.42. 크기 0.22m.
- 회전: 왼손 (168,25,-12), 오른손 (168,-25,12).
- 잡기: 메시 로컬 -Z로 0.06m 이동, 상대 X -6도.
- Main 및 Stage1_Astra의 SpaceBootstrap 직렬화 설정과 런타임 기본값을 동일하게 변경.
- 생성 첫 프레임부터 대기 위치/회전을 적용하여 카메라 원점에서 보간되는 구간 제거.
- 수동 프리셋 메뉴는 UNITY_EDITOR 전용. Player 빌드에서 존재하지 않으며 필수 실행 단계가 아니다.

## 빌드 적용 경로

EditorBuildSettings 및 SpaceBuild의 필수 씬에 Main·Stage1_Astra가 포함된다.
SpaceBootstrap이 로컬 플레이어 생성 시 firstPersonHandSettings를 FirstPersonHandView.Create에 전달한다.
따라서 이 MR을 머지한 소스로 새로 만든 빌드에서 자동 적용된다. 이미 배포된 실행 파일은 변경되지 않는다.

## 검증

- 정적 확인: 실행 경로, 빌드 씬 포함, 두 씬의 동일한 손 설정, diff 공백 오류 확인.
- 회귀 테스트 추가: 수동 메뉴 없이 생성 즉시 대기 포즈 적용, 두 빌드 씬의 직렬화 설정과 기본값 일치(총 3개 케이스).
- 로컬 Unity 테스트 실행 및 새 Windows 빌드 생성은 미실행. CI 결과와 실제 플레이 검증을 별도로 확인해야 한다.
- 변경 전 사용자 스크린샷에서 손목이 위를 향하는 모습과 런타임 X=-78을 확인. 최종 구도의 시각 검증은 미완료.

## 머지 전 확인

1. 최신 브랜치의 Main 및 Stage1_Astra를 새로 로드한다. Play 중 프리셋 메뉴는 누르지 않는다.
2. 시작부터 손이 화면 양쪽 아래에 있고 중앙 시야를 가리지 않는지 확인한다.
3. 좌/우 잡기를 각각 누르고 놓아 해당 손만 뻗고 복귀하는지 확인한다.
4. 방망이·용접 도구 장착, 1/3인칭 전환, 탑승/기절 및 원격 아바타를 확인한다.
5. 새 Windows 빌드에서도 동일 구도를 확인하고 스크린샷을 MR에 첨부한다.

## 컴파일 참조 보완

- 추가한 씬 회귀 테스트가 SpaceBootstrap을 직접 사용하지만 테스트 asmdef에 Metagame.Bootstrap 직접 참조가 누락되어 CS0234가 발생했다.
- 테스트 asmdef에 Metagame.Bootstrap 참조를 추가했다. 기존 Metagame.Editor의 간접 참조에 의존하지 않는다.
- Bootstrap은 테스트 어셈블리를 참조하지 않아 순환 참조를 만들지 않는다. 테스트는 Editor 전용이며 플레이어 빌드 로직은 변경하지 않는다.
- 검증: Unity 6000.5.4f1에 포함된 Roslyn으로 기존 테스트 어셈블리 응답 파일에 Bootstrap 참조를 추가하여 전체 테스트 소스를 임시 폴더로 컴파일했다. 종료 코드 0, CS0234 포함 컴파일 오류 없음. 다른 기존 테스트의 obsolete API 경고만 출력됐다. 이는 컴파일 검증이며 테스트 실행/Windows 플레이어 빌드 검증은 아니다.

## 제외 범위

기존 로컬 렌더러·머티리얼·프로젝트 설정 변경은 포함하지 않는다. 본 작업에서 MR 승인·머지는 수행하지 않는다.
