# 용접 접합 추천 가이드 (2026-09-14)

- 용접건을 든 로컬 플레이어에게 파츠 접합부의 노란 반투명 띠를 표시한다. 솔로의 Owner와 멀티 참가자의 ViewOwner/remoteHeld 경로를 모두 지원한다. 원격 플레이어, 내려놓기, 비활성화, 다운, 탑승, 재료 소진 시 숨긴다.
- 첫 비드의 실제 접촉 범위(`WeldBeadMinRadius + WeldBeadContactSkin`, 현재 5cm)를 공유한다. 그 표면에서 비드를 시작하면 다른 파츠에 닿는 위치를 추천한다. 조인트가 이미 온전한 파츠 쌍은 제외한다. 조립대/바닥은 이번 파츠 간 추천 대상에 포함하지 않는다.
- `WeldingJointGuide`는 근처 몸체 콜라이더의 접합 후보 영역에 레이를 투영해 표면 메시를 만든다. 비드/고정쇠/트리거는 표시 대상에서 제외한다. 물리 콜라이더나 네트워크 객체를 추가하지 않고, 조회만으로 비드·조인트를 생성하지 않는다.
- `PlasmaWeldingTool` Inspector의 **접합 추천 가이드**에서 거리(기본 4m), 법선 오프셋(1.2cm), 노란색/알파(0.32)를 조절한다. 기존 조준 원의 오프셋 기본값은 2cm다. 새 씬/프리팹 연결은 필요 없다.
- `Resources/WeldingGuide.shader`는 URP 투명 셰이더이며 ZWrite Off, ZTest LEqual을 사용한다. 불투명 몸체 → 추천(3000) → 조준 원(3100) 순으로 렌더링한다. 추천이 조준 원의 깊이를 가리지 않으며 벽 뒤로 투시하지 않는다.
- 정지 상태는 0.1초 간격으로 갱신하고, 추적 중인 몸체가 이동/회전/비활성화되면 즉시 다시 투영한다. 면별 샘플 수는 최대 48×48 셀로 제한한다. 실제 Main 화면의 접합부 모양/투명도와 다중 피어 동시 플레이, 밀집 파츠 성능은 별도 플레이 확인이 필요하다.

## 검증

Unity 6000.5.4f1 별도 검증 프로젝트 `outputs/tractor-tests`에서 컴파일 및 관련 EditMode 테스트 **99/99 통과**. 결과는 `.local-validation/joint-guide-verified.xml`, 로그는 `.local-validation/joint-guide-verified.log`에 기록한다. 검증 범위는 기존 용접/절단/복원/네트워크 상태 회귀와 추천 위치의 실제 첫 비드 접합, Box/MeshCollider, 표면 오프셋, 이동 후 표시 갱신, 솔로/원격 표시 소유권, 해제 시 숨김이다. 실제 인게임 시각 검증을 대신하지 않는다.
