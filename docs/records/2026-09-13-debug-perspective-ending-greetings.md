# F11 개발용 시점 전환과 엔딩 순차 인사

## F11

- Unity 에디터 또는 Development Build에서 일반 플레이 중 F11을 누르면 1인칭 ↔ 3인칭으로 전환한다. 배포 빌드에는 단축키를 포함하지 않는다.
- `GameSession.LocalPlayer.Cam`만 변경한다. 시점 선택을 네트워크 입력이나 RPC로 전달하지 않으므로 각 참가자가 독립적으로 사용한다.
- 기존 캐릭터 가시성 처리와 1인칭 손 표시가 `OrbitCamera.FirstPerson`을 따라갱신된다. 3인칭에서는 자기 몸을 볼 수 있고, 1인칭에서는 몸을 감추고 손과 그림자를 유지한다.
- 탑승·기절·협동 밀기 중에는 기존 자동 카메라가 우선한다. 이때 F11은 자동 카메라가 끝난 뒤 복귀할 시점을 바꾼다. 엔딩·입력 차단 상태와 자동 테스트 입력 중에는 단축키를 받지 않는다.
- 카메라의 조준 각도, 이동 상태, 다른 참가자의 카메라는 변경하지 않는다. 시점 전환과 자동 카메라 복귀에 따라 근접 클리핑 거리도 맞춘다.

## 엔딩

기획 문서 §22.2를 갱신했다.

1. 서버가 확정한 참가자 순서대로 A 인사 → A 얼굴 클로즈업 → B 인사 → B 얼굴 클로즈업을 반복한다.
2. 인원당 2초: 처음 0.6초는 인사 동작을 보여주고, 다음 0.65초 동안 얼굴로 접근하며, 남은 0.75초는 얼굴을 보여준다. 다음 사람에게 넘어갈 때 처음 0.3초 동안 카메라를 연결한다.
3. 전원의 인사가 끝나면 카메라가 와이드 화면으로 돌아오며 전원이 동시에 6초간 탑승한다. 개인별 탑승 지연은 없다.
4. 발사 5초 → 기념사진 5초 → 종료 문구 3초 → 로비 복귀를 유지한다.

인사·탑승 시간은 1인 8초, 2인 10초, 3인 12초, 4인 14초다. `DemoEnding`이 참가자 수에 따라 발사·사진·종료 시각을 계산하고 `DemoEndingView`와 로비 복귀 판정이 같은 시각을 사용한다. 카메라는 누적 프레임 이동 대신 공유 엔딩 시각으로 위치를 계산하므로 늦은 진입에도 현재 순서를 재현한다.

엔딩 스냅샷에 외형 선택값도 포함해 실제 참가자의 색조·헬멧 장식·배지를 인사와 기념사진에 반영한다. 예전 스냅샷에 선택값이 없으면 기본 외형(0)을 사용한다.

## 검증

- 화면 직접 조작 없이 `outputs/tractor-tests`의 별도 복사 프로젝트에서 Unity 6000.5.4f1 컴파일 및 헤드리스 테스트 52/52 통과.
- 범위: `DebugPerspectiveTests`, `EndingGreetingTests`, `DemoEndingTests`, `EndingSceneTests`, `FirstPersonVisibilityTests`, `RemoteRidingVisibilityTests`.
- 새 테스트는 두 카메라의 독립 전환, 자동 카메라 복귀, 1~4인 인사 순서와 시간 경계, Play Mode에서 각 얼굴로 이동하는 실제 카메라 좌표와 전원의 탑승 완료를 확인한다.
- 결과: `.local-validation/perspective-ending-final.xml`, `.local-validation/perspective-ending-final.log`.
- 실제 화면에서 키를 누르는 시각 검수와 두 PC의 네트워크 동시 재생은 실행하지 않았다. 클로즈업 구도·이동 속도의 미적 판단은 별도 확인이 필요하다.
