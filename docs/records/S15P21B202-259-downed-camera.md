# S15P21B202-259 기절 카메라

## 지금까지는 기절해도 카메라가 그대로였다

`PlayerRig.GoDown` 이 카메라를 **건드리지 않았다.** 몸은 래그돌로 쓰러지는데 시야는 서
있을 때와 똑같이 수평을 봤다 — **자기가 기절했는지 화면으로 알 수 없었다.**

기획은 요구한다.

- §10.1 "강한 넉백이나 기절 중에는 **자동으로 3인칭 전환**한다"
- §10.3 "쓰러진 캐릭터 중심의 3인칭 자유 시점이다 … **구조되면 1인칭으로 돌아온다**"

## 카메라가 몸의 회전을 쓰지 않았다

`OrbitCamera.LateUpdate` 는 이렇다.

```csharp
Vector3 raw = Target.position + Vector3.up * TargetHeight;   // 골반 + 세계 위쪽
Quaternion rot = Quaternion.Euler(pitch, yaw, 0f);           // 마우스뿐
```

주석이 이유까지 적어 두었다 — "물리 강체의 회전은 흔들릴 수 있으므로 위치는 골반의 월드
위치와 **세계의 위쪽만** 사용한다".

**걸을 때는 그것이 맞다.** 래그돌 골반이 매 스텝 떨리는 것을 시야가 받으면 멀미가 난다.
그런데 **넘어질 때는 그 떨림이 정보다.**

그래서 넘어지는 동안만 `Doll.Head` 의 회전을 그대로 쓰는 경로를 하나 냈다. 기존 1인칭
경로는 손대지 않았다.

## 단계 둘

```
① 쓰러지는 동안 (5초)   시야가 머리 본의 회전을 따라간다. 마우스 무시
② 그 뒤                쓰러진 몸 중심의 3인칭 자유 시점 (§10.3)
```

**①은 기획에 없는 연출이다.** §10.1·§10.3 은 **결과만** 정하고 전환 과정을 정하지 않는다.
즉시 3인칭으로 튀면 "내가 맞았다" 가 아니라 "화면이 바뀌었다" 로 읽히므로 한 번 몸과
함께 넘어가게 두었다.

①에서 마우스를 막는 이유는 몸이 넘어지는 회전과 마우스 회전이 섞이면 무엇이 넘어지는
것인지 알 수 없기 때문이다. `Steer` 첫 줄에서 돌려보낸다.

### 전환을 시간으로 끊었다

"몸이 멈추면" 으로 하면 §20.1 의 "기절한 플레이어도 다른 물체의 충격으로 다시 밀릴 수
있다" 때문에 **운석에 굴러다니는 동안 영영 1인칭에 머문다.** 검증이 그 경우를 잠근다 —
매 프레임 몸을 밀면서 5초를 재도 전환이 일어난다.

②로 넘어갈 때 시점 각도를 **머리가 보고 있던 방향에서 이어받는다.** 안 그러면 3인칭이
되는 순간 시야가 한 번 더 튄다.

## 선례를 따랐다

`OrbitCamera.SetVehicleView(bool)`(§22.2 탑승 궤도 카메라)가 상태를 저장하고 모드를
강제한 뒤 나갈 때 되돌린다. `SetDownedView(bool, Transform eyes)` 를 같은 구조로 만들었다 —
새 방식을 발명하지 않았다.

탑승 중이었다면 그쪽이 이미 값을 들고 있으므로 **두 번 저장하지 않는다.** 두 번 저장하면
복원이 어긋난다.

## §10.3 의 나머지 줄

| §10.3 | 상태 |
| --- | --- |
| 이동 불가 | **이미 막혀 있었다** — `Tick` 이 `Downed` 면 조종을 건너뛴다 |
| 장비 사용 불가 | **이미 막혀 있었다** — `GoDown` 이 `DropEquipment` 를 부른다 |
| 핑 불가 | 핑 기능 자체가 없다 (§25.8 [Art]·[UI] 몫) |
| 근접 음성은 계속 | 음성은 [Network] 몫이고 카메라와 무관하다 |
| **손·견인빔으로 이동되면 카메라도 따라간다** | **저절로 된다** — 타깃이 골반이고 S15P21B202-249 의 동료 운반이 골반을 끈다. 검증으로 잠갔다 |
| **구조되면 1인칭 복귀** | `Revive` 에서 `SetDownedView(false)` |

## 검증 16개

카메라는 `LateUpdate` 표현이라 EditMode 로 화면을 볼 수 없다. **상태와 전환을** 잠갔다 —
S15P21B202-243 에서 스윙 궤적을 순수 함수로 빼 검증한 것과 같은 방식이다.

| 묶음 | 무엇 |
| --- | --- |
| 진입 | 서 있으면 없음 · 기절하면 들어감 · **넘어지는 동안은 1인칭** |
| 넘어지는 동안 | **마우스가 안 먹힘** · 끝나면 다시 먹힘 |
| 3인칭 전환 | 5초에 바뀜 · 4.9초엔 아직 · **운석에 밀려도 미뤄지지 않음** · 시간 보고 |
| 몸 추적 | 타깃이 골반 (§10.3 운반) |
| 구조 복귀 | 1인칭 복귀 · 넘어지는 중에 구조돼도 복귀 · 두 번 기절하면 다시 처음부터 |
| 다른 모드 | Alt 자유 시점이 꺼짐 · **탑승 카메라 그대로** · 남의 카메라 불변 |
| 기존 금지 | 기절 중 이동·장비 불가 |

전체 604개 중 591 통과. 실패 13개는 develop 에 이미 있던 것이다(S15P21B202-232 건).
588 + 16 = 604 — **늘어난 실패가 없다.**

## 검증에서 걸린 것

**`SendMessage("LateUpdate")` 로 카메라를 강제로 돌릴 수 없다.** EditMode 에서
`ShouldRunBehaviour()` 단정에 걸린다. 회전을 보는 것을 포기하고 이미 공개돼 있던
`OrbitCamera.Yaw` 로 바꿨다 — **화면이 아니라 상태를 보는 것이 이 스위트의 방식**인데
한 곳에서 그것을 잊었다.

알 수 있다.

- 넘어지는 5초가 **멀미가 나지 않는지** — 머리 본이 물리로 떨리므로 이것이 가장 걱정된다
- 3인칭으로 물러나는 것이 튀지 않는지
- 5초가 긴지 짧은지
