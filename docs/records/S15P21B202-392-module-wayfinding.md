# [Art] 파츠 운반 경로 유도등 배치

- Jira: S15P21B202-392 / 선행 공유 작업: S15P21B202-369
- 브랜치: S15P21B202-392-module-wayfinding (369의 b2a62e6에서 분기)
- 사용자 요청으로 유도등 관련 씬·코드·재질·테스트·기록을 이 브랜치에 커밋하여 공유한다. MR·머지는 하지 않는다.

## 반영

- 반복 화살표·상승 화살표·별도 진입 게이트를 제거하고 작은 바닥 매립등으로 축소. 경로 간격 약 4.5m.
- 안내용 재질을 별도 URP Unlit 에셋으로 분리. 조명/그림자의 영향을 줄이고 과한 HDR 발광 없이 색을 유지한다. 원래 공유 아트 재질은 변경하지 않는다.
- 중앙 기존 기둥을 경사로에서 벗어난 외곽으로 이동하고 높이를 조정.
- AssemblyGuidanceLight는 기존 ShipAssembly.Floors를 읽어 다음 필요한 층의 색을 표시한다. 조립 규칙·물리·네트워크 권한은 바꾸지 않는다.
- 조립 순서 색: 엔진 주황 → Part_2 청록 → Part_3 보라 → 최상단 견인 Part_4 연두. 탐색 진행 번호(견인=2)와 조립 순서를 구분한다.
- 후속 안내 변경: 엔진 배치 후 견인 Part_4가 Locked이면 먼저 연두로 안내. 잠금 해제로 Locked를 벗어나면 위치에 관계없이 청록으로 진행한다. 보라 파츠까지 쌓은 뒤에는 최상단 조립을 위해 다시 연두로 표시한다. 실제 조립 판정은 변경하지 않는다.
- 빈 층·잘못된 파츠·기울어진 층 중 첫 번째를 안내한다. 용접 전이라도 올바르게 쌓였으면 다음 층을 안내하며, 모든 층이 맞으면 옅은 백청색.

## 검사

- Unity 컴파일 오류 검색 0건. 견인 잠금 해제 안내를 포함한 AssemblyGuidanceLightTests 11/11 통과.
- 초기 버전 Play Mode에서 주황 표시와 엔진 중앙 배치 후 청록 전환 확인. 이후 추가한 초록 우선 안내는 조건 테스트로 검증했으며 전체 플레이 흐름 재검증은 별도다.
- 기둥 위치는 3.4m 정사각형 보수적 파츠 박스로 남서 경사로부터 중앙까지 41지점 검사. 원래 기둥 및 새 안내 기둥의 진입 방해를 줄였다. 전체 맵 충돌체 감사 또는 실제 손 운반 완주 검사는 아님.
- Play 종료, 씬 저장. 검사 중 못 해제·파츠 이동·운석 생성 상태는 저장하지 않음.

## 첫 파츠 소실 조사 — 미재현

- 운석 스포너를 끄고 전체 못 동시 해제: 파츠는 시작 위치에서 약 0.22m 상승 후 유지.
- 별도 Play에서 못 4개를 순차 해제, 근처 착탄 처리 적용: 파츠는 시작 위치 근처에 유지.
- 중앙에 검사 목적으로 배치한 파츠 위에 진단용 운석을 떨어뜨린 뒤에도 파츠 활성·외형 유지.
- 색상 미표시 역시 이번 기준 Play에서는 원래 재질로도 색상이 보여 원인 확정 불가. 이번 재질 변경은 가독성·일관성 개선이지 재현된 결함의 원인 제거 주장 아님.
- 간헐적인 소실 원인은 미확정. 임의 리스폰·순간이동·운석 무효화로 증상을 덮지 않았다. 추가 발생 시 파츠 위치/속도/상태와 발생 직전 입력을 확보해야 한다.
- 기존 Console의 운석 파편 프리팹 참조 형식 경고 및 폰트 참조 문제는 별도 미해결 항목이다.

## 범위 제외

화물고 확장·빙판 퍼즐, 전체 맵 콜라이더 재구성, 멀티플레이·플레이어 빌드 검증은 포함하지 않는다.
