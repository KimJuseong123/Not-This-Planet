# Astra ver2 지뢰 탐색 지역 (2026-09-14)

대상: `METAGAME/Assets/Scenes/Stage1_Astra_ver2.unity`.

## 구현
- Part 3 밀실 앞 x20–31, z8.5–18 접근 구간에 매설 지뢰 16개. 양옆 낮은 벽으로 일반 보행 진입을 유도한다. 기존 다이얼, 압력 발판, 문, 파츠 위치와 조립대까지의 운반 길을 보존한다.
- 글자 없는 노란 삼각형/검은 느낌표 경고 표지 3개. 입구 양쪽과 귀환 방향에 배치했다.
- 탐색기 3개: 입구 안전 구간 두 개, 밀실 내부 귀환용 한 개. 기존 도구 집기·내려놓기·추락 복귀 기능을 사용한다.
- 좌클릭 유지 중 반경 6m의 미폭발 지뢰를 탐색한다. 걸음/달리기/점프 입력을 막고 수평 이동을 즉시 멈춘다. 시점 회전과 중력, 이동 발판, 외부 물리 상호작용은 보존한다. 해제·내려놓기·넘어짐·탑승 시 제한이 풀린다.
- 지뢰에 가까울수록 동심원 3개의 주기가 1.2초에서 0.12초까지 짧아진다. 빨간 LED가 함께 점멸한다. 1인칭 LED와 원격 도구 표현은 기존 시각 동기화를 사용한다.
- 발 위치가 지뢰에서 수평 0.65m, 수직 0.45m 이내일 때 폭발한다. 물건은 작동시키지 않는다. 피해 35와 밀쳐내기, 짧은 섬광 및 폭발 흔적을 남긴다. 같은 지뢰는 다시 터지지 않는다.
- 서버가 폭발을 판정하며 미폭발/폭발 비트와 섬광 경과 시간을 기존 WorldSync 10Hz 메시지에 포함한다. 지뢰 파괴 후 늦게 접속해도 지속 상태를 복원한다. 실제 별도 클라이언트 연결은 미검증이다.

## 운반 배려
보행 경로 중심 (x,z): (25,8) → (25,10.5) → (27,11.2) → (27,12.9) → (26,14.6) → (25,15.4) → (25,17.7).
압력 발판 분기: (25,15.4) → (22,15.4) → (21,14).
위 경로의 지뢰 중심 최소 거리는 각각 약 1.50m와 1.10m이다. 길 위에 정답 표시를 추가하지 않아 탐색기로 경로를 찾게 한다. 파츠에는 지뢰가 반응하지 않으며 견인장치가 필수인 장애물을 추가하지 않았다.

## 검증
검증 결과는 `docs/records/validation/astra-minefield/`에 보관한다. Unity 6000.5.4f1의 격리 프로젝트에서 컴파일, 관련 EditMode 테스트, 실제 PlayerRig의 입력을 통한 PlayMode 동작 및 운반 경로를 검사한다. 전체 빌드와 별도 네트워크 피어/지연 테스트는 수행하지 않았다.

최종 결과: 관련 EditMode **87/87 통과**, 실제 PlayerRig 입력 PlayMode **17/17 통과**, 기존 파츠 운반 **451개 지점 통과**, 지뢰 회피 경로 두 개의 지면/캡슐 충돌 검사 통과. 씬과 신규 아트의 GUID 참조 누락 0개, 신규 에셋의 meta 누락 0개. 최종 미리보기: `docs/art/stage1-astra-minefield-2026-09-14/`. 씬 GUID는 `c30d332e947e3ad438ea79859898aec8`로 유지했다. 검증 중 경고 표지와 큰 파츠의 귀환 동선이 겹쳐 표지를 옮겼고, 양면 삼각형의 조명 및 벽 위로 보이는 높이를 보정했다.
