# Stage2 렌치 투척과 크레인 시점

- 렌치 장착 중 Q를 누르면 즉시 전방으로 던진다. 충전 입력은 사용하지 않는다. 떨어진 렌치는 조준 후 E로 다시 장착한다. 장비대에서도 기존처럼 장착할 수 있다.
- 투척 물리는 Stage2Yard 권한 인스턴스가 처리하고, 기존 Stage2 스냅샷으로 위치·회전·생성·회수를 복제한다. 관찰자는 물리를 중복 실행하지 않는다. 월드 렌치는 최대 16개이며 추가 투척 시 가장 오래된 렌치를 정리한다.
- 크레인 조종 장치에 E로 진입하면 기존 OrbitCamera의 탑승 시점을 이용해 3인칭으로 전환한다. 조종 중 E는 시선 방향과 관계없이 종료하며 이전 시점 설정을 복원한다.
- 조종 중 회전·반경·상승·하강·정밀 조작·시점·종료·태블릿 키를 표시한다. 안내는 현재 Controls 바인딩을 따른다. 손 장비 및 일반 대상 안내는 조종 중 숨긴다.
- 기존 씬과 프리팹 수정, Inspector 추가 설정은 없다.

## 검증

Unity 6000.5.4f1의 분리된 프로젝트 복사본에서 Stage2Tests 12/12 통과. Play Mode에 들어가 Q 입력 소비, 투척 속도와 이동, E 재습득, 태블릿/기절 중 투척 차단, 늦참용 상태 복원·권한 없는 회수 차단, 크레인 3인칭·반경 조작·E 종료·원래 시점 복귀를 검사했다. 기존 조립·복구·제독·장 전환 검사도 포함한다.

결과: `.local-validation/stage2-controls/tests-final.xml`. 마지막 일반 대상 안내 숨김 변경은 별도 Bootstrap 컴파일로 확인했다. 그래픽 없는 자동 검사이므로 화면 배치의 육안 검수와 실제 다중 프로세스 네트워크 플레이는 이번 검증 범위에 포함하지 않는다.
