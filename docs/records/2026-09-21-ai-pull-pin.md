# AI 고정못 1개 뽑기 — 로컬 실험

## 기준 및 범위
- 작업 브랜치: `codex/ai-team-slots-local`.
- 작업 전 체크포인트: `f9cf66d9` (로컬 모델 명령 연동과 장애물 우회 추종).
- 원격 push / MR / Jira 변경 없음.
- 기존 플레이어·고정못 물리와 씬은 수정하지 않는다. AI가 기존 이동·잡기 입력을 사용한다.

## 실행 흐름
1. 방장이 AI 사용을 켜고 추가팩 준비 완료 후 게임 시작.
2. 개발용 ESC 메뉴에서 동료 선택, `못 뽑아줘` 전송.
3. 로컬 LLM의 `pull_pin` 판단을 선택한 동료에게 전달.
4. 명령한 플레이어 주변 30m 안에서 접근 가능한 빈 고정못을 가까운 순으로 선택.
5. 걸어갈 접근 지점과 손이 닿는 거리, 뒤로 물러날 바닥을 확인.
6. 기존 PlayerRig의 조준/잡기/뒤로 이동 입력으로 실제 고정못을 뽑는다.
7. 한 개 해제하면 완료하고 대기한다. 여러 개 일괄 작업은 아직 지원하지 않는다.

`못 뽑기 직접 테스트` 버튼은 LLM을 건너뛰고 동일 작업을 실행한다. 모델 해석 문제와 게임 동작 문제를 분리하기 위한 개발용 버튼이다. 새 단축키는 추가하지 않았다.

## 중단 및 보호
- 대기/중단/다른 지원 명령을 받으면 기존 작업과 손잡기를 해제한다.
- 못 진행도를 초기화하거나 강제로 완료하지 않는다. 다시 지시하면 기존 진행도부터 이어진다.
- 동료끼리 같은 못을 선택하지 않도록 예약한다. 다른 플레이어가 이미 작업하는 못은 제외한다.
- 손에 도구나 물체가 있으면 자동으로 버리지 않고 작업을 거절한다.
- 대상 소실, 쓰러짐, 탑승, 경로/당기기 진행 정체, 최대 작업시간 초과 시 안전하게 중단한다.
- 텍스트 요청 처리 중 직접 테스트/즉시 중단을 누르면 늦은 LLM 응답이 작업을 덮어쓰지 못하도록 무효화한다.

## 이동 보정
Stage1 단상의 약 25cm 턱을 NavMesh는 걸어 넘을 수 있다고 판단했지만 실제 PlayerRig는 자동 계단 오르기가 없어 걸렸다. 내비게이션의 허용 턱 높이를 25cm에서 5cm로 줄여 경사로 경유를 유도했다. 플레이어 물리/점프/콜라이더는 변경하지 않았다.
못 최종 접근 구간은 느리게 이동하며 장애물 미리보기 거리를 줄인다. 일반 따라오기의 충돌 미리보기 거리는 유지한다.
