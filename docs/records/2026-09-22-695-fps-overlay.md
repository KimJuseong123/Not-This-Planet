# 695 · 로컬 FPS 표시

기준: `396f8765`, 브랜치 `S15P21B202-695-ui-fps`.
워크트리: `.local-worktrees/695-ui-fps`.

## 동작

- 로비 및 ESC 설정의 그래픽 탭에 **FPS 표시** 토글을 추가했다. 기본값은 꺼짐이다.
- 켜면 안전 영역 오른쪽 위에 작은 흰색 `xxx FPS`와 검은 그림자를 표시한다.
- 최근 약 0.5초 동안 실제 프레임 수 / unscaled 경과 시간을 계산한다. 첫 샘플이 모이면 표시하며, 일시정지 시간 배율에 영향을 받지 않는다.
- 기존 설정 흐름대로 즉시 미리보기, 저장, 취소, 기본값 복원을 지원한다. 저장하지 않고 취소하면 원래 상태로 돌아간다.
- 개인 설정 객체에 하나만 연결한다. 로비·외형 선택·게임 진입에서 중복 추가를 막고, 씬 전환 시 기존 설정 객체와 함께 유지된다.
- 꺼짐 상태에서는 컴포넌트를 비활성화해 Update/OnGUI를 실행하지 않는다. 설정 이벤트만 유지해 다시 켤 수 있고, 파괴 시 구독을 해제한다.
- 단축키 바인딩은 추가하지 않았다. 요청한 설정 토글로 조작한다.

## 기존 기능 영향 검토

- `showFps`는 로컬 JSON 표시 설정에만 추가했다. 구버전 파일은 누락 항목을 false로 읽는다. Clone에도 포함해 미리보기/저장 시 값이 유실되지 않는다.
- Mirror 메시지·플레이어 프리팹·네트워크 권한 변경 없음. 다른 플레이어에게 FPS나 토글 상태를 전송하지 않는다.
- 프레임 제한·vSync·시간 배율·카메라·입력 바인딩을 변경하지 않는다. 기존 설정 적용 경로를 사용한다.
- GUI는 Repaint에서만 읽기 전용 Label을 그린다. 클릭 이벤트를 소비하지 않으며 GUI 색/깊이/배율을 복원한다.
- UI 텍스트 배율과 화면 안전 영역을 따른다. 현재 팀 HUD는 왼쪽 위, FPS는 오른쪽 위다.
- 매 프레임은 숫자 누적만 수행하고 문자열 생성은 샘플 갱신 때로 제한했다. 반복 객체 검색·파일 I/O·네트워크 호출 없음.
- 배치모드/그래픽 장치 없는 실행에서는 오버레이를 설치하지 않는다.
- 씬·프리팹·패키지·프로젝트 설정 변경 없음. 별도 Inspector 연결 필요 없음.

## 검증

Unity 6000.5.4f1의 별도 검사 프로젝트에 브랜치 소스와 필요한 기존 에셋을 복사했다. 원본 프로젝트의 패키지 캐시를 읽기 전용 참조했다. 사용자의 화면이나 실행 중인 에디터를 조작하지 않았다.

검사 범위: `GameSettingsTests`, `FpsCounterTests`, `FpsOverlayTests`, `KeyGuideHolderTests`.
최종 실행: **28/28 통과**, C# 컴파일 성공. FPS 계산 9개, 설정 14개, 오버레이 수명/미리보기 통합 1개, 기존 키 안내 4개.

`FpsOverlayTests`는 Play Mode에 진입해 임시 설정 파일로 미리보기·취소·저장·초기화·반복 토글·구독 해제를 검사한다. FPS 표시 토글이 기존 프레임 제한과 vSync 설정을 보존하는지, timeScale=0에서도 실제 Update가 샘플을 생성하는지, 끄면 샘플을 초기화하는지도 확인했다.

초기 샌드박스 실행은 라이선스 IPC 접근에 실패했다. 해당 검사 프로세스만 종료한 후 승인된 배치 실행으로 완료했다. 기존 코드의 obsolete API 및 Mirror Weaver 의존성 경고가 있으며 이 작업의 신규 FPS 코드 컴파일 오류는 없다.

최종 검사 결과와 로그: `tmp/fps-validation/final-results.xml`, `tmp/fps-validation/final-unity.log`.
검사 프로젝트 준비 스크립트: `tmp/fps-validation/prepare.py` (로컬 검사 산출물, Git 제외).

## 남은 검증 범위

전체 플레이어 빌드, 실제 다인 접속, 화면 렌더링/해상도별 시각 검수 및 GPU 성능 측정은 하지 않았다. 이 변경이 실제 게임의 목표 FPS를 보장한다는 의미는 아니다. 실제 플레이 시 그래픽 설정에서 FPS 표시를 켜고 저장하면 현재 렌더 프레임률을 확인할 수 있다.
