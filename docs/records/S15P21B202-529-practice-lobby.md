# 우주선 연습 로비

## 목적

실제 게임의 조작을 작은 장난감 같은 대상으로 연습한다. 별도의 가짜 용접·타격·고정못 판정을 만들지 않는다.

## 범위

- develop 74f7116에서 분기. 태블릿 MR 코드는 포함하지 않는다.
- 새 씬: `METAGAME/Assets/Scenes/PracticeLobby.unity`.
- Stage1_Astra에 실제 배치된 몽둥이·용접건·고정못 객체(씬 설정 포함)를 복제. 원본 씬/에셋 수정 없음.
- 둥근 선실, 좌석 4개, 우주 창문, 샌드백, 미니 로켓 용접 작업대, 고정 화물, 작은 운반 화물.
- Stage1과 동일한 SpaceBootstrap 재사용. 별도의 PlayerRig/GameSession/FirstPersonHandView 생성 코드는 제거했다. 손의 위치·각도·크기와 오디오 설정도 Stage1 씬의 값을 가져온다. GameHud, 태블릿, 견인 컨트롤러, 맵 복구 등 공통 초기화 경로가 그대로 실행된다.
- 실내 중력만 SpaceBootstrap.gravity=(0,-9.81,0). Stage1 진입 시 Stage1의 -5 중력이 다시 적용된다. 물리 상수나 도구 조작/판정 코드는 수정하지 않는다.
- 야외 지형 자동 생성 및 야외 폭풍/하늘 효과는 로비에 배치하지 않는다. 훈련 대상과 실내 조명만 별도이며, 3인칭/1인칭 도구의 동작과 고정못 조작 규칙은 동일하다.
- 실제 파츠는 기존 SpaceshipPart 규칙을 그대로 사용하므로 일반 작은 화물처럼 손에 들리지 않는다. 손으로 집는 연습은 별도의 가벼운 화물로 한다.
- 메뉴의 `우주선 연습실`로 입장하거나 씬을 직접 Play. 출발 카펫 안에 3초 머물면 기존 혼자 하기 경로로 Stage1에 진입한다.
- 시작 좌석 옆 RESET 콘솔 근처에서 현재 상호작용 키(기본 E)를 누르면 연습실 전체가 초기화된다. 도구·용접·고정못·플레이어 위치 모두 초기화됨을 안내한다.

## 의도적으로 제외

- 아직 혼자 연습 전용이다. 기존 방 생성·참가와 Mirror 온라인 씬 설정은 바꾸지 않는다.
- 함께 입장, 전원 준비, 다인 출발 및 재접속은 별도 네트워크 작업이 필요하다.
- 운석 피격 컷신은 아직 없다. 출발은 기존 fade/loading 전환을 사용한다.
- 유료 생성 서비스 및 신규 패키지 설치 없음.

## Stage1 실행 구조로 수정한 뒤 검증

- `PracticeLobbyBootstrap`은 연습 안내·초기화·출발 연결만 담당한다. 플레이어/입력/손/도구/HUD/태블릿 생성은 Stage1의 `SpaceBootstrap`에 맡겼다.
- Stage1에 저장된 손 설정의 전체 JSON, 도구/못의 수치 설정, 자식 구조·메시·콜라이더·월드 크기 동일성 검사 통과. 복제된 씬 객체의 참조 ID는 서로 달라야 하므로 설정 비교에서 제외한다.
- 실제 캐릭터 키에 맞춰 작업대 높이를 0.28m로 낮추고 도구를 그 위에 다시 배치했다. 매달린 공과 미니 로켓도 접근 가능한 높이로 조정했다. 도구/못 자체의 크기·잡기 거리·조인트·조작 규칙은 바꾸지 않았다.
- `parity-gameclock.xml`: PracticeLobbyTests 7/7 통과. 실제 PlayerRig 입력으로 도구 집기, 클릭 스윙/용접 모드, 고정못 클릭 유지 후 뒤로 당기기, 태블릿 열기/닫기, 초기화, Stage1 진입 및 -5 중력 복귀를 확인했다. 용접 비드 생성·절단과 샌드백 타격은 별도의 실제 API 검사도 포함한다.
- EditMode에서 EnterPlayMode 이후 `WaitForSeconds`가 필요한 게임 시간을 기다리지 않는 문제가 있어 `Time.time`을 확인하며 프레임을 기다리도록 검사를 수정했다. 초기 시안 검증보다 이 검증을 우선한다.
- `stage1-final-regression.xml`: 확장 91개 중 81개 통과, 10개 실패. 이 결과를 전체 통과로 간주하지 않는다.
  - 미변경 `ClampPullTests` 8개: 오래된 테스트 배치에서 잡기에 실패한다. 테스트는 못 중심에서 플레이어를 1.2m 떨어뜨리고, 현재 PlayerRig는 실제 표면에서 골반까지 0.72m로 제한한다. 기준 develop을 별도 실행한 결과는 없으며, 테스트/런타임 파일에 이 브랜치의 수정이 없음을 확인했다.
  - 미변경 `PartClampTests.Pull_TakesThePlannedTime` 1개: 위에 기록한 4.5초 기대값 불일치.
  - 실제 입력 검사 1개: 동작 검사가 끝난 뒤 Play 종료 시 `WeldingJointGuide.Hide()`에서 이미 파괴된 root를 참조하는 예외. 공용 용접 코드의 종료 순서 문제이며 이 작업에서 수정하지 않았다. 최종 입력 검사에서는 자신이 사용한 도구를 가이드보다 먼저 정리한다. 이는 테스트 정리 순서만 조절한 것이며, 제품의 씬 종료 문제를 해결했다는 의미는 아니다.
- 새 씬의 1인칭 몽둥이/용접건 보유 시점을 캡처했다. OnGUI는 캡처되지 않는다. 2인 시점 비교, 수동 마우스 QA, 실행 파일 빌드는 아직 미검증이다.
- 최종 `lobby-tool-final.xml`: `PracticeLobbyTests;FirstPersonHandViewTests;FirstPersonToolVisualTests;ToolCarryCollisionTests;MeteorBatTests` 63/63 통과. 위의 기존 고정못 테스트 28개는 이 최종 필터에 포함하지 않았으며, 실패 9개를 해결한 것으로 취급하지 않는다.
- 기존 Stage1 씬/공용 Gameplay/SpaceBootstrap/기존 프리팹의 실제 내용 변경 없음. 별도 물리/입력 패치나 신규 패키지는 추가하지 않았다.
