# 탑승 중 반중력 빔 가시성 보정

사용자 확인: 하차 후가 아니라 탑승 중 클릭으로 장을 켜도 VFX가 보이지 않음.

코드 조사에서 충돌체 변경은 빔 생성/표시 경로를 변경하지 않았고, 빔은 Visual과
별도 계층에 있어 선체 렌더러 숨김의 대상도 아니었다. 다음 렌더링 취약점을 보정했다.

- 원뿔 표면을 비스듬히 보는 경우 투명도가 0까지 내려갔다. 기체 위에서 아래를 보는
  조종석 시점은 원뿔 벽과 거의 평행해 이 조건에 해당할 수 있다. 각도별 계수 하한을 0.4로 변경.
- 전체 화면 대기 합성이 빔을 덮었다. 기존 행성/운석 경고와 같은 stencil bit 64로 제외한다.
  완전히 희미해진 픽셀은 discard하여 제외 마스크를 남기지 않는다. 이 방식은 다른
  투명 경고 효과와 마찬가지로 빔이 그려진 픽셀의 배경 안개에도 영향을 준다.
- 깊이 텍스처 미제공 시 near-plane 기본값으로 전체 투명도가 0이 될 수 있어
  해당 값에서는 접촉 페이드만 생략한다. 기본 깊이 검사는 유지한다.
- 셰이더 리소스를 못 찾으면 조용히 종료하지 않고 원인을 로그에 남긴다.

효과 토글·재활성화와 기체 회전에도 빔이 월드 아래 방향을 유지하는 테스트를 추가했다.
Gameplay와 테스트 어셈블리의 Roslyn 컴파일 오류는 각각 0이다.
화면 조작은 하지 않았고 GPU 셰이더 컴파일/실제 외관/테스트 실행은 미검증이므로,
위 사항은 코드에서 확인한 취약점이며 사용자 증상의 확정된 재현 원인으로 단정하지 않는다.
