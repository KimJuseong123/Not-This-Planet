## 목적
확정된 워크플로우(Jira 이슈 → 브랜치 → MR → develop 머지)와 자동화 규칙 R1·R2·R4·R5·R6·R7·R8·R9가 실제 이벤트에서 계획대로 동작하는지 처음부터 끝까지 검증한다.

## 한 일
- A. 잘못된 제목·빈 설명으로 이슈 생성 → R1 설명 템플릿 삽입 ✅ · R2 `needs-fix` + 멘션 댓글 ✅ (생성 시 발동 확인)
- B. 제목을 `[Infra] …`로 수정 → R2 `needs-fix` 제거 + `Infra` 레이블 ✅
- C. 활성 스프린트 배정 → R8 기한 자동 채움 ⚠ 미동작 (감사 로그 확인 필요)
- D. 카드를 손으로 진행 중으로 → R5 6초 내 `해야 할 일`로 되돌림 + 댓글 ✅
- E. 이슈 키 브랜치 push → R4 진행 중 전환
- F. 이 기록 파일 커밋 → MR 생성 → 개발 패널 연결
- G. 카드를 손으로 완료로 → R9 되돌림
- H. MR 머지 없이 닫기 → R7 댓글 → 다시 열기
- I. 팀장 머지 → R6 완료 (팀장 필요)
