## 목적

가까운 작업 공간은 선명하게 유지하고 먼 절벽의 대비를 낮춰 거리감을 만든다.
기본 거리 안개 비교에서 시작해, 현재는 Stage1_Astra 실행 시 자동 적용되는 공간 밀도 적분 안개를 포함한다. 아래 '한 일'과 추가 기록은 작업 순서에 따른 이력이다.

## 현재 버전 실행 방법 (공유용)

1. 이 브랜치의 METAGAME 프로젝트를 Unity 6000.5.4f1로 연다.
2. Assets/Scenes/Stage1_Astra.unity를 열고 Play한다.
3. 별도 버튼 없이 거리 안개와 공간 안개가 자동 적용된다. Windows 빌드에도 같은 코드와 씬의 셰이더 참조가 포함된다.
4. 선택 사항: Metagame > Rendering > Fog Compare에서 토글/슬라이더 및 1/2/3 버튼으로 비교한다. 슬라이더 값은 세션 내에서만 유효하다.
5. Play/씬 종료 시 유도 빛 재질 참조와 기본 안개를 복원하고 생성한 재질을 해제한다. 런타임 파이프라인 복제는 더 이상 하지 않는다.

PC/Mobile 렌더러에 Stage1FogRendererFeature를 등록하되 Stage1_Astra의 Stage1FogController가 활성 상태일 때만 패스를 실행한다. 서버처럼 그래픽 장치가 없는 환경에서는 초기화하지 않는다. 안개판 실험은 폐기했으며 현재 소스는 안개 오브젝트를 생성하지 않는다. 검증 PNG/로컬 로그/검증용 실행 파일은 저장소에 포함하지 않는다.

### 빌드 자동 적용 검증 (2026-09-11)

- runtime/Gameplay의 Stage1FogController와 Stage1FogRendererFeature가 실제 기능을 소유하고, Editor의 비교 창은 동일 컨트롤러를 조절한다. 직렬화된 셰이더/유도등 4개 참조를 씬에 추가했다.
- fog-runtime-play.log: 비교 창 호출 전 자동 활성화 AUTO PLAY PASS, 플레이 카메라 렌더, 세 모드 전환 및 자원 정리, Main/Lobby 비활성 확인 통과. runtime-auto-play.png를 직접 확인했다.
- fog-runtime-build.log: Unity 6000.5.4f1 Windows64 Development 플레이어 빌드 성공, Stage1DistanceFog 셰이더 직렬화/포함 확인. 출력은 저장소 밖이 아닌 저장소 루트의 비추적 fog-build-smoke 폴더이며 git에 추가하지 않는다. 전체 릴리스 빌드가 아닌 Stage1_Astra 단일 씬 검증 빌드다.
- 생성된 실행 파일의 직접 조작/성능·모바일 기기 검증은 미수행이다. 빌드 과정의 공용 설정 자동 변경은 검증 후 되돌렸다. MR은 생성하지 않았다.

## 한 일

- Stage1_Astra RenderSettings: ExponentialSquared → Linear.
- 색상: RGB (0.085, 0.078, 0.17) → (0.19, 0.22, 0.34).
- 최초 시작 거리 30, 종료 거리 160에서 차이가 약하다는 사용자 피드백을 받아 15 / 90으로 강화했다. Linear에서는 기존 Density 값이 사용되지 않는다.
- Metagame > Rendering > Fog Compare에 Play 전용 ON/OFF 비교 창을 추가했다. 현재 열린 씬에 강화 설정을 임시 적용하는 버튼도 제공한다. 빌드에는 포함되지 않는다.
- 기존 Concept Mineral Ground 셰이더의 ComputeFogFactor/MixFog 지원을 확인했다. 셰이더는 수정하지 않았다.
- Main/Lobby, 공용 물리·견인·네트워크, 패키지 및 프로젝트 설정은 변경하지 않는다.
- 사용자가 이 브랜치의 씬 작업 시작을 승인했다. 팀 채널 공유 링크는 별도 확인 필요.

## 직접 조정하는 방법

1. Assets/Scenes/Stage1_Astra.unity를 연다.
2. Window > Rendering > Lighting의 Environment에서 Other Settings > Fog를 확인한다.
3. Mode = Linear. Start를 높이면 가까운 곳이 더 선명해지고, End를 높이면 전체 안개가 약해진다.
4. 같은 플레이 카메라와 위치에서 비교한다. 씬을 저장해야 다른 실행에도 반영된다.

## 검증

- 배치 전용 Stage1FogValidation.Run으로 컴파일, 적용 전후 렌더, Play Mode 초기화 후 설정 유지 및 다른 씬 로드 후 설정 복원을 검사한다.
- 실행 인자: -batchmode -projectPath <METAGAME> -executeMethod Metagame.EditorTools.Stage1FogValidation.Run -stage1-fog-validation -logFile <로그 경로>
- 검증 이미지는 프로젝트 외부 ../fog-validation에 생성한다. 검증 도구는 씬이나 공용 설정을 저장하지 않는다.
- Unity 6000.5.4f1 컴파일 및 배치 검증 완료. 4개 파츠·1개 Bootstrap·기존 견인 활성화 컴포넌트·누락 스크립트 없음 확인.
- Play Mode 진입 후 안개 설정 유지, 실제 플레이 카메라 렌더 확인. 지상·전체 조감도·플레이 카메라의 전후 이미지 총 6장 생성.
- Main 로드 시 ExponentialSquared / 0–300, Lobby 로드 시 Fog 비활성으로 원래 씬 값 복원. Astra 재로드 시 Linear / 30–160 복원 확인.
- 기존 403 검증에서도 관찰된 UnityEditor.Search.SearchDatabase 내부 ArgumentOutOfRangeException이 이번 새 폴더 초기화에서도 발생했다. 안개 관련 컴파일·런타임 오류는 확인되지 않았고 검증은 정상 완료됐다.
- 플레이어 빌드나 실제 로비 게임 전환을 끝까지 실행한 검증은 아니며, 다른 씬 설정 복원은 Play 종료 후 에디터 씬 로드로 확인했다.

## 남은 것 / 후속

- 15 / 90 강화 버전과 비교 창은 사용자 에디터가 열려 있고 MCP가 응답하지 않아 실시간 컴파일·버튼 검증은 아직 수행하지 못했다. 위의 검증 결과는 최초 30 / 160 설정 기준이다.
- 실제 밝기·안개 강도에 대한 사용자 시각 확인.
- 플레이어 빌드 및 다중 클라이언트 성능 측정은 이번 에디터 시각 검증에 포함하지 않는다.
- 커밋·push·MR은 별도 요청 시 수행한다.

## 셰이더 비교 실험 (사용자 후속 요청)

- 재질·조명·맵 디자인 변경 없이 안개만 비교한다. 기존 Haze RenderGraph 구조를 참고하되 공용 Haze.shader 및 AtmosphereController는 변경하지 않는다.
- Stage1DistanceFog.shader: 화면 깊이로 거리를 읽고, 부드러운 시작 곡선과 최대 불투명도 제한을 적용한다. 초기값 12–85m / 최대 0.4 / 청보라색이다. 색상 입력은 sRGB에서 linear로 변환한다.
- 기본 안개와 중복 적용하지 않는다. 원래 명암의 최소 60%가 혼합 이전 단계에서 남지만, 명암 보존이나 물리적 볼류메트릭 산란을 보장하는 효과는 아니다.
- 하늘 깊이를 제외하고 기존 atmosphere-exempt stencil bit 64를 실제 depth/stencil attachment로 검사한다. 투명 효과 렌더 이전에 적용하므로 투명 빔은 후처리 안개에 덮이지 않는다. 거리 안개가 적용되지 않는 투명 재질은 경계에서 차이가 날 수 있다.
- 비교 창: Metagame > Rendering > Fog Compare. Play 중 1 없음 / 2 기존 기본 안개 / 3 셰이더 안개 선택. 시작·끝·최대 강도·색상을 실시간 조절한다.
- Editor-only Stage1FogTestSession이 활성 URP와 renderer data를 메모리에서 복제한다. 원본 에셋 저장이나 렌더링 경로 전환은 하지 않는다. Play 종료·도메인 리로드·씬 변경 때 복원 및 해제한다.
- 아직 플레이어 빌드에 연결한 기능이 아니라 에디터 비교 실험이다. 승인된 모양을 정한 다음 런타임 씬 전용 연결을 별도로 정리한다.
- 배치 TestShader 검증: 세 모드 렌더링, 셰이더 오류 없음, 원래 파이프라인·안개 복원 통과. 결과: fog-validation/shader-test-0.png, -1.png, -2.png.
- Play 비교 검증 통과: 실제 플레이 카메라에서 세 모드 렌더링, 테스트 종료 복원, Main/Lobby 설정 복원 및 Astra 재로드 확인. fog-shader-play.log에 SHADER PLAY PASS / VALIDATION COMPLETE 기록. 이번 실행에서 C#·셰이더 오류 및 예외 로그 없음. 비교 창 버튼의 직접 클릭 검증과 플레이어 빌드 성능 측정은 미수행.

### 원근감 강화 튜닝

- 사용자 요청에 따라 셰이더 추천값을 10–65m, 최대 강도 0.65, 색상 sRGB (0.27, 0.32, 0.43)으로 강화했다.
- 거리에 따른 채도 감소 0.7을 추가했다. 보라·분홍 계열은 RGB 기반의 부드러운 마스크로 추가 감소한다. 10m 이내는 이 효과가 0이며 원본 재질은 수정하지 않는다.
- 비교 창의 '추천값 · 원근감 강화' 버튼으로 새 값을 명시적으로 적용할 수 있다. '먼 곳 채도 낮추기' 슬라이더로 조절한다.
- 기존 stencil 제외 대상인 배경 행성·마커와 투명 효과는 계속 제외된다. 이들의 색을 바꾸는 작업은 포함하지 않는다.
- 이번 튜닝 시 사용자의 Unity 에디터가 열려 있어 강제 종료하지 않았다. 이 변경의 컴파일·시각 재검증은 미수행이며, 위 PASS는 이전 셰이더 버전에 대한 결과다.

### 가까운 거리 및 수직 유도 빛 보호

- 추천값을 5–55m로 변경했다. 최대 강도 0.65와 거리 채도 감소 0.7은 유지한다. 5m 이내는 거리 효과가 없다.
- 씬의 Module beacon 3개와 02 Tractor sky beacon은 불투명 재질이라 기존 투명 효과 제외만으로 보호되지 않는다. 테스트 세션에서 해당 렌더러의 재질만 메모리에 복제하고 셰이더 모드에서 렌더 큐를 Transparent로 옮겨 안개 이후 그린다. 원래 셰이더, 색, 깊이 검사는 유지하므로 벽을 투시하는 표시로 만들지 않는다.
- 안개 없음/기본 안개 모드에서는 원래 큐, 세션 종료에는 원래 재질 참조로 복원한다. 원본 씬·재질 파일은 이번 변경에서 수정하지 않았다.
- Unity가 열려 있어 이번 변경의 컴파일 및 실제 렌더 결과는 아직 검증하지 않았다. 비교 창의 추천값 버튼으로 적용해야 한다.

### 지면의 몽환적인 안개 실험

- 기존 거리 안개에 별도 지면 안개를 추가했다. 깊이에서 월드 위치를 복원하고 카메라~표면 구간 최대 80m를 8회 샘플링한다. 월드 Y 0~3m 부근의 부드러운 높이 마스크와 천천히 이동하는 2D 노이즈로 낮은 안개층을 표현한다.
- 추천 강도 0.22, 흐름 속도 0.12. Fog Compare의 '추천값 · 옅은 몽환 안개' 버튼 및 별도 토글/강도/바닥 높이/두께/속도 슬라이더로 비교한다. 지형을 따라가는 안개가 아니라 고정 월드 높이의 저지대 안개다.
- 광원 산란이나 그림자까지 계산하는 완전한 볼류메트릭 시스템은 아니다. 투명 효과·유도 빛과 하늘 제외는 유지한다. 추가 패키지, 유료 에셋, 씬 저장은 없다.
- Unity가 사용 중이므로 강제 종료나 Play 초기화 없이 소스만 반영했다. 이번 셰이더의 컴파일, 시각 품질, GPU 성능은 미검증이다. 이전 PASS 로그를 이번 변경의 검증으로 간주하지 않는다.

### 국소 안개 띠로 교체

- 사용자 스크린샷에서 기존 높이 안개가 구분되지 않아, 해당 fullscreen 높이 레이어를 비활성화하고 별도 투명 안개 띠 12개로 대체했다. 거리 안개는 유지한다.
- Stage1MistPatch.shader: 카메라 방향의 수직 빌보드, 움직이는 절차적 노이즈, 부드러운 가장자리/깊이 접합, 근접 페이드, stencil 유도 빛 보호. 별도 텍스처/패키지 없이 메모리상의 메쉬와 재질을 공유한다.
- 중앙을 비운 고정 XZ 지점에서 Basin 콜라이더에 레이캐스트하여 바닥을 찾는다. 슬라이더 높이는 월드 높이 대신 바닥 기준 보정이다. 전체 지형이나 장식과의 최종 배치는 시각 검증이 필요하다.
- 비교 세션에서만 생성, 다른 안개 모드에서는 비활성화, Play/씬 종료 시 해제한다. 원본 씬·재질 저장 없음. 이번 변경도 Unity 사용 중이라 컴파일/시각 검증은 아직 미완료.

### 안개판 폐기 / 공간 밀도 적분으로 변경

- 사용자에게 근접 통과 시 판/덩어리처럼 보이는 문제가 확인되어 MistPatch 생성 코드와 실험용 셰이더·메타를 삭제했다. 임시 안개 오브젝트는 더 이상 생성하지 않는다.
