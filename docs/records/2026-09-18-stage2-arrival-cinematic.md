# Stage1 엔딩 → 지구 불시착 컷씬

사용자 요청: 1장 엔딩에서 완성한 우주선이 우주를 유영하다 운석에 맞아 파손되고 가장 가까운 2장 행성에 불시착한 뒤 Stage2_Earth를 시작한다.

## 재생 순서

기존 인사·탑승·발사·기념사진을 유지하고 완료 문구를 '1장 완료'로 바꿨다. 이후 다음 23초 연출을 재생한다.

| 추가 컷씬 시간 | 장면 |
| --- | --- |
| 0~8초 | 실제 조립된 우주선의 무중력 유영. 지구가 보이고 5.4초부터 화면 밖의 운석이 접근 |
| 8~14초 | 운석 충돌, 섬광·충격음·카메라 흔들림. 조립 파츠가 분리·회전하고 선체 파편 52개가 확산 |
| 14~23초 | 가장 가까운 행성인 지구로 비상 강하. 지구 확대, 재진입 화염·경보, 충돌 섬광과 암전 후 Stage2_Earth 시작 |

자막과 레터박스를 추가했다. 충격음·경보음은 런타임 PCM 합성으로 생성하며 외부 오디오 파일이나 패키지가 필요하지 않다. 이번 연출은 실시간 메시 기반 초안이며 영화급 파괴 시뮬레이션이나 녹화 영상은 아니다.

## 실제 조립 상태 보존

기존 DemoEndingView가 서버 스냅샷에서 만든 `Completed Ship`을 그대로 사용한다. 각 파츠의 상대 위치·회전·크기와 용접 비드를 유지한 채 우주선 전체를 화면에 맞춰 배치하고, 충돌 이후에만 각 파츠를 분리한다. 게임플레이 Rigidbody나 NetworkIdentity를 복제하지 않는다.

## 동기화와 전환

새 씬을 추가로 로드하지 않고 기존 Stage1_Ending의 공통 시간축을 연장했다. 시작 시각은 기존 `NetworkTime`/서버 준비 완료 절차로 확정된다. 모든 파손·카메라·낙하 자세는 경과 시간의 함수이며 프레임별 물리 적분을 쓰지 않는다. 늦게 들어온 클라이언트도 현재 시점의 모습을 직접 복원한다.

`DemoEnding.Finished`는 불시착 연출 끝에서만 참이다. `EndingSceneFlow.ContinueToStage2`도 완료 전 호출을 거부하며 씬 전환은 호스트/서버만 결정한다. 기존 준비 타임아웃·끊김 처리·자동 플레이어 생성 억제를 유지한다. 솔로 전체 엔딩은 44초, 4인 전체 엔딩은 50초다.

## 검증 자료

최종 관련 자동 테스트 **53개 통과 / 실패 0개**. 전용 렌더 5개 시점을 확인하고 지구 표면을 대륙·바다·극지·구름 무늬로 보완했다.

[컷씬 검수 자료](../../artifacts/stage2-arrival/README.md)를 참고한다. 1~4인 단계 시간, 실제 스냅샷 상대 배치, 충돌 후 분리, 같은 경과 시간의 파편 위치 재현, 조기 씬 전환 차단 및 Stage2 게임플레이 진입을 검사한다. 실제 다중 PC의 네트워크 지연·재접속 실측은 별도이며 공통 시각의 재생·복원 검증과 구분한다.
