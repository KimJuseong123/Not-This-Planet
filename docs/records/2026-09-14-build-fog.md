# 빌드에서 Fog 누락

## 증상과 근거

- 사용자 확인: 에디터 싱글은 정상, 빌드에서는 싱글과 멀티(방장·참가자) 모두 Fog가 보이지 않음.
- Unity 6000.5.4f1 / URP 17.5.0.
- Main 및 Stage1_Astra의 저장된 RenderSettings는 FogMode 3(ExponentialSquared).
- Stage1AtmosphereProfile은 실행 중 FogMode 1(Linear), 거리 10~60을 적용한다. Haze와 Ground Fog는 비활성화되어 있다.
- GraphicsSettings의 Fog stripping은 Automatic이었다. 씬에 저장되지 않은 런타임 Linear 변형이 빌드에서 제거될 수 있다.
- URP Config의 USE_DYNAMIC_BRANCH_FOG_KEYWORD는 0으로 Fog 키워드 변형을 사용한다.

## 수정

GraphicsSettings.asset의 m_FogStripping을 0(Automatic)에서 1(Custom)로 변경했다. 기존 Keep Linear / Exp / Exp2 활성 설정을 유지하여 런타임 Fog 변형을 보존한다. Fog 거리, 색상, 네트워크 및 카메라 코드는 변경하지 않았다.

## 검증 및 남은 확인

- 설정 diff와 세 Fog 모드 보존 값을 확인했다.
- 실행 중인 Unity Editor가 있으며, 이 조사에서는 새 플레이어 빌드나 시각 재현을 수행하지 않았다. 셰이더 제거는 증상과 설정으로 강하게 지지되는 원인이지만 최종 확인은 재빌드 후 필요하다.
- 기존 실행 파일에는 수정이 반영되지 않는다. 동일 소스에서 클라이언트를 다시 빌드한다.
- 새 빌드의 싱글에서 같은 위치·방향으로 에디터와 비교한다. 선형 Fog가 10~60 거리에서 적용되는지 확인한다.
- 같은 새 빌드로 멀티 방장과 참가자를 실행해 각각 확인한다. 로비 복귀 후 재입장도 확인한다.
- 여전히 실패하면 실행 시 RenderSettings.fog, fogMode, fogStartDistance, fogEndDistance와 해당 재질의 Fog 셰이더 변형을 확인한다.
