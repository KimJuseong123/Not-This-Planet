# AI 자연어 대상 선택과 사회적 반응

## 실행 흐름

ESC 텍스트 입력 → 로컬 Qwen3 1.7B → `{action, recipients, approach}` → 호스트의 대상/상태 검증 → 필요 시 이동 → 방향 전환 → 행동.

- `춤춰봐`: 선택된 동료가 제자리에서 요청자를 바라본 뒤 춤.
- `다들 이리 와서 인사해`: AI 전원에게 서로 다른 도착 지점 배정 → 접근 → 요청자를 보고 오른손 흔들기.
- `파랑아 내 앞으로 와서 춤춰`: 파랑 AI만 접근 후 춤. 파랑이 사람이거나 없으면 다른 AI로 대체하지 않는다.
- `둘이 나 따라와`: 빈 동료 최대 두 명. 작업 중인 동료는 자동 배정하지 않는다.
- `다들 모여`: 명령 당시 위치 주변에 모인 다음 요청자를 바라본다.
- `초록아 하트 해줘`, `노랑아 따봉`: 제자리에서 방향 전환 후 기존 이모티콘.

문장에 대상이 없으면 메뉴의 선택을 사용한다. 문장에 전원/인원수/색상 이름이 있으면 문장의 지시가 우선이다. 임의 닉네임과 서로 다른 여러 행동을 한 문장에 배정하는 것은 지원 범위가 아니다.

## 안전/상태

- LLM은 행동 선택만 한다. 사람 캐릭터/좌표/물리/임의 코드를 제어하지 않는다.
- 요청 전 AI 객체 및 명령 순번을 저장한다. 응답을 기다리는 동안 사람이 들어오거나 새 명령이 내려오면 이전 응답이 그 자리를 덮어쓰지 않는다.
- 인사/춤은 작업 중인 AI나 물건을 잡은 AI에게 강제하지 않는다. 먼저 중단해야 한다.
- 접근 경로를 찾지 못하면 실행하지 않는다. 접근 중 실패하면 행동을 취소한다.
- 인사는 메시 본만 움직이며 잡기 입력이나 실제 팔 콜라이더를 움직이지 않는다. 시작 시각/활성 상태는 서버가 동기화한다.
- 춤은 기존 클립과 네트워크 이벤트 사용. 방향 전환이 끝나기 전에 춤을 시작하지 않는다.
- 금지 표현(`~지 마`, `~지 말…`, `하면 안 돼`)은 모델 오판으로 금지된 행동을 실행하지 않도록 중단으로 강제한다. `raw_decision`과 `safety_override`로 모델 원본과 안전 보정을 구분한다. 따라서 모든 결과가 LLM 단독 결과라는 뜻은 아니다.

## 실행팩

- 새 엔드포인트 `/api/companion-social/text`, health의 `command_schema=social-v1` 필요. 구형 실행팩을 준비 완료로 오인하지 않는다.
- 기존 v4 실험 API/프롬프트는 보존했다. 새 게임 분류기는 현재 게임에서 실행 가능한 명령만 제공한다.
- 프로젝트의 `artifacts/ai-pack/p3`를 최종 실행팩으로 교체했다. 기존 것은 `artifacts/ai-pack/p3-before-social-20260921`에 보존.
- 로컬 모델 재사용. 외부 API, 새 모델 다운로드, 결제 없음. 실행기/모델 ZIP와 manifest도 다시 생성했다.
- 배포 빌드는 별도로 만들어야 한다. 다른 PC의 기존 `AI/p3`는 새 실행팩으로 업데이트해야 하며, Unity 코드 변경만으로 기존 EXE가 갱신되지는 않는다.

## 검증

- Python 단위 검사 22개 통과.
- 실제 최종 EXE의 개발용 예시 16개: 안전 보정을 포함하면 16/16, 보정 전 LLM 단독은 15/16. 이 예시들은 프롬프트 개발에 사용했으므로 일반화 정확도 측정치가 아니다.
- 결과: `tools/AICompanionService/results/social-final.json` (로컬 검사 결과, Git 제외).
- 첫 분류 약 6.9초, 이후 약 1.2초 수준. 이 PC의 CPU 실측이며 게임 동시 부하/다른 PC의 보장은 아니다.
- Unity 기존 못/이동 복구/춤 관련 44개 통과. 새 그룹 행동 검사는 `METAGAME/Logs/ai-social-v10.xml` 통과(방향 전환/춤 중단/모이기/접근 후 인사/인간 대상 제외 포함).
- `METAGAME/Logs/ai-social-final.xml`: 최종 실행팩+Unity 회귀 57/57 통과, 건너뜀 0. 실제 `SendText("춤춰봐")` → 로컬 LLM → 서버 AI 춤 재생과 기존 따라오기/중단/못 명령 연결을 확인했다. 기존 별도 44개와 합쳐 관련 Unity 검사 101개 통과.
- 두 PC 관찰 화면과 손 흔들기 외형의 시각적 QA, 새 배포 빌드는 아직 하지 않았다.

기존 `2026-09-21-ai-group-orders.md`의 ‘새 행동 자연어 미연결’ 상태를 이번 작업으로 대체한다. 음성 입력(STT) 연결은 이번 범위가 아니다.
