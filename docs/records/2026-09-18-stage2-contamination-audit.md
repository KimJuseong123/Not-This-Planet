# Stage2 오염·제독 기획 대조

기준: [2장 기획 §10](../planning/chapter-2-plan.md#section-10), Terrain 적용 커밋 `cc082287`, Unity 6000.5.4f1.

현재 위협은 **유독 가스에 의한 우주복 표면 오염**이다. 방사선 피폭·내부 중독 수치는 따로 구현하지 않았고, 방독면은 기획의 선택 아이디어로 남아 있다. 필터 모델이 씬에 있다는 이유로 보호 효과가 생기지는 않는다.

## 규칙 대조

| 항목 | 실제 구현 / 검증 대상 |
| --- | --- |
| 초반 안전 | 첫 로켓 모듈의 볼트 3개 체결 완료 전에는 가스 비활성 |
| 간헐적 누출 | 40초 주기: 0~6초 예고, 6~23초 누출, 23~40초 휴지기 |
| 공간·층 구분 | 하부 `(16,3.5,10)`, 크기 `9×7×12`; 상부 `(10,7,9)`, 크기 `8×4×8`. 겹쳐도 이중 누적하지 않음 |
| 누적 | 2명 이상 연속 노출 55초에 100%. 솔로 90초는 기존 초안 완화값이며 기획의 45~60초 가설과 구분 |
| 이탈 | 누적만 멈추며 기존 오염은 자연 감소하지 않음 |
| 행동 불능 | 오염 100%에서 기절. 제독은 오염만 제거하고 물리 피해·기절을 치료하지 않음 |
| 동료 분사 | 사거리 12m, 중심선 기준 12도, 초당 18% 제거. 벽 차단·자기 제독 제외. 위층 사선 허용 |
| 고정 샤워 | 발 기준 반경 2m 이내 초당 22% 제거. 솔로 제독 대안 |
| 멀티 | 오염 판정은 호스트, 플레이어별 오염·도구·분사 시작/끝·기절 상태를 전체 스냅샷에 포함 |

40초 중 실제 누출은 17초이므로 한 곳에 서 있어도 벽시계 55초 만에 기절하는 것은 아니다. 55초는 **실제 누출에 노출된 누적 시간**이다. 두 구역 밖과 누출 휴지기에는 가스 피해가 없다.

## 발견 사항

시작 지점 반경 3m 안에 들어오면 매 시뮬레이션마다 오염을 0으로 만드는 코드가 있었다. '개인 복구 시 초기화' 의도와 달리 걸어서 돌아오기만 해도 고정 샤워를 대체했다. 전용 재현 테스트로 걷기와 실제 개인 복구를 분리해 검증한다.

[수정 전 결과](../../artifacts/stage2-art/contamination-baseline.xml): 전용 5개 중 4개 통과, 위 재현 1개 실패. 오염 60% 상태로 시작 지점에 이동하자 0%가 됐다. 위치 기반 초기화를 제거하고 `GameSession.PlayerRespawned` 이벤트를 통해 실제 개인 복구 완료 시 호스트가 해당 플레이어의 오염만 초기화하도록 수정했다. Stage2Bootstrap이 구독·해제를 맡으며 Stage1에는 구독자가 없다.

## 시각·청각 완성도 한계

현재 가스 입자와 초록색 경계, HUD 누출 예고·개인 및 동료 오염 수치, 분사 선은 있다. 하지만 기획에 제안된 **우주복 얼룩, 시설 경고등·누출음, 제독 명중 효과음**은 아직 구현되어 있지 않다. 분사 선도 폭을 가진 원뿔 판정을 완전히 표현하는 최종 VFX가 아니다. 따라서 '기획의 모든 피드백까지 완성'이라고 판단하지 않는다.

구조 조건은 기획에서 미정이다. 현재 공통 G 구조를 사용하며, 제독 없이 100%인 사람을 살리면 다음 오염 판정에서 다시 기절할 수 있다. 기존 HUD가 제독 후 구조를 안내하는 이유다.

## 검증 범위

[수정 후 결과](../../artifacts/stage2-art/contamination-validation.xml): 전용 5개와 기존 Stage2·StageCatalog·아트 회귀 18개, **총 23개 통과 / 실패 0개**. 시작 구역으로 걷기만 해서는 오염이 유지되고 실제 개인 복구 후에는 초기화되는 것을 확인했다.

실제 Stage2_Earth 씬의 PlayerRig와 호스트 오염·분사 메서드를 사용한다. 긴 노출 시간은 메서드의 dt를 제어하여 재현한다. 공간 이탈·상하층·중복 구역·솔로 완화·기절·샤워·상층 분사·사거리·각도·자기 제독 제외·복제 상태의 비권한 판정을 확인한다. 기존 Stage2 회귀 테스트의 벽 차단과 실제 프레임 기반 제독, 첫 체결 후 가스 활성화도 함께 실행한다.

실제 여러 PC의 동시 접속, 패킷 지연·손실·늦참 상태는 이번 전용 테스트의 실측 범위에 포함하지 않는다. 스냅샷 직렬화·복제 적용 검증과 실제 네트워크 실측은 구분한다.
