# AI 견인·하역·용접 보강

## 적용 범위
- 기존 `codex/ai-team-slots-local` 작업 위에 추가. 커밋/push/MR 없음.
- 플레이어 입력, 견인 물리, 수동 용접 판정은 유지. 순간이동·자동 정렬·강제 조인트 생성 없음.
- LLM/STT/명령 스키마는 변경하지 않음. AI 실행기 재포장 없이 Unity 코드 재컴파일/새 게임 빌드 필요.

## 견인
- 상승 → 수평 경유 → 하강하는 제한형 항로 후보 20개 중 통과 가능한 최단 후보 선택.
- 실제 견인 장치 콜라이더와 적재 파츠를 감싼 공간으로 각 구간을 검사. 이동 중 다시 막히면 정지/재탐색.
- 맵에 수작업으로 지정한 고정 항로는 아님. 출발/목적지로부터 생성하는 유한 경유 항로이며, 일반적인 3D 미로 탐색은 지원하지 않음.
- 막힌 경우 무한히 벽으로 밀지 않고 실패 상태를 표시. 취소/실패 시 장을 끄지 않아 공중에서 짐을 의도적으로 떨어뜨리지 않음.

## 하역
- 움직이는 받침 파츠 위치와 화물의 실제 하단 높이를 갱신.
- 수평 정렬 오차, 선속도, 각속도가 작은 경우에만 장 해제.
- 해제 후 받침면을 실제로 감지하고 높이/위치/속도가 1.2초 안정되어야 파츠 하역 성공.
- 7초 안에 안정되지 않으면 최대 두 차례 재인양. 이후 실패 표시.
- 삐뚤어진 파츠를 완벽한 정답 회전으로 강제 정렬하지 않음.

## 용접
- 수동 용접과 동일한 접촉 탐색으로 상대 파츠를 선택하고 작업 도중 다른 상대를 선택하지 않음.
- 두 파츠에 AI 작업 예약 적용.
- 성공 조건을 임의의 live bridge 대신 선택한 상대에 대한 용접 강도로 변경.
- 실제 빔이 의도한 접합부/상대에 닿을 때만 도구 입력. 고정/이동 로직을 직접 변경하지 않음.
- 절단은 기존 파츠 비드 제거 동작 유지. 특정 접합만 선택 절단하는 것은 이번 범위 밖.

## 검증 및 한계
- Unity EditMode: 항로/안착 판정 신규 10케이스 및 명령/런타임 기존 20케이스 통과. 실제 모델 통합 1케이스는 opt-in으로 제외.
- 실제 Stage1 견인·적층·용접, 바람, 이동 장애물, 호스트/원격 2인 플레이는 아직 검증하지 않음.
- 보수적인 경계 상자 검사 때문에 좁은 출발 공간/큰 화물은 항로 없음으로 멈출 수 있음. 실제 맵 테스트 후 구간/여유 폭 조정 필요.

## 플레이 검증 순서
1. 잠금/고정못이 해제된 견인 장치로 빈 비행, 장애물 옆/위 경유 확인.
2. 못을 모두 뺀 파츠를 인양하여 조립대 부근까지 운반. 바람에 흔들리면 감속/재확보 및 실패 상태 확인.
3. 적층 후 장이 꺼지기 전 정지, 해제 후 받침면/안착 확인 및 재시도 확인.
4. 가까이 쌓은 두 파츠 용접. 근처 제3 파츠 연결로 성공 판정되지 않는지 확인.
5. 모든 단계에서 중단/대상 파괴/사람 탑승/수동 승객 조작 확인. 멀티플레이 별도 검증.
