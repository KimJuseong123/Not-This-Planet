## 1. 큰 규칙 셋 — 나머지는 거의 다 여기서 나옵니다

### 규칙 ① 물리는 호스트에서만 돈다

참가자 화면의 부품·탈것·도구·운석은 **kinematic(스스로 안 움직이는 상태)** 이고, 호스트가
보낸 자세를 따라가기만 합니다. 양쪽이 각자 굴리면 결과가 갈리기 때문입니다.

> `WorldSync.cs:12-29` — "물리는 서버에서만 돈다(-145). 클라이언트의 같은 오브젝트는
> 키네마틱으로 두고 받은 자세를 따라가기만 한다 — 양쪽이 각자 굴리면 결과가 갈린다."

**따라서 참가자 화면은 대부분 "그림" 입니다.** 판정은 전부 호스트에서 납니다.

### 규칙 ② 단 하나의 예외 — 내 캐릭터

`-363` 이후 참가자도 **자기 캐릭터만은** 로컬 물리로 즉시 돌립니다. 서버 자세와 벌어진
만큼은 매 물리 스텝에 10%씩 갚습니다(되감지 않고 조금씩 끌어옵니다).

> `PredictionCorrection.cs` — `Rate = 0.1f`, `Epsilon = 0.01m`

### 규칙 ③ 호스트는 지연이 0이다

호스트는 서버 그 자체라 왕복도 보간도 없습니다. **구조상 공평하지 않고, 그것이 알려진
대가입니다.**

실측(2026-09-09, 같은 사람·같은 빌드·역할만 바꿈):

| | 왕복(RTT) | 입력→화면 |
|---|---|---|
| 호스트였을 때 | 0.0ms | **~10~25ms** |
| 참가자였을 때 | 77.8ms | **~166ms** |

❓ **Q0. 참가자가 호스트보다 ~150ms 늦게 반응하는 것은 사양으로 두는가?** (없앨 방법은

## 3-1. Q7 의 원인 — 같은 문제를 두 곳이 다르게 풀었다

참가자 화면에서 "서버가 보낸 자세만 따라가는 물체" 를 세우는 방법이 **두 가지**입니다.

| | 부품 · 탈것 · 도구 | 운석 · 흔적 |
|---|---|---|
| 어디서 | `WorldSync.PrepareClientBody` ([:898](../../METAGAME/Assets/_Project/Scripts/Runtime/Network/WorldSync.cs#L898)) | `MeteorSpawner.CreateGhost` ([:1175](../../METAGAME/Assets/_Project/Scripts/Runtime/Gameplay/Hazards/MeteorSpawner.cs#L1175)) |
| 강체 | `isKinematic = true` | `isKinematic = false` |
| 콜라이더 | **손대지 않는다 → 켜진 채** | **전부 끈다** + `detectCollisions = false` |
| 판정 컴포넌트 | 원래 없다 | `enabled = false` |
| 참가자 몸이 | **막힌다** ✅ | **통과한다** ❌ |

**둘 다 "판정은 서버 몫" 을 지키려던 것인데, 운석 쪽은 그것을 콜라이더까지 끄는 것으로
구현했습니다.** 판정을 끄는 데 필요한 것은 `Meteor` 컴포넌트를 끄는 것 하나뿐입니다 —
콜라이더는 *막는* 일을 할 뿐 아무 판정도 하지 않습니다.

`ClearNetworkMeteors` 의 주석("충돌러가 꺼져 있어 남으면 지면을 뚫고 영원히 떨어진다")이
그 부작용을 이미 적어 두고 있습니다. 지면조차 못 막고 있다는 뜻입니다.

**고칠 방향** — 운석 그림도 부품과 같은 모양으로 세운다: `isKinematic = true` · 보간 켜기 ·
**콜라이더는 켠 채로 두고** `Meteor` 컴포넌트만 끈다.

**따라오는 것 둘**

1. 키네마틱이 되면 중력으로 궤적을 흉내내던 부분이 멈추므로, 자세 적용을 `MovePosition`
   으로 바꿔야 합니다(흔적 쪽 `DeadReckonScar` 와 같은 결).
2. **낙하 중 운석과 착지한 흔적은 위험도가 다릅니다.** 흔적은 멈춰 있어 참가자 화면의
   위치가 서버와 같습니다 — 콜라이더를 켜면 **무조건 좋아집니다.** 낙하 중인 돌은
   ~166ms(≈1.6m) 낡은 자리에 있어서, 막기 시작하면 "호스트에는 안 맞았는데 참가자만
   막히는" 새 어긋남이 생길 수 있습니다.
   → **흔적부터 켜고, 낙하 중은 실제 플레이로 확인한 뒤 결정합니다.**
