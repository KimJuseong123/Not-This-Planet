# 687: 입장 컷씬 종료 후 태블릿 유지

## 범위와 원인

- 브랜치: `S15P21B202-687-ui`, 기준 `9b0967b6`.
- 로비에서 `Stage1_Astra` 진입 후 입장 컷씬을 끝까지 보거나 스킵하면 각 플레이어의 태블릿이 열린 상태여야 한다.
- `Stage1CutsceneScene.LateUpdate`는 15초 이후 태블릿을 열지만, `Stop`이 컷씬 시작 전에 저장한 상태를 무조건 복원해 다시 닫았다. 일찍 스킵하면 마지막 태블릿 샷 자체도 실행되지 않는다.
- 가산 씬 로딩 중 스킵하면 `OpenView`가 오래된 연출을 버리므로 `Stop` 수정만으로는 충분하지 않다.

## 수정

- 완료된 입장 연출의 `Stop`은 태블릿을 열어 두고 커서를 해제한다. 공세 연출과 진행 중 중단된 입장 연출은 기존 상태 복원을 유지한다.
- `Stage1CutsceneFlow`는 로컬 플레이어가 준비되고 게임 진행 상태가 되었을 때 한 번 태블릿을 연다. 컷씬 화면을 못 띄운 클라이언트와 늦게 몸이 생성된 클라이언트도 대상이다.
- 최초 자동 열기 이후 사용자가 직접 닫으면 다시 열지 않는다. 엔딩 중에는 자동 열기를 실행하지 않는다.
- 네트워크 권한, 스킵 투표, 진행 시간, 운석, 카메라 복원, 씬·프리팹·패키지 설정은 변경하지 않았다.

## 검증 범위

- `Stage1CutsceneTests`에 정상 종료/스킵 및 서버 상태를 수신한 클라이언트, 반복 정리, 공세 상태 복원, 입장 중단, 로컬 몸 생성 지연과 수동 닫기 회귀 검사를 추가했다.
- 기존 실제 월드 테스트의 입장 후 기대값을 열린 상태로 갱신하고 수동 닫기 검사를 추가했다.
- Unity 6000.5.4f1 `-batchmode -nographics`, EditMode, `!Heavy`로 검증했다. 화면 직접 조작은 하지 않았다.
- 대상: `Stage1CutsceneTests`, `CutsceneSkipTests`, `TabletOnboardingTests`, `Stage1TabletViewTests`, `TabletGuideTests`. **55개 중 52개 통과, 기존 실패 3개**. 새 회귀 검사 10개는 모두 통과했다.
- 수정 전 `HEAD`의 런타임 소스 두 파일로 비교 실행한 결과, 태블릿 관련 재현 검사 6개는 모두 실패했다(열려 있어야 하는 태블릿이 닫힘). 수정 후 같은 6개가 통과했다. 비교 후 수정 소스를 복원했다.
- 운석 관련 기존 테스트 `SerializedAssaultMultiplierControlsInterval`의 세 매개변수는 수정 전후 모두 `Expected 30, actual 10`으로 실패했다. 이번 수정의 회귀가 아니며 기대값이나 운석 코드는 변경하지 않았다.
- Unity 스크립트 컴파일 통과. 기존 구형 API 사용 경고가 있으며, 변경한 코드에 컴파일 오류는 없다. `git diff --check` 통과.
- 증거: 워크트리의 `tmp/687-validation/final.xml`, `final.log`, `original.xml`, `original.log` (Git 제외). 초기 배치 실행의 라이선스/패키지 연결 실패는 정상 권한의 대기형 배치 실행으로 해결했다.
- 검증 한계: 실제 로비→Stage1 전체 플레이, 여러 PC의 동시 접속, 컷씬/태블릿 화면의 시각적 연결, 플레이어 빌드는 실행하지 않았다. `Heavy` 실제 월드 테스트는 기대값만 갱신했고 실행하지 않았다. 자동 상태 검사 통과를 실제 다인 화면 검증 완료로 보지 않는다.

## 추가 런타임 확인 절차

1. 호스트와 원격 클라이언트가 로비에서 Stage1에 진입해 컷씬을 끝까지 본다. 마지막 태블릿 샷에서 탐색으로 전환할 때 태블릿이 내려가지 않는지 확인한다.
2. 다시 진입해 15초 이전 전원 스킵, 15초 이후 전원 스킵을 각각 수행한다. 모든 화면에서 태블릿이 열리고 입력 차단이 해제되어야 한다.
3. 느린 클라이언트의 가산 씬 로딩 중 전원 스킵을 수행한다. 플레이어 생성과 로딩 완료 후 태블릿이 열려야 한다.
4. Tab으로 닫은 뒤 계속 닫힌 상태인지, 다시 열기와 페이지 이동/확인이 되는지 확인한다.
5. 태블릿을 연 상태/닫은 상태 각각 공세 컷씬을 재생하고 스킵한다. 이전 상태와 카메라가 복원되어야 한다.
6. 입장 중 Esc 메뉴를 열어 둔 채 컷씬이 종료되면 메뉴가 유지되어야 하고, 메뉴를 닫으면 열린 태블릿을 읽을 수 있어야 한다.
