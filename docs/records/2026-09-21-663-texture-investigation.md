# 663: 식생·오브젝트 텍스처 조사

- 기준: `S15P21B202-663-qa`, `7b69e199`, Unity 6000.5.4f1 / URP 17.5.0.
- 워크트리: `.local-worktrees/663-qa`.
- 요청: 혼자하기와 멀티플레이에서 일부 식생·오브젝트의 텍스처가 보이지 않는 원인 조사 및 수정. 화면 직접 조작 금지.
- 상태: **현재 체크아웃에서 증상 미재현. 원인 및 수정 미확정.** 재현 위치와 실행 환경을 추가로 확인해야 한다.

## 확인한 근거

1. 모든 `.mat`의 저장된 텍스처 GUID를 에셋 `.meta`와 대조했다. 참조가 있는 텍스처의 누락이나 LFS 포인터만 남은 파일은 발견하지 못했다.
2. 새 워크트리에서 에셋을 임포트하고 Unity 배치모드로 빌드에 등록된 9개 씬을 읽었다. Renderer의 실제 머티리얼 슬롯에서 null 및 Standard 셰이더를 발견하지 못했다. 텍스처가 연결된 메시의 UV0 누락도 발견하지 못했다. 씬은 저장하지 않았다.
3. Stage1_Astra를 자동 Play Mode로 진입시켜 60 프레임 후 Renderer를 조사했다. 번호 식생 7종(총 459개 렌더러), 버섯나무 95개, 꽃 무리 23개, 작은 보라꽃 17개, TinyFlowerPatch 10개의 텍스처 연결이 유지됐다. null 머티리얼/셰이더는 없었다. 이 검사는 혼자하기 경로이며 다중 클라이언트 검증이 아니다.
4. 번호 식생 7종을 별도 빈 씬에 배치해 GPU RenderTexture로 실제 출력했다. 잎·꽃의 색과 텍스처가 표시됐다. 사용자 화면 캡처 또는 UI 조작 없이 자동 생성한 이미지다.
5. 회귀 테스트 **35/35 통과**: VegetationInteractionTests(실제 Play Mode 접촉·흔들림 포함), TinyFlowerPatchBuilderTests, AssemblyDockVisualTests, PlayerFogExemptionTests, ArtLinkCleanupTests, AuthoredMapSettingsTests.

## 조사 중 구분한 사항

- 일부 장식, 안내등, 임시 지오메트리, Stage2 블록아웃, 발사대 상태 표시는 의도적으로 단색 또는 절차적 셰이더를 사용한다. `mainTexture == null`만으로 이들을 결함으로 판정하면 기존 상태 표시와 연출을 훼손할 수 있다.
- PlantRustle은 시각 자식의 회전을 변경하며 머티리얼 또는 텍스처를 교체하지 않는다.
- UrpRenderValidation.AddMaterialDependencies는 `.mat` 경로만 수집하므로 주석과 달리 FBX 내장 머티리얼 검사가 빠진다. 이번 실제 씬 조사에서 사용 중인 내장 재질 문제는 발견되지 않았으므로 보고 증상의 원인으로 확정하지 않았다.
- 자동 Play Mode 진입에서 기존 convex mesh의 256 폴리곤 제한 경고 4개가 발생했다. 텍스처 오류는 아니며 테스트 실패나 C# 컴파일 오류는 없었다.

## 변경 및 증거

게임 코드·씬·프리팹·머티리얼에 추측성 수정을 적용하지 않았다. 임시 검사 코드는 Assets 밖으로 옮겼다. Unity 자동 설정/직렬화 변경은 원복했다. 원래 develop 작업 폴더의 사용자 수정은 건드리지 않았다.

검사 스크립트, 로그, XML 결과, 씬/런타임 머티리얼 목록과 `texture-plants.png`는 워크트리의 `.local-validation/texture-663/`에 로컬 증거로 보관한다.
