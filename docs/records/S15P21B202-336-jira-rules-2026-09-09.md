# Jira Automation 규칙 실측 전문 (2026-09-09)


[문서 안내](../README.md) → [작업 기록](README.md) → 협업·자동화

2026-09-09 Jira Automation 활성 규칙을 조회한 출력입니다. 해당 시점의 규칙 조건을 대조하는 근거로 사용하며, 웹훅 URL은 호스트만 보존합니다.

본문의 “현재”, 검증 수치, 미완료 항목은 **기록 당시 기준**입니다. 후속 변경은 관련 이슈와 [주제별 색인](README.md)을 함께 확인합니다.

`scripts/jira/dump_rule.py` 로 규칙 JSON 을 뜨고 `scripts/jira/summarize_rules.py` 로 정리한 출력이다.
**문서(`jira-gitlab-automation.md`)가 아니라 이것이 그 시점의 사실이다.**

`DISABLED` 는 안 쓰는 것이라 뺐다 — 목록에는 `자동 스프린트 활성`(id 5782244) 이 꺼진 채로 있다.

⚠ **웹훅 액션의 URL 은 호스트만 남긴다.** R10 의 MM 웹훅 URL 은 그 자체가 비밀이다 —
가진 사람은 누구나 팀 채널에 글을 넣을 수 있다. 첫 판에서 이 문서에 URL 전문을 그대로 적어
커밋했고(2026-09-09), 이력에서 지운 뒤 `summarize_rules.py` 가 호스트만 찍도록 고쳤다.
**규칙 덤프 JSON 자체도 리포에 두지 않는다** — 스크래치패드에만 둔다.
