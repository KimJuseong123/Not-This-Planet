# 핵심 파츠 솔로 밀기·당기기 (2026-09-13)

- 요청: 혼자서도 핵심 파츠를 이동하고, 1번 견인 파츠와 나머지 파츠의 잡기 조건을 통일한다. 화면 직접 조작은 하지 않는다.
- 코드 확인: `PartPushTable.MinPeople = 3`과 `ForceFor`의 인원 제한이 1·2인에게 힘을 주지 않았다. 몸밀기와 손잡기 참여는 이미 `PartPush.Gather`에서 합산했다. 1번 파츠의 견인 전환은 별도의 80kg 차량 물리를 사용하므로 일반 파츠와 물리 반응이 다를 수 있다. 보고된 장면을 직접 재현하지는 않았다.
- 변경: 최소 인원을 1명으로 바꾸고, 1·2인에게 기존 3인 수준의 출발 힘을 제공한다. 3·4인 힘은 유지한다. 속도 상한은 기존 0.4/0.8/1.2/1.5m/s 표를 사용한다.
- 조작: 고정이 풀린 자유 파츠에 몸을 대고 0.2초 이동하면 잡기 없이 밀기 시작. 좌·우클릭으로 잡은 뒤 전진·후진하면 밀기·당기기. 혼자 이동할 때도 밀기 카메라 대상이 된다.
- 회귀 검증 추가: 파츠 1~4 각각 몸밀기·잡고 밀기·잡고 당기기 총 12개 사례. 실제 파츠 명세의 자식 콜라이더와 질량을 사용해 지면 위 이동 거리를 검사한다. 기존 1·2인 제한 검증과 솔로 카메라 검증도 새 규칙에 맞췄다.
- 검증 결과: 생성된 Unity C# 프로젝트 `Metagame.Gameplay.Tests.Editor.csproj` 컴파일 성공(오류 0). `git diff --check` 통과. Unity EditMode 실행은 같은 프로젝트가 이미 에디터에 열려 있어 배치 실행이 거절됐다. 테스트 실행 통과나 실제 물리 이동은 아직 확인하지 못했다.

## 남은 확인

1. Unity에서 `Metagame.Gameplay.Tests.PartPushTests`와 `PartPushCameraTests`를 실행한다.
2. 혼자 플레이하며 1번 파츠 견인 전환 이후와 2~4번 고정못 제거 이후 각각 몸밀기·잡고 전진·잡고 후진을 확인한다.
3. 고정된 파츠, 빔으로 운반 중인 파츠, 용접된 파츠는 수동 이동이 차단되는지 확인한다.
4. 두 명 이상 합동 이동과 반대 방향 입력 상쇄, 이동 종료 후 카메라 복귀를 확인한다. 멀티플레이 실측은 미수행이다.


## 후속 체감 조정 — 솔로 운반 질량

- 사용자 플레이 피드백: 이동은 가능하지만 너무 무거워 잘 당겨지지 않는다.
- 자유 상태의 기본 질량을 20%로 낮춤(기본 406~745kg → 약 81~149kg). 견인 차량으로 전환된 1번 파츠의 80kg과 가까운 수준이다. 조립 상태는 원래 질량을 복구하고 용접 비드의 추가 질량은 유지한다.
- 밀기 힘이 질량에 비례하므로 질량 감소만으로 목표 이동 속도가 올라가지는 않는다. 솔로 속도 상한도 0.4에서 0.6m/s로 올렸다. 2~4인 속도는 유지한다.
- 상태 전환·추가 질량·물리 표현 갱신 후 질량 유지 및 조립 후 복구를 검사하는 회귀 테스트 2개를 추가했다.
- 검증: 테스트 프로젝트 포함 컴파일 성공, 오류 0개, 경고 89개. diff 공백 검사 통과. Unity 물리 테스트와 플레이 체감은 미확인이다. 화면 직접 조작은 하지 않았다.
- 새 게임에서 자유 상태 전환 후 솔로 당기기와 운석 충돌 반응을 확인해야 한다. 자유 상태 질량이 낮아져 외부 충격에 대한 반응도 달라질 수 있다.
