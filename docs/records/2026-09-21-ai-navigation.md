# AI 기본 내비게이션 실험 (2026-09-21)

## 범위

- 작업 폴더: `S15P21B202-ai-integration-20260920`, 로컬 브랜치 `codex/ai-team-slots-local`.
- 기존 텍스트 AI 연결 위에 출입구/벽 우회/경사로 경로 이동을 추가한다.
- LLM/STT 설정, 원본 모델 import 설정, 씬, 프리팹, 플레이어 물리/조작은 변경하지 않는다.
- 순간이동, 점프, 사다리, 견인 탑승, 고정못 실제 작업은 이번 범위가 아니다.
- Jira, commit, push, MR은 수행하지 않았다.

## 구현

- `TeamRoster.EnsureServer`가 세션 소유 `AiNavigationWorld`를 준비한다.
- 방장 AI 정책이 Active일 때만 지형 수집/갱신. 클라이언트는 기존 NetPlayer 복제를 그대로 사용한다.
- NavMesh는 실제 Physics Collider에서 생성한다. 질의 전용 레이어/플레이어/도구는 제외하고 파츠는 통행 장애물로 처리한다.
- 높이 1.8m, 반경 0.55m, 경사 40도, 턱 0.25m 기준. 세션 위치 중심 512×128×512m 범위.
- 2초 간격 비동기 지형 갱신, AI별 0.75초 간격 경로 재계산. 플레이어가 1m 이상 이동하면 경로를 더 일찍 갱신한다.
- `AiNavigationRoute`의 모서리 안내를 `AiFollowController`가 기존 PlayerRig InputFrame으로 실행한다. NavMeshAgent가 Transform을 직접 움직이지 않는다.
- 벽을 사이에 둔 직선 거리가 아닌 경로 잔여 거리를 도착 기준으로 사용한다. 도착 거리 2.3m.
- 충돌/낭떠러지는 별도 물리 검사로 멈춘다. 경로상 진전이 6초 없으면 명령을 종료하고 상태에 원인을 표시한다.
- 경로 없음은 대기하며 재탐색한다. 올라갈 경로 없는 단상에 목표를 아래층으로 강제 투영하지 않는다.

## 지형 데이터와 빌드

원본 import mesh의 Read/Write를 켜지 않기 위해 `Resources/AiNavigationGeometry.asset`에 위치/삼각형 데이터만 복사했다. Stage1_Astra와 PracticeLobby의 서로 다른 충돌 메시 44개, 정점 534,235개이다. 파일은 약 18MB(에디터 직렬화 크기)이며 텍스처/법선은 복제하지 않는다.

이 Resources 데이터는 빌드에 포함되고 런타임에서 자동 사용된다. 사용자가 NavMesh를 수동으로 켤 필요는 없다. 실제 player build는 아직 검증하지 않았다.

맵에 새로운 MeshCollider 모델을 추가하거나 원본 충돌 메시 형상을 변경하면 Play를 종료하고 `Tools > Not This Planet > AI > Rebuild Navigation Geometry`로 재생성한다. 위치 변경만으로는 재생성이 필요 없다. 미등록 읽기 불가 메시는 보수적인 장애물 박스로 대체되므로 그 주변 경로가 막힐 수 있다.

## 검증 기록

- v1: 경로/경사 연결 계산 통과, 실제 캐릭터가 모서리를 일찍 돌아 멈춤. 모서리 허용 오차와 몸통 여유 수정.
- v2: 벽 물리 우회, 동적 경로 재생성/분리된 단상 거부, 경사 연결 3건 통과. 테스트 시작 전 로그에서 native NavMeshPath의 필드 초기화 예외를 찾아 지연 초기화로 수정.
- v3: 관련 54건 중 52 통과 / 1 실패 / 1 opt-in 생략. 실제 경사로 등반 통과. 실제 Stage1은 읽기 불가 지형을 박스로 대체하여 못 주변 후보 경로 0/128이었음.
- Geometry cache 적용 후 Stage1 검사: 665개 소스, 근사 박스 0개, 시작점에서 못 주변 후보 지점으로 83/128 경로 생성. 이 수치는 모든 못 뽑기 성공률이 아니며, 임의 방향의 후보점 중 일부는 파츠 내부/다른 높이에 있어 도달 불가할 수 있다.
- 최종 v4: **54/54 통과, 실패/생략 0**. `METAGAME/Logs/ai-navigation-v4.xml`, `ai-navigation-v4.log`.
  - AiNavigationTests, AiRuntimeTests(실제 로컬 추가팩 opt-in 포함), TeamRosterTests, TeamSlotsTests, AiHostPolicyTests.
  - Unity Editor 6000.5.4f1에서 컴파일/Play Mode 물리/로컬 LLM 검증. 새 컴파일 오류와 예외 없음.
  - 기존 Mirror 외부 어셈블리 확인 경고, 일부 모델 Convex Hull 경고와 deprecated API 경고는 남아 있다.

## 직접 테스트

1. 이 폴더의 `METAGAME`를 Unity 6000.5.4f1로 열고 기존 Lobby 방 만들기 흐름을 사용한다.
2. AI 사용 켜기, 대기용 AI 테스트 끄기. 추가팩 준비 후 게임 시작.
3. Esc의 개발용 AI 텍스트 창에서 한 AI 선택 → `나 따라와` 전송 → 메뉴 닫기.
4. 출입구를 나간 뒤 옆으로 이동, 큰 파츠 반대편으로 이동, 연결된 경사로로 단상에 올라가기.
5. `여기서 기다려` 또는 `그만해` / 전체 즉시 중단 버튼으로 정지 확인.

`그만 따라와`의 LLM 오분류는 아직 수정하지 않았다. 이번 검증에서는 분류 품질과 이동 로직을 분리한다.

## 남은 제약

- 다른 PC 및 멀티 관찰/플레이어 빌드 검증은 사용자 요청으로 연기.
- Stage1 전체 동선의 실제 캐릭터 주행/시각 검증은 필요하다. 위 83개는 경로 계산 검사이지 실주행 83건이 아니다.
- 움직이는 사람/작은 도구를 능동적으로 돌아가는 군중 회피는 아직 없으며, 안전 검사에서 정지할 수 있다.
- 경로 준비/갱신 중 잠시 멈출 수 있다. 실제 게임에서 갱신 부하 측정이 필요하다.
- 고정못 접근 위치 선정/잡기/당기기는 다음 작업에서 이 경로 계층을 재사용한다.
