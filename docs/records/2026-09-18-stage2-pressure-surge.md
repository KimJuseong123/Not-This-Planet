# Stage2 배수 압력 역류

기준 커밋 `b78ed5b8`, Unity 6000.5.4f1, 603 작업 브랜치. 시작 시 작업 폴더는 깨끗했다. 화면 직접 조작 없이 imagegen, 연결된 Blender MCP, Unity 배치 모드로 제작했다.

## 산출물

- 현장 컨셉 1장 + 정면/왼쪽/오른쪽/후면 별도 PNG 4장: `docs/assets/concepts/stage2/pressure-surge/`.
- FBX: `METAGAME/Assets/_Project/Models/Stage2/S2_SurgePump.fbx`.
- FBM: 동명 폴더, 실제 연결된 512×512 BaseColor PNG 7장. 경로는 FBX 상대 경로이며 Blender 재가져오기 검사 통과.
- 원본: `Source~/S2_SurgePump.blend`, 이미지 7장을 내부에 패킹. 기존 사용자 Blender Scene은 보존.
- 13,632 삼각형, 메시 5개. 고정 본체와 손잡이/계기 바늘/배출 덮개/경고등 가동부 분리. UV 및 미터 크기 검사 기록은 `artifacts/stage2-models/SurgePump*.json`.
- Stage2_Earth에 세 인스턴스, 재질, 물줄기, 경고등, 바닥 예고선, 감압 상호작용을 저장. 갱신 도구는 `Stage2PressureAuthoring.Apply`.

## 검증

Blender FBX 재가져오기: 스케일/UV/메시 수/FBM 상대 경로 통과. Unity 컴파일 및 기존 기능 포함 29/29 검사 통과. 최종 배치와 효과 재활성화 수정 후 압력/씬 8/8 검사도 통과. 실제 Play Mode에서 분출이 자체 충돌체에 막히지 않고 플레이어를 밀며, 벽 뒤에서는 밀지 않음을 확인했다.

Windows 개발 빌드 후 별도 호스트·클라이언트·도중 합류 관찰자 3개 프로세스에서 원격 감압과 경고/분출/감압 복제 및 연결 해제를 검증했다. 6개 판정 통과. 원시 로그 대신 `artifacts/stage2-pressure/network-smoke.json`에 결과를 남겼다. 테스트 XML 및 장면 렌더는 같은 폴더에 있다.

잔여 한계: 시뮬레이션 유체가 아닌 게임용 입자 물줄기다. 실제 1~4인 플레이에서 예고 시간·밀침 강도·반복 빈도의 재미 검증과 다양한 GPU의 성능 측정은 별도다.

## 최종 멀티 재검증 보완

사용자 요청으로 원격 플레이어의 물리 이동량을 추가 측정했다. 기존 2.4m/s 충격이 보행 제동에 상쇄되어 서버에서 0.6초간 0.072m만 이동했다. 네트워크 누락은 아니었으나 작업 방해 강도가 약해 해당 물줄기 충격만 4.5m/s로 보정했다. 수정 후 서버 0.283m/0.6초, 클라이언트 0.365m/1초를 확인했고 원격 감압 및 도중 합류 포함 8개 네트워크 판정이 통과했다. [상세 검증 기록](../../artifacts/stage2-final-validation/README.md)을 참고한다.
