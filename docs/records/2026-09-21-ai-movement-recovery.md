# AI 이동 이탈 복구

## 범위
- 기존 `follow`, `pull_pin` 명령의 이동 복구만 보완. 여러 못/방향 지정/LLM·STT 변경 없음.
- 씬, 플레이어 물리, 바람 세기, 기존 고정못 당기기 규칙은 수정하지 않는다.
- 서버에서 AI 입력을 만드는 `AiCompanionController`에 복구 처리를 연결한다. 인간 플레이어에는 적용하지 않는다.
- 사용자 요청으로 못 뽑기 변경과 함께 로컬 체크포인트 커밋에 포함한다. push / MR은 수행하지 않는다.

## 동작
- 공중/넘어짐/큰 속도: 입력을 멈추고 명령과 못 예약을 유지. 잡던 못은 놓지만 해제 진행도는 유지.
- 착지 후 0.4초 안정화, 현재 위치부터 경로와 이동 진행 기준을 다시 계산.
- 보행 중 0.12초 이하의 짧은 비접지 상태는 복구 시작으로 판단하지 않는다. 못 작업의 경로 기준은 선택한 못의 접근 지점으로 유지한다.
- 복구 중에는 못 작업의 제한 시간을 소모하지 않도록 보류.
- 이동 지시가 있는데 위치 진전이 없으면 옆/뒤 방향 중 충돌과 발밑을 검사한 방향으로 잠시 걷기. 점프나 장애물 통과는 하지 않는다.
- 걷기로 복귀할 경로가 없거나 탈출 시도가 실패하면 이전 안전 위치를 재검사하여 복귀.
- 안전 위치는 바닥, NavMesh, 경사, 몸이 차지할 공간, 복귀 후 연결 경로를 확인. 이동 기록을 조금 남겨 끼인 현재 위치로 덮어쓰지 않는다.
- 새 장애물/캐릭터가 복귀 지점을 막으면 순간이동하지 않는다. 도구 소지/물체 잡기/다른 사람에게 잡힌 상태도 강제 복귀하지 않는다.
- 강제 복귀는 명령당 최대 2회, 최소 간격 10초. 유효한 위치가 없으면 이유를 표시하며 대기. 새 명령이나 중단으로 초기화.

## 검증
- `METAGAME/Logs/ai-recovery-v1.xml`: 9/9 통과.
- 공중으로 위치를 이동시킨 뒤 동일 못 명령으로 해제 완료, 공중에서 취소 후 자동 재개 없음.
- 연결되지 않은 별도 바닥에 떨어진 뒤 이전 안전 위치 복귀.
- 기존 장애물 우회/경사로 이동 및 실제 Stage1 못 한 개 해제 회귀 검사.
- `METAGAME/Logs/ai-recovery-v2.xml`: 60/60 통과, 생략 없음. 기존 로컬 LLM 실제 실행, AI 자리/방장 정책 회귀 포함.
- `METAGAME/Logs/ai-recovery-v3.xml`: 마지막 비접지 유예/못 작업 목적지 보정 후 복구·못·경로 10/10 통과, 생략 없음.
- 새 장애물이 이전 복귀 지점을 막으면 복귀하지 않음, 장애물 제거 후 복귀, 정체 시 실제 이동으로 먼저 탈출하는 검사 통과.

## 제한
- 통제된 PlayMode 테스트로 공중 이탈·분리된 지면·정체를 재현한다. 사용자가 만난 특정 바람 타이밍/나무 위치를 그대로 재현한 것은 아니다.
- 다른 PC의 원격 화면, Windows 플레이어 재빌드 검사는 별도 필요.
- 플레이어가 쓰러지거나 AI를 끄면 기존 정책대로 작업 취소. 기절 자동 부활은 추가하지 않는다.
- 안전 위치를 확보하기 전 이탈했거나, 계속 공중에 있거나, 복귀 조건이 충족되지 않으면 무리하게 순간이동하지 않는다.
