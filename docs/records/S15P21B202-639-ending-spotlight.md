# S15P21B202-639 · 엔딩 인사 구간의 개인 스포트라이트

엔딩에서 참가자를 한 명씩 클로즈업하며 손을 흔드는 구간에, 그 사람에게만 무대
조명을 켠다. 커마(631)에 세운 것을 그대로 쓴다.

## 먼저 쟀다 — 그리고 커마와 달랐다

지라에 "먼저 잴 것" 으로 적어 둔 대로 했다. 엔딩 무대를 세워 놓고 렌더해서
화소로 쟀다.

```
와이드(0.4초)  평균 0.548 · 하위25% 0.267 · 포화 0.0% · 차지 14.7%
클로즈업(1.5초) 평균 0.549 · 하위25% 0.222 · 포화 0.0% · 차지 33.9%
```

**커마에서는 광원이 캐릭터 표면에 전혀 기여하지 않았다**(전부 꺼도 차이 0.000).
엔딩은 다르다 — 키 라이트를 끄니 화소가 바뀌었다.

| 잰 것 | 커마(631) | 엔딩(639) |
|---|---|---|
| 광원 켬/끔 화소 차이 | **0.000 · 최대 0** | 평균 **0.0736** · 최대 **2.247** |

그래도 결론은 같다. **Unity 의 광원은 공기 중의 빛줄기를 안 그린다.** 무대 조명의
빛기둥은 광원이 먹든 말든 직접 그려야 나온다. 그래서 여기서도 `Light` 컴포넌트를
새로 넣지 않고 631 의 가산 합성 메시를 그대로 쓴다.

## 빌더를 공용으로 뺐다

631 때는 `CustomizerBootstrap` 안에 있어 엔딩에서 쓸 수 없었다.
`Metagame.Core` 의 `StageSpotlight` 로 옮겼다 — 메시 공장이 이미 거기 있다
(`Prim`, `MeshVisual`). 커마와 엔딩 양쪽이 참조하는 유일한 어셈블리다.

`StageSpotlight.Create(이름, 부모, 높이, 위반지름, 아래반지름, 웅덩이폭, 웅덩이깊이, 레이어)`

**루트의 원점이 캐릭터 발밑**이다. 그러면 "광원은 정수리 위, 웅덩이는 광원 바로
아래" 라는 관계가 저절로 지켜진다 — 631 에서 이 축이 어긋나 정면에서는 왼쪽으로,
옆에서는 뒤로 쏠려 보였던 자리다.

커마 쪽은 숫자를 하나도 안 바꿨다. 631 의 검증이 그대로 통과하는 것으로 확인했다.

옮기면서 새는 것도 하나 막았다. 631 은 조각마다 만든 재질 셋을 아무도 안 지우고
틀(`glowMaterial`)만 지우고 있었다. 이제 `Destroy()` 가 셋 다 지운다.

## 엔딩 무대의 제약

| 제약 | 안 지키면 |
|---|---|
| 레이어 **31** | 엔딩 카메라가 그 레이어만 본다 — 아무것도 안 보인다 |
| `_stage` 의 자식 | 무대는 원점이 아니라 (10000, 10000, 10000) 에 있다 |
| 커마보다 **좁게** | 인사 자리 간격이 1.1m 뿐이다 |

마지막 것은 **검증이 잡았다.** 웅덩이 폭을 아래 반지름의 1.5배로 뒀더니 지름이
1.35m 라 옆 사람 발밑까지 갔다. 1.15배(지름 1.04m)로 좁혔다.

| | 커마(631) | 엔딩(639) |
|---|---|---|
| 아래 반지름 | 0.78 | **0.45** |
| 웅덩이 폭 · 깊이 배수 | 1.9 · 1.35 | **1.15 · 0.82** |
| 광원 높이 | 1.98 | 1.98 (같다) |

## 켜고 끄는 시각

코루틴이 아니라 **순수 함수**다 — `DemoEnding.SpotlightIntensityAt(localTime)`.
`elapsed` 는 호스트가 실은 `Snapshot.StartedAt` 과 서버 시각의 차라서, 네 명이
같은 순간에 같은 밝기를 본다. 늦게 들어온 참가자도 어긋나지 않는다.

```
0.00 → 0.000      카메라가 아직 이전 사람에게서 넘어오는 중
0.20 → 0.000      도착
0.30 → 0.982      뿅
0.40 → 1.229      넘겼다가
0.60 → 1.000      가라앉는다
1.70 → 1.000      손 흔드는 동안 유지
1.80 → 0.648      사그라들기 시작
1.95 → 0.000      화면이 넘어가기 전에 다 꺼진다
```

### 켜는 시점을 한 번 고쳤다

처음에는 슬롯이 시작하자마자(0초) 켰다. **렌더해 보니 "뿅" 이 안 보였다** —
카메라가 다음 사람으로 넘어가는 데 0.3초가 걸리는데, 그 전에 켜 두면 *이미 켜진
것을 향해 카메라가 다가갈 뿐*이다. 켜지는 순간이 화면에 없다.

0.20초로 미뤘다. 카메라가 거의 도착한 뒤에 켜지기 시작해 0.4초에 가장 밝다.
검증이 이것을 잠근다 — `SpotlightStartsAt` 이전에는 0 이어야 한다.

### 끄는 시점

1.95초에 완전히 꺼진다. **카메라가 움직이기 시작하는 2.0초보다 먼저**여야
넘어가는 화면에 두 개가 같이 걸리지 않는다. 사그라드는 구간(0.25초)이 있어서
꺼지는 것도 보인다.

## 검증

| 무엇을 지키나 |
|---|
| 인사 자리마다 조명이 한 벌씩 있고 **레이어 31** 이다 |
| 광원이 그 사람의 세로축 위, 웅덩이가 광원 바로 아래에 있다 |
| **웅덩이가 자리 간격보다 좁다** — 옆 사람을 안 밝힌다 |
| 셋 다 가산 합성이다 (불투명이면 캐릭터를 가린다) |
| 카메라가 도착하기 전에는 꺼져 있다 |
| 한 번에 **한 명만** 켜져 있다 (2·3·4 인 전부, 0.02초 간격으로 전 구간) |
| 화면이 넘어가기 전에 꺼진다 |
| 탑승·발사 구간에는 하나도 안 남는다 |
| 무대를 접으면 조명도 사라진다 |

## 남은 것

  담당자와 확인했다
* 캐릭터 자체 밝기는 안 건드렸다. 엔딩은 커마와 달리 광원이 먹으므로 필요하면
  키 라이트(0.85)를 올리는 손잡이가 있다 — 별개 작업이다
