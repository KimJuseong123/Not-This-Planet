# Astra ver2 글자 없는 안내와 Blender 제작 인계

## 반영 결과

대상은 `METAGAME/Assets/Scenes/Stage1_Astra_ver2.unity`다. 앞서 놀이 전용 시설을 제거한 씬을 기준으로 수정했다. 기존 색상 광선, 조립대 요구 색, 고정못·끈과 회수 경로를 보존했다.

- 시설·기믹의 TextMesh 27개를 숨기고 행동 순서 그림으로 대체했다. 연료 표시 등 기존 참조는 유지한다.
- 이 씬의 Astra 도구 HUD를 마우스 동작·도구·행동 그림과 게이지로 바꿨다. 다른 씬의 기존 안내는 유지한다.
- 로켓·먹물총·연료통·송풍기의 형태를 구분하고, 연료통과 차량에 실제 잔량 창을 추가했다.
- 승강기, 격리실, 대포, TNT에 실제 상태를 읽는 표시를 추가했다. 클라이언트 대포 표시는 수신 상태를 사용한다.
- 파츠/귀환선의 모양, 서로 다른 조작부 그림, TNT/대상 바위의 일치 문양을 추가했다.
- 그림판은 비충돌 시각 요소다. 기존 방망이·용접기는 도구 선반의 시야를 가리지 않도록 옆으로 옮겼다.

제작 인계는 [시작 문서](../art-production/astra-ver2/README.md), [45개 제작 항목 명세](../art-production/astra-ver2/model-brief.md), [CSV](../art-production/astra-ver2/asset-manifest.csv), [FBX 반입 규칙](../art-production/astra-ver2/fbx-handoff.md)에 정리했다. 개별 상호작용 오브젝트·제어부·위험 구역 115행의 실측 CSV와 현재 렌더 12장, 아이콘 원본을 포함한다. 115행은 FBX 제작 개수가 아니다. FBX 파일 자체는 이번 작업에서 만들지 않았다.

## 검증

Unity 6000.5.4f1 격리 프로젝트에서 최종 소스와 씬으로 실행했다.

- 관련 EditMode 테스트 **103/103 통과**: 도구·탐색·폭파·대포·회수·잡기와 새 안내 상태 테스트 포함.
- PlayMode 실제 조작 검사 **19/19 통과**: 새 외형 연료통 잡기/1인칭 표시/주유/빈 잔량, TNT 유효 설치와 원격 폭파, 대포 탑승/두 번째 조작자 점화/3초 후 발사, 상태 표시 확인.
- 화물 이동·지지 **718**, 보행·지지 **1,152** 샘플 및 지뢰 안전 경로 검사 통과.
- **9,266 컴포넌트**의 직렬화 참조 검사에서 누락 스크립트·끊긴 참조 없음.
- 원본 프로젝트에 전달한 씬의 자산 GUID **183개** 해석 확인. 변경 소스와 검증 소스 일치 확인.
- 최종 씬 SHA256: `3CDCB4EB5A10A4EABB2EA7C2219A423E1FBAECD23B673A6CD99A808BF9EBCDD7`.

[검증 증거](validation/astra-wordless-guidance/)에 결과 XML, 실제 동작 검사 결과, 경로·참조 검사 및 재실행용 임시 검사 코드를 보관했다. 시각 검토는 [참고 이미지](../art-production/astra-ver2/reference/)에 있다.

## 범위와 남은 확인

전체 빌드 및 별도 네트워크 피어 간 실기 검증은 실행하지 않았다. 기존 게임 메뉴·태블릿·공통 HUD의 모든 문자를 제거한 것은 아니다. 초보자가 설명 없이 이해하는지는 사용자 플레이 관찰이 필요하며, [직관성 검토](../art-production/astra-ver2/interaction-audit.md)에 대상별 남은 관찰을 명시했다.
