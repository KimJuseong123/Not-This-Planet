# Part_1 견인 전환 충돌체 유지

## 변경

기존 전환은 Part_1의 모든 충돌체를 끄고 2.4 × 0.34 × 2.2m 플랫폼 하나로 대체했다.
실제 몸체의 위쪽은 통과하고 좁은 받침 옆 빈 공간에는 걸릴 수 있는 구조였다.

- 전환 전에 같은 Rigidbody에 속한 활성 몸체 BoxCollider를 수집한다.
  고정못·소켓·트리거·별도 Rigidbody는 제외한다.
- 원본 충돌체는 비활성화하고, 중심·크기·위치·회전·스케일·물리 재질·접촉 오프셋을
  보존한 복합 충돌체를 Visual 아래 생성한다. 빔 루트를 아래로 돌려도 외형과 함께 움직인다.
- 실제 몸체가 있으면 임시 플랫폼 충돌체를 비활성화한다. 몸체가 없는 기존 테스트/장치는
  플랫폼을 계속 사용한다. 반복 초기화와 리셋에서도 임시 플랫폼이 다시 켜지지 않는다.
- 착륙과 상승 장애물 검사는 각 몸체 상자를 개별 탐사한다. 전체를 큰 상자 하나로
  합치지 않아 몸체 사이 빈 공간을 보존한다.
- 씬·프리팹 재저장과 Inspector 연결은 필요 없다.

## 검증

- 수정 시작 시 Git 작업 트리 변경 없음.
- Gameplay / Editor 테스트 어셈블리: Unity 참조를 이용한 Roslyn 컴파일 오류 각각 0.
- 전환 직후, 탑승 중, 하차 후, ForceReset 후 넓은 상단 충돌과 좁은 받침 옆 빈 공간,
  임시 플랫폼 비활성 상태를 확인하는 회귀 테스트 추가.
- Unity 화면 조작과 플레이 모드 변경은 하지 않았다. 회귀 테스트 실행 및 실제 물리 동작은 미검증.

Editor 확인: Part_1의 마지막 고정못 해제 전후 같은 위치에서 몸체 상단과 받침 옆으로 접근한다.
몸체에 충돌하고 빈 공간은 통과해야 한다. 탑승·회전·하차 후 반복하고, 기체의 실제 바닥으로
착륙하는지와 몸체 상단이 천장을 통과하지 않는지 확인한다.
