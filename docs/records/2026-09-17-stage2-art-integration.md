# Stage2 Earth 모델 통합 및 환경 배치

603 브랜치의 기존 `Stage2_Earth` 초안을 모델 라이브러리로 교체했다. Stage1_Astra의 주변 환경 밀도와 열린 작업 공간을 참고하되, 지구의 폐산업 시설과 자생 식생으로 구성했다.

## 배치

- 기존 47종 중 46종, 모델 인스턴스 1,289개. 완성 로켓 일체형은 조립 대상과 혼동되지 않도록 제외했다.
- 바닥 슬래브 143개, 청색 준비 동선 21개, 황색 조립 동선 11개, 볼라드 20개.
- 외곽 벽 68개, 폐공장 파사드 41개, 냉각탑 3개, 굴뚝 7개, 배수로 29개.
- 식생 메시 888개. 마른 풀·씨풀·관목·고사목·로제트 잡초·꽃·이끼·지의류·담쟁이·갈대 등을 외곽과 폐허에 군락으로 배치했다.
- 주변 지형, 지구 하늘, 오후 조명과 거리 안개를 추가했다. 출발 지점과 크레인 시야, 운반·조립 통로는 열어 두었다.

## 기획과 연결

| 기준 | 반영 및 보존 |
| --- | --- |
| [2장 기획](../planning/chapter-2-plan.md) §§3,6 | 불시착선 → 공구대 → 제독 샤워 → 발사장으로 이어지는 기존 시작 동선과 Stage1 완료 후 진입 구조 보존 |
| §7 크레인·컨테이너 | 기존 회전축·이동 훅·승강기·뚜껑에 모델 피벗 연결. 고정 발판은 회전부와 분리 |
| §§8,9 사다리·체결 | 높이 변경 시 모델 프레임과 작업 발판이 기존 상태를 따름. 로켓 3개는 독립 Rigidbody 유지, 모델 볼트 9개에 체결 색상 연결 |
| §10 오염·제독 | 유독 탱크·샤워·분사기 외형 연결. 기존 가스 영역과 판정 유지 |
| §12 멀티·복구 | 기존 호스트 판정과 복제 상태를 읽는 외형 추종만 추가. 상호작용 ID 26개 및 장비 참조 보존 |
| §15 미정 요소 | 필터대와 필터는 환경 소품이며 신규 필수 기믹으로 채택하지 않음 |

식생에는 충돌체가 없다. 벽에는 단순 충돌체를 사용하고 핵심 장비의 기존 물리·상호작용 충돌체를 유지했다. 크레인의 고정 케이블 및 중복 발판 메시만 파생 메시로 정리했으며 원본 FBX는 보존했다. 초안의 공중 안내 문구는 숨기고 게임의 상호작용 안내를 유지했다.

볼트의 기존 상호작용 ID를 유지하면서 조작 위치는 모델 볼트 중심에 맞췄다. 실행 렌더에서 발견한 크레인 케이블의 분홍색 재질도 수정했다. LineRenderer를 추가하기 전에 훅 메시의 URP 재질을 확보하여 새 LineRenderer 자신의 기본 재질을 잘못 선택하지 않게 했다.

## 검증과 검수

- Unity 6000.5.4f1 배치 실행으로 새로고침·컴파일·씬 저장·5개 시점 렌더. 화면 직접 조작 없음.
- 씬 참조 검사: 상호작용 26개, 볼트 9개, 운반 파츠 3개, 누락 스크립트 0개. 식생 충돌체 없음.
- 자동 검증은 기존 Stage2·StageCatalog 회귀와 신규 통행 공간·복제 상태 외형 추종 테스트를 사용한다. 최종 결과는 [검증 자료](../../artifacts/stage2-art/README.md)를 참조한다.
- 이번 작업에서 실제 여러 PC의 동시 접속 플레이와 VR 성능 측정은 수행하지 않았다. 기존 네트워크 구현을 유지하고 복제 상태의 외형 반영을 자동 검사한다.
- 모델은 기존 저폴리곤 초안 품질이다. 상세 노화 PBR, LOD, 베이크 조명 및 최종 성능 튜닝은 별도 작업이다.

## 편집 유지보수
