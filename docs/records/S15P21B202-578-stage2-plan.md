## 목적

로컬에 작성한 2장 기획과 이미지 초안을 팀이 검토할 수 있도록 최신 논의와 일치시키고, AI 실험 변경이 섞이지 않게 공유한다.

## 작업 내용

- 기획서에 컨테이너 개방·인양, 이동식 사다리, 수동 렌치와 마우스 회전 체결 방향을 반영했다.
- 크레인 조종석 승강기와 한시적 방독면은 제안·미정 사항을 구분해 기록했다.
- 최신 v2 맵 시안과 이전 v1 시안·프롬프트를 단일 Stage2 자료 폴더 아래에 정리했다.
- 전동 체결기·고정 발판 시안은 폐기하지 않고 이전안으로 표시했다.
- 문서 색인을 최신 develop 내용에 추가했고 기존 AI 실험·Unity 변경은 가져오지 않았다.

## 검증 결과

- 2026-09-17 Windows에서 변경된 Markdown의 상대 링크 209개와 명시적 section 앵커를 검사했다. 누락 없음.
- PNG 10장의 SHA-256이 원본과 일치하며 10장 모두 Git LFS 추적을 확인했다.
- 변경 19개 파일이 모두 docs/ 안에 있으며 공백 오류 검사를 통과했다. 커밋 직전 fetch 기준 develop과 분기 기준이 같음을 확인했다.
- Unity 실행·컴파일·물리·네트워크 테스트는 수행하지 않는다. 이번 변경은 문서와 2D 시안만 포함한다.

## 결정과 근거

- 기획서는 기능 기준, 컨셉 이미지는 시각 참고로 분리한다. 그림의 훅 위치·인원수 등 오차를 규칙으로 오해하지 않도록 명시했다.
- 별도 develop 기반 브랜치로 올려 AI 실험의 커밋과 변경이 유입되지 않게 한다.
- 사용자 요청 범위는 Jira 등록과 브랜치 push이며 MR 생성·develop 병합은 포함하지 않는다.
