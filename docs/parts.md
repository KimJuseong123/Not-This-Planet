# 파트 구분 및 역할 배분

> ⚠️ **이 문서는 살아있는 문서입니다.** 파트 구분과 역할 배분은 프로젝트 진행에 따라
> 바뀔 수 있습니다. 변경 시 이 문서를 수정하고 하단 변경 이력에 한 줄 남겨주세요.
> Jira 이슈 제목의 `[파트]` 태그는 이 문서를 기준(source of truth)으로 합니다.

## 1. 파트 태그

인원(6명)이 아니라 **게임 개발의 작업 영역** 기준으로 나눈다.
한 사람이 여러 파트를 겸할 수 있고, 하나의 파트를 여러 명이 나눠 맡을 수도 있다.

| 태그 | 영역 | 범위 | 담당 팀원 |
| --- | --- | --- | --- |
| `[Plan]` | 기획 | 게임 기획, 레벨 디자인, 밸런싱, 기획 문서 | TBD |
| `[Art]` | 3D 아트 | 모델링, 텍스처, 애니메이션, VFX | TBD |
| `[UI]` | UI/UX | UI 디자인, uGUI 구현, HUD, 메뉴 | TBD |
| `[Sound]` | 사운드 | BGM, 효과음, 오디오 믹싱 | TBD |
| `[Character]` | 물리 & 캐릭터 조작 | 캐릭터 컨트롤러, 물리, 카메라, 입력 | TBD |
| `[Puzzle]` | 퍼즐 & 레벨 상호작용 | 퍼즐 메커닉, 인터랙션, 레벨 스크립팅 | TBD |
| `[Network]` | 네트워크 & 멀티플레이어 | 세션, 동기화, 매치메이킹 | TBD |
| `[QA]` | QA | 버그 탐색·기록·트래킹, 테스트 플레이 관리 | TBD |
| `[Infra]` | 개발 환경 | Git/Jira/CI 운영, 빌드 파이프라인, 프로젝트 설정 | TBD |

- 어느 태그에도 안 맞는 작업이 반복되면 태그를 새로 만들지 말고, 먼저 팀에서 논의 후
  이 표에 추가하고 사용한다.

## 2. 역할 배분 초안 (팀장 제공 원안)

### 기획
- 레벨 디자이너

### 디자인
- 3D 아티스트
- UI
- 사운드

### 개발
- 물리 & 캐릭터 조작
- 퍼즐 & 레벨 상호작용
- 네트워크 & 멀티플레이어

### 마감
- QA (버그 탐색 및 기록 관리)

### 원안 → 파트 태그 매핑

| 원안 | 태그 |
| --- | --- |
| 레벨 디자이너 | `[Plan]` |
| 3D 아티스트 | `[Art]` |
| UI | `[UI]` |
| 사운드 | `[Sound]` |
| 물리 & 캐릭터 조작 | `[Character]` |
| 퍼즐 & 레벨 상호작용 | `[Puzzle]` |
| 네트워크 & 멀티플레이어 | `[Network]` |
| QA | `[QA]` |
| (원안에 없음 — 운영상 필요하여 추가) | `[Infra]` |
