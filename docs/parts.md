# 파트 구분 및 역할 배분

Jira·MR 제목에 사용하는 파트 태그와 담당자를 정의합니다. Task의 태그는 실제 작업 영역, Epic의 태그는 완료 판정 책임을 나타냅니다. 담당이나 태그가 바뀌면 연동 설정과 변경 이력도 갱신합니다.

[문서 안내](README.md) · 관련: [Jira 이슈 작성](jira-convention.md)

> 파트 구분과 담당은 작업 진행에 따라 갱신합니다. 변경 시 §3 이력과 §1의 연동 설정을 함께 수정합니다.
> Jira 이슈 제목의 `[파트]` 태그와 MR 제목의 파트는 **이 문서가 기준(source of truth)** 입니다.

## 1. 파트 태그 13종

인원(6명)이 아니라 **게임 개발의 작업 영역** 기준으로 나눕니다. 한 사람이 여러 파트를 겸할 수 있고, 한 파트를 여러 명이 나눠 맡을 수도 있습니다.

| 태그 | 영역 | 범위 | 담당 팀원 | Epic |
| --- | --- | --- | --- | --- |
| `[Plan]` | 기획 | 게임 기획, 레벨 디자인, 밸런싱, 기획 문서 | 송승우 | -8 |
| `[Art]` | 3D 아트 | 모델링, 텍스처, 애니메이션, VFX | 이수진 · 김주성 | -10 |
| `[UI]` | UI/UX | UI 디자인, uGUI 구현, HUD, 메뉴 | 미정 | -11 |
| `[Sound]` | 사운드 | BGM, 효과음, 오디오 믹싱 | 미정 | -12 |
| `[Character]` | 캐릭터 조작 | 캐릭터 컨트롤러, 카메라, 입력 | 미정 | -13 |
| `[Physics]` | 물리 · 행성 환경 | 중력·물리 튜닝, 행성 스케일 환경 | 미정 | -41 |
| `[Puzzle]` | 퍼즐 · 상호작용 | 퍼즐 메커닉, 인터랙션, 운반체 | 김주성 | -14 |
| `[Level]` | 레벨 구성 | 스테이지 배치, 기믹 구성 | 미정 | -42 |
| `[Network]` | 네트워크 · 멀티플레이 | 세션, 동기화, 매치메이킹 | 금준영 | -15 |
| `[Backend]` | 서버 · API | 서버, 프로토콜, 중계 | 최재현 | -43 |
| `[Data]` | 데이터 · 저장 | 세이브, 데이터 테이블 | 금준영 | -44 |
| `[Infra]` | 개발 환경 | Git/Jira/CI 운영, 알림, 빌드, 프로젝트 설정 | 금준영 | -9 |
| `[QA]` | QA | 버그 탐색·기록·트래킹, 테스트 플레이 관리 | 미정 | -16 |

- **담당 팀원** = 그 파트에서 실제로 작업하는 사람. **Epic 담당자** = 그 파트의 완료 판정 책임자이며, 담당이 정해지지 않은 파트는 당분간 **팀장(김수호)** 입니다.
- 담당이 `미정` 인 파트의 이슈도 만들 수 있습니다 — 이슈 담당자를 직접 지정하면 됩니다.
- 어느 태그에도 안 맞는 작업이 반복되면 태그를 새로 만들기 전에 팀에서 먼저 논의합니다.

### 태그를 늘리거나 이름을 바꿀 때 함께 고쳐야 하는 곳

사람이 읽는 곳과 기계가 읽는 곳이 따로 있어서, 한 곳만 고치면 이슈·MR이 규칙 위반으로 잡힙니다.

| 무엇 | 어디 |
| --- | --- |
| 이 표 (사람이 읽는 기준) | `docs/parts.md` |
| 제목 검사 정규식 | Jira 자동화 **R2** — [jira-gitlab-automation.md](./jira-gitlab-automation.md) §R2 |
| MR 제목·레이블 검사 | `scripts/ci/ci_common.py`의 `PARTS` |
| 파트 → 팀원 매핑 (알림 멘션) | `scripts/ci/team.json`의 `members[].parts` |
| Jira 레이블 | 사이트 레이블에 태그와 **글자까지 같은** 값이 있어야 함 |

## 2. 원안과의 매핑

팀장이 준 역할 배분 원안(기획 / 디자인 3 / 개발 3 / 마감)을 파트 태그로 옮긴 결과입니다.

| 원안 | 태그 |
| --- | --- |
| 레벨 디자이너 | `[Plan]` |
| 3D 아티스트 · UI · 사운드 | `[Art]` · `[UI]` · `[Sound]` |
| 물리 & 캐릭터 조작 | `[Character]` · `[Physics]` |
| 퍼즐 & 레벨 상호작용 | `[Puzzle]` · `[Level]` |
| 네트워크 & 멀티플레이어 | `[Network]` · `[Backend]` · `[Data]` |
| QA | `[QA]` |
| (원안에 없음 — 운영상 필요해 추가) | `[Infra]` |
