- **결정 사항**: 대화에서 사용자가 정한 배경, 장비 치환, 크레인 움직임과 시야, 이동식 사다리, 수동 회전 체결, 컨테이너 획득 과정을 뜻한다. 팀 전체 승인이나 구현 완료를 뜻하지 않는다.
- **설계 제안**: 결정된 방향을 플레이 가능한 규칙으로 연결하기 위한 초안이다. 테스트 후 변경할 수 있다.

### 2026-09-18 추가 결정: 배수로 물과 이동

사용자 요청으로 발사장 일부에 실제 들어갈 수 있는 흐르는 배수로를 추가한다. 얕은 곳은 이동 속력이 느려지고, 깊은 곳은 무중력처럼 부유하며 이동한다. 기존 고소 작업용 사다리와 크레인 역할을 대체하지 않는다.

- 동쪽 기존 배수로를 Terrain으로 파고 얕은 둑과 양끝 경사, 깊은 중앙 수로를 연결한다. 작업 동선에는 건널 다리를 둔다.
- 수면은 흐르는 잔물결, 주변 반사, 굴절, 깊이에 따른 투과·색 변화, 물가 포말, 입수한 캐릭터 주변 물결로 표현한다.
- 얕은 물 감속은 잠긴 정도에 따라 점진적으로 적용한다. 깊은 물에서는 WASD 이동, 기존 상승/하강 입력(Space/Ctrl)을 재사용한다. 입력을 놓으면 관성으로 감속하며 깊이를 유지한다.
- 물 밖에서는 정상 중력이 복구된다. 다리 위, 탑승 중, 작업대 이동 잠금 상태에 수중 이동이 적용되지 않아야 한다. 기절 중에는 수영 입력을 받지 않는다.
- 배수로 자체는 오염 누적 또는 제독 장치가 아니다. 물에 들어간다고 기존 오염이 지워지지 않는다. 익사·산소·소모 자원은 추가하지 않는다.
- 정적 물 영역은 서버와 로컬 예측이 같은 좌표로 판정하고, 캐릭터 결과는 기존 이동 동기화를 따른다. 미세 수면 물결은 표시 전용이다.
- 초기 구현값: 폭 7m/길이 60m, 수면 -0.12m, 중앙 바닥 약 -2.5m, 최대 얕은 물 감속 50%, 수영 수평 1.65m/s·수직 1.15m/s, 물 흐름 0.3m/s. 확정 밸런스가 아니다.

## 한 줄 요약

외계 행성을 탈출한 탐사대가 우주선 손상으로 멸망한 지구에 불시착한다. 버려진 발사장에서 크레인 조종사와 작업자가 위치를 주고받으며 인류의 로켓을 쌓고 체결하고, 유독물질에 오염된 동료를 분사기로 씻어주며 지구를 탈출한다.

<a id="section-2"></a>

## 목적과 1장과의 차이

1장이 운반·적층·접합·탈출이라는 기본 루프를 배우는 장이라면, 2장은 익숙한 목적을 다른 장비와 환경에서 수행하며 협력을 응용하는 장이다.

| 역할 | 1장 | 2장 |
| --- | --- | --- |
| 탈출 수단 | 외계 우주선 | 인류의 로켓 |
| 운반 장치 | 이동하는 견인 모듈과 저중력장 | 축이 고정된 크레인 |
| 작업자 이동 | 저중력장에서 부양하며 작업 | 이동식 사다리를 배치하고 발판에서 작업 |
| 배치 협력 | 견인 위치와 파츠 배치 조정 | 조종사의 사각지대를 동료가 안내 |
| 접합 | 플라즈마 용접 | 수동 렌치로 볼트·너트 체결, 클릭 유지 + 마우스 원형 이동 |
| 파츠 획득 | 흩어진 모듈 접근·고정못 해제 | 보관 컨테이너를 연 뒤 크레인으로 인양 |
| 위협 | 운석 낙하와 충격 | 방사능 또는 유독물질이라는 배경의 오염 위협 |
| 대응 | 방망이로 운석 반사 | 분사 장비로 동료의 오염 제거 |

2장의 차별점은 **조종·안내·체결·제독이 서로 다른 위치에서 동시에 필요한 상황**에 둔다. 컨테이너 개방은 파츠 획득의 기본 과정이며, 컨테이너마다 다른 퍼즐이나 긴 탐색을 붙일지는 기본 루프 검증 후 판단한다.

<a id="section-3"></a>

## 배경 및 도입

### 확정된 이야기

1. 탐사대가 1장에서 조립한 우주선으로 행성을 탈출한다.
2. 비행 중 운석에 맞아 우주선이 고장 난다.
3. 멸망한 지구에 불시착한다.
4. 기존 우주선 대신 지구의 로켓을 조립해 다시 탈출해야 한다.

### 도입 연출 제안

- 불시착한 우주선과 손상된 외계 장비를 보여준다.
- 가까운 곳에 버려진 발사대, 이동식 사다리, 크레인과 파츠 보관 컨테이너가 보인다.
- 태블릿에 새로운 로켓의 형태와 목표를 전달한다.
- 준비 구역에서는 안전하게 주변과 도구를 확인한다.
- 첫 인양·체결을 경험한 뒤 작은 오염 상황으로 제독 장비를 소개한다.

1장 전체 조작 안내를 다시 반복하지 않는다. 크레인, 사다리, 체결, 제독처럼 달라진 동작을 실제 사용 시점에 짧게 안내한다. 컷신 길이·건너뛰기·장 간 전환 방식은 후속 확정한다.

<a id="section-4"></a>

## 핵심 경험과 설계 원칙

### 핵심 경험

- 조종사는 보이지 않는 접합면을 동료의 안내로 맞춘다.
- 작업자는 접합부에 맞춰 사다리를 옮겨 설치하고 올라가 체결한다.
- 크레인이 하중을 받치는 동안 다른 사람이 연결부를 조인다.
- 분사 담당자는 오염된 동료를 찾아 현장을 오가며 작업을 이어갈 수 있게 돕는다.
- 실수로 기울거나 떨어진 파츠를 다시 들어 올려 복구한다.
- 외계 장비에 익숙한 탐사대가 지구의 투박한 작업 장비를 사용하는 대비를 즐긴다.

### 설계 원칙

1. **역할은 직업이 아니라 현재 행동으로 나눈다.** 누구나 조종·체결·제독을 맡거나 교대할 수 있다.
2. **정보 차이가 협력을 만든다.** 조종사의 모든 시야를 가리는 것이 아니라 정밀 배치에 필요한 정보가 지상·발판 작업자에게 더 잘 보이게 한다.
3. **지원 담당자가 이동한다.** 오염된 작업자가 매번 작업을 중단하고 지상으로 내려오게 하지 않는다.
4. **지원만 계속하게 만들지 않는다.** 짧게 제독한 뒤 다른 작업을 도울 여유가 있어야 한다.
5. **사다리는 이동 수단이다.** 정밀 등반이나 불안정한 승하차를 핵심 난관으로 삼지 않는다.
6. **실수는 복구 가능해야 한다.** 파츠 유실·끼임·접근 불가로 진행이 막히지 않게 한다.
7. **핵심 협동부터 검증한다.** 크레인의 사각지대, 심한 흔들림, 오염, 자원 부족을 처음부터 모두 겹치지 않는다.

<a id="section-5"></a>

## 핵심 게임 루프

```text
태블릿과 발사장을 보고 목표 파악
  → 파츠 보관 컨테이너 개방
  → 인양 경로 확보 및 훅 연결
  → 크레인으로 들어 올려 이동
  → 작업자가 이동식 사다리를 배치하고 접합 높이까지 이동
  → 동료의 안내로 파츠 위치 조정
  → 크레인이 받쳐주는 동안 볼트 체결
  → 하중을 풀어 연결 상태 확인
  → 인양 연결 해제
  → 다음 파츠 조립
  → 로켓 완성 및 탈출
```

작업 중 오염이 발생하면 분사기를 든 동료가 찾아가 제독한다. 제독은 모든 단계 사이에 반복 삽입되는 고정 절차가 아니라, 현장의 위험 상태에 따라 발생하는 지원 행동이다.

대표 장면: 조종사가 상단 파츠를 받치고, 발판 작업자가 위치를 안내한 뒤 체결한다. 오염이 쌓이면 지원 담당자가 아래층이나 같은 층에서 분사한다. 체결이 끝나면 작업자가 물러나고 조종사가 하중을 천천히 풀어준다.

<a id="section-6"></a>

## 콘텐츠 1: 발사장 파악과 작업 준비

### 목표

탈출에 필요한 로켓, 사용할 장비, 파츠 위치와 작업 동선을 알아본다.

### 공간 구성 제안

| 구역 | 기능과 배치 조건 |
| --- | --- |
| 불시착·준비 구역 | 시작 위치, 목표 확인, 도구 학습. 초반 안전 확보 |
| 중앙 발사대 | 로켓 하단을 고정하고 상단을 조립하는 중심 공간 |
| 이동식 사다리 작업 구역 | 넓고 평평한 설치 면, 접합부 접근과 제독 사선 확보 |
| 크레인과 조종석 | 파츠 적치장과 발사대에 모두 도달할 수 있는 위치 |
| 파츠 보관 컨테이너 | 개방 후 인양 연결. 크레인 작업 반경 안에 배치하고 상부 인양 경로 확보 |
| 크레인 승강기 후보 | 고정 기둥 옆에서 조종석까지 접근. 로켓 체결용 사다리와 역할 구분 |
| 장비·제독 구역 | 도구 보관과 솔로용 고정식 제독 설비 제안 |
| 오염 발생 시설 | 파손된 배관·탱크 등. 위험 방향과 예고를 읽을 수 있게 배치 |

### 레벨 배치 원칙

- 크레인의 최솟값·최댓값 작업 반경과 작업 높이로 모든 필수 인양 지점에 도달할 수 있어야 한다.
- 회전축 바로 아래처럼 크레인이 닿지 않는 사각 구역에 필수 파츠를 두지 않는다.
- 사다리가 로켓을 완전히 둘러싸거나 인양해 들어오는 방향을 막지 않게 한다.
- 난간·기둥·사다리·작업자의 대기 위치를 인양 경로와 함께 설계한다.
- 사다리 출입구에 파츠를 내려놓아 유일한 동선을 막는 상황을 방지한다.
- 약간 어긋난 조립을 허용할 여유를 확보하되, 허용 범위를 벗어난 배치까지 모든 접합부에 접근할 수 있다고 가정하지 않는다.
- 바닥 구역 번호·색상 표식으로 공통 방향 기준을 제공한다. 정답 위치나 자동 조립 가이드는 아니다.

### 컨테이너 개방과 인양

- 로켓 파츠는 보관함·컨테이너 안에 들어 있으며, 열어야 꺼낼 수 있다.
- 상부가 열리는 뚜껑 또는 분할 지붕을 제안한다. 측면 문만 열리고 천장이 남으면 수직 인양이 막힌다.
- 열린 문·지붕, 파츠, 훅·와이어, 작업자의 대기 공간이 서로 간섭하지 않도록 치수를 맞춘다.
- 입구에서 파츠를 식별하고 큰 인양 고리에 접근할 수 있어야 한다. 로켓 파츠를 실물로 옮기는 과정은 유지한다.
- 첫 컨테이너는 단순한 개방으로 가르친다. 잠금 방식·개방 조작·추가 협동 퍼즐·가스 누출과의 연계는 미정이다.
- 가스 때문에 컨테이너에 접근할 시점을 고를 수는 있지만 방독면 소진으로 필수 파츠가 영구 봉쇄되지는 않게 한다.

### 태블릿과 안내

- 2장 로켓의 실루엣과 조립 순서를 보여준다.
- 크레인 조작, 체결, 제독의 새 규칙을 그림 중심으로 짧게 안내한다.
- 정확한 체결 완료 정보의 노출 범위는 미정이다. 1장 UI 규칙을 그대로 복사하지 않는다.
- 로켓의 파츠 수·실루엣·조립 순서는 에셋과 작업 높이를 함께 검토한 뒤 확정한다.

<a id="section-7"></a>

## 콘텐츠 2: 크레인 인양과 협동 배치

### 목표

고정축 크레인으로 파츠를 들어 옮기고, 동료의 안내를 받아 기존 파츠 위에 배치한다.

### 결정된 움직임

| 축 | 동작 |
| --- | --- |
| 회전 | 고정된 중심축을 기준으로 팔이 좌우 원운동 |
| 작업 반경 | 회전축과 인양 지점 사이의 거리를 조절 |
| 인양 높이 | 와이어를 감거나 풀어 물체를 올리고 내림 |

작업 반경은 회전축에서 인양 지점까지의 거리이며 지름과 구분한다. 팔 위에서 트롤리가 앞뒤로 이동하는 방식은 구현 후보이지 확정 외형은 아니다.

### 시야와 안내

- 크레인 팔과 조종석 구조가 조종사의 정면 아래 시야를 가린다.
- 큰 이동과 대략적인 파츠 위치는 확인할 수 있지만 접합면의 간격과 맞물림은 보기 어렵다.
- 지상 또는 작업 발판의 동료가 가까이서 보고 위치를 안내한다.
- 1차 시험에서는 사각지대를 없애는 하향 보조 카메라를 제공하지 않는다.
- 시야 차단 정도는 2인 테스트로 조절한다. 조종사가 장시간 아무 판단 없이 지시만 기다린다면 과도한 차단이다.
- 회전 방향, 중심 쪽·바깥쪽, 상승·하강처럼 구분되는 표현과 바닥 표식을 활용한다. 서로 보는 방향이 다른 상태에서 단순히 “왼쪽”만 요구하지 않는다.

### 인양 연결 제안

1. 파츠에 크고 식별 가능한 인양 고리를 둔다.
2. 크레인 훅을 접근시키고 작업자가 상호작용해 연결한다.
3. 파츠를 들어 올리고 회전·반경·높이를 조절한다.
4. 목적 위치에서 크레인이 받쳐주는 동안 체결한다.
5. 작업자가 안전한 위치로 물러나고 조종사가 천천히 하중을 푼다.
6. 체결 상태를 확인하고 와이어에 장력이 없는 상태에서 해제한다.

작은 고리에 정밀 조준을 반복하게 하지 않는다. 느슨하지 않은 와이어를 해제할 수 있는지, 해제 조건을 어떻게 보여줄지는 상세 설계에서 확정한다.

### 조작과 물리 제안

- 입력을 놓으면 회전·반경 이동이 감속 후 정지하고, 인양 높이는 유지한다.
- 조종석에서 내려도 위치를 유지해 2인·솔로의 역할 교대를 지원한다.
- 정밀 작업용 저속 조작을 제공한다. 구체적인 키 배치는 미정이다.
- 파츠 흔들림은 약하게 시작한다. 조종 난이도와 사각지대의 영향을 구분해 테스트한다.
- 기본 3축 외에 파츠 자체의 회전·비틀림을 어떻게 제어할지는 미정이다. 첫 시험은 결합 방향이 단순한 파츠를 사용해 별도 회전 조작 없이 가능한지 확인한다.
- 크레인 전복·와이어 파단·복잡한 다중 걸이는 초기 범위에서 제외한다.

### 조종석 엘리베이터 제안

- 긴 사다리 대신 고정 기둥 옆 승강기로 조종석에 오르는 방향을 검토한다.
- 지상과 상부 양쪽에 호출 수단을 두고, 조종사가 내린 뒤에도 다시 탑승할 수 있게 한다.
- 고정 승강장과 회전 조종석의 연결에는 원형 통로 또는 안전한 정렬·정지 규칙이 필요하다. 이동 중 틈새 추락·끼임을 방지한다.
- 조종석 승강기는 로켓 체결용 장비가 아니다. 작업자는 별도의 이동식 사다리를 사용한다.
- 조종석 교대 시간, 제독 접근, 솔로 왕복을 검증한다. 승강기 치수·속도·탑승 인원은 미정이다.

<a id="section-8"></a>

## 콘텐츠 3: 사다리와 고소 작업

### 목표

저중력 빔 대신 사다리와 작업 발판으로 높은 접합부에 접근한다.

### 이동식 사다리와 작업 발판

- 사다리는 고정 배경이 아니라 플레이어가 들고 옮겨 설치하는 장비로 둔다.
- 넓은 지지대와 작은 상단 발판을 가진 접이식 A형 작업 사다리를 우선 제안한다. 정확한 형태와 운반 인원은 미정이다.
- 운반 상태에서는 접고, 안정적인 지면에서 펼쳐 설치하는 방식을 검토한다.
- 설치한 사다리로 접합부까지 올라가 안내·체결한다. 최상단까지 닿는 높이와 발판 면적은 로켓 크기와 함께 결정한다.
- 사람이 올라가 있을 때는 이동·접기·회수를 막는 것을 초기 안전 규칙으로 제안한다.
- 기존 v1 그림의 고정 타워와 층별 모듈 적층은 이전안이다. 최신 기본 접근 수단으로 사용하지 않는다.

### 이동과 안전 제안

- 도구를 소지한 채 사다리를 이용할 수 있다. 등반 중에는 도구 사용을 제한한다.
- 사다리 위·아래 진입과 발판으로 넘어가는 동작은 안정적으로 연결한다.
- 좁은 사다리의 교행과 반대편 진입 충돌은 검증 항목으로 둔다.
- 발판을 너무 좁게 만들어 체결하려다 상시 추락하게 하지 않는다.
- 인양 중 파츠와 사다리 사이에 작업자가 끼이지 않도록 대피 공간을 확보한다.
- 기절한 동료가 발판에 남아도 다른 사람이 접근해 제독·구조할 수 있어야 한다.

안전 공간과 정식 오염 차폐 공간은 구분한다. 사다리의 작업 발판이 자동으로 오염 면역 구역이 되는 것은 아니다.

<a id="section-9"></a>

## 콘텐츠 4: 볼트 체결과 조립

### 목표

크레인으로 배치한 로켓 파츠를 볼트·너트와 체결 도구로 연결한다. 용접건은 2장의 기본 접합 장비로 사용하지 않는다.

### 체결 방식 제안

- 연결부에 브래킷을 걸고 큰 볼트를 조이는 방식을 우선 검토한다.
- 약간 어긋난 배치도 허용 범위 안에서는 연결할 수 있도록 한다.
- 허용 범위 밖에서는 체결이 되지 않는 이유를 거리·기울기·접합부 상태로 확인할 수 있어야 한다.
- 총 같은 전동 체결기 대신 몽키스패너 등 수동 공구 형태를 우선한다. 망치는 외형 후보로 언급됐지만 원형 조임 동작에 맞는 기본 도구는 수동 렌치로 제안한다.
- 첫 시험에서는 볼트·너트를 개별 소모품으로 운반하지 않는다. 외형과 체결 행동부터 검증한다.
- 하단 파츠는 발사대에 고정하고 이후 파츠부터 크레인으로 받쳐 조립하는 방식을 제안한다.

### 클릭 유지 + 마우스 회전 체결

1. 큰 볼트에 공구를 대고 클릭을 유지한다.
2. 마우스를 원형으로 움직여 공구를 돌리고 체결을 진행한다.
3. 클릭을 놓으면 체결 조작을 끝내고 일반 시점 조작으로 돌아온다.

입력 방식은 사용자가 요청한 방향이며 아래 판정은 설계 제안이다.

- 유효한 볼트에 공구를 건 동안만 마우스 입력을 체결에 사용해 시점이 함께 빙빙 돌지 않게 한다.
- 완벽한 원 대신 대략적인 회전도 인식하고, 커서가 화면 끝에 닿아 입력이 막히지 않게 한다.
- 긴 반복 회전보다 짧고 읽기 쉬운 손동작을 우선한다. 회전량·체결 시간·감도는 테스트 후 결정한다.
- 체결 진행을 공구·볼트 움직임과 소리로 보여준다. 반대 회전으로 풀기, 중간 진행 유지, 접근성 대체 입력은 미정이다.

### 접합 상태 제안

| 상태 | 의도한 결과 |
| --- | --- |
| 미체결 | 크레인이 받치지 않으면 분리되거나 낙하할 수 있음 |
| 임시 체결 | 일부 지점만 연결되어 흔들리거나 한쪽으로 처질 수 있음 |
| 충분한 체결 | 크레인의 하중을 풀어도 안정적으로 유지 |

볼트 위치와 조여진 외형, 도구 소리, 파츠의 물리 반응으로 상태를 읽게 한다. 임시 체결이 구체적으로 어떤 힘까지 버티는지는 물리 검증 후 정한다.

크레인이 하중을 받친 상태에서 체결하고, 하중을 점진적으로 넘겨 연결을 확인하는 과정이 핵심이다. 발사 때만 숨겨진 품질 때문에 실패하게 만드는 규칙은 아직 확정하지 않는다.

## 방해 요소와 대응: 오염·제독

### 위협의 방향

멸망한 지구의 오염이 작업을 위협한다. 최신 시각 방향은 맵 곳곳에 퍼진 유독 가스이며, 방사능을 별도 규칙으로 포함할지는 미정이다. 방망이를 대신해 소방관의 방수총을 연상시키는 분사 장비로 동료를 씻어준다.

첫 구현에서는 **우주복 표면에 유독성 분진·액체가 쌓이는 오염**으로 규칙을 단순화하는 것을 제안한다. 내부 중독·방사선 피폭·표면 오염을 별도 수치로 동시에 구현하지 않는다. 방사능을 실제 플레이 위협으로 채택할 경우 분사기로 제거할 수 있는 범위를 별도로 정의해야 한다.

### 오염 발생 제안

- 파손된 배관이나 탱크에서 오염이 간헐적으로 발생한다.
- 노출된 작업자에게 오염이 누적된다.
- 위험 전에 누출음, 시설 경고등, 분출 전조 등으로 예고한다.
- 발사장 전체가 항상 같은 강도로 오염되는 방식은 피한다.
- 초반에는 안전하게 새 도구를 익히고, 이후 작업 구역과 오염 구역이 겹치게 한다.
- 오염 구역에서 벗어나면 추가 누적을 멈추되, 기존 오염의 자연 감소 여부는 미정이다.
- 층별 오염 범위를 명확히 한다. 눈에 보이는 오염은 아래층인데 위층까지 이유 없이 피해가 발생하지 않게 한다.

### 한시적 방독면 — 추가 아이디어

- 맵 곳곳에서 방독면을 주워 잠시 중독을 막는 아이디어를 검토한다. 필수 진행 장비로 확정하지 않는다.
- 게임 규칙은 방독면 = 신규 오염 누적 예방, 분사기 = 이미 쌓인 표면 오염 제거로 구분하는 안을 우선한다.
- 기존 오염을 방독면 착용만으로 지우거나 모든 위협에 면역이 되게 하지 않는다.
- 지속 시간, 효과량, 자동/수동 착용, 개수, 재사용·보충 여부는 미정이다.
- 헬멧을 쓴 토끼 캐릭터와 어울리는 필터 부착 방식이 필요하다. 그림의 마스크를 실제 방독면 성능이나 방사선 방호의 표현으로 해석하지 않는다.

### 상태와 피드백 제안

| 단계 | 피드백과 역할 |
| --- | --- |
| 낮음 | 우주복에 얼룩이 나타나 동료도 상태를 인지 |
| 주의 | 경고등·개인 경고음으로 지원 필요성을 전달 |
| 위험 | 충분한 예고 후 행동 불능에 이를 수 있음 |

주의 단계에서 조작 반전·심한 화면 왜곡을 기본으로 넣지 않는다. 핵심 작업이 불쾌하게 느껴지는지 먼저 확인한다. 행동 불능 전환 시점과 구조 조건은 미정이다.

### 분사 장비 제안

- 물대포처럼 전방으로 제독액을 분사한다. 명칭은 ‘제독 분사기’를 임시 사용한다.
- 팀원에게 맞으면 오염이 줄어든다. 맞고 있다는 시각·청각 피드백을 제공한다.
- 일정한 분사 폭을 줘서 정밀 사격보다 동료 지원에 집중하게 한다.
- 사선이 확보되면 아래층에서 위층으로, 발판 사이로 분사할 수 있다.
- 벽·바닥을 관통하지 않는다. 난간 사이의 판정은 실제 분사 효과와 일치시킨다.
- 자기 자신을 완전히 씻는 기능은 초기 제안에서 제외하고 솔로 대안으로 고정식 제독 설비를 검토한다.
- 초기에는 탄약·제독액 보충과 호스 끌기를 제외한다. 분사기의 외형과 별개로 실제 호스 연결은 미정이다.
- 분사 충격으로 팀원을 밀어 떨어뜨리는 기능은 초기 범위에서 제외한다.
- 분사기는 낙상·물리 충격을 모두 회복시키는 만능 치료 도구가 아니다.

### 이동 지원의 재미

분사 담당자가 작업자를 찾아다니는 것을 기본으로 한다. 오염된 사람이 매번 사다리에서 내려와 치료받는 왕복은 기본 루프로 만들지 않는다.

- 누구의 오염이 더 심한지, 어느 작업이 중단되면 팀 전체가 멈추는지 보고 지원 순서를 고른다.
- 높은 층까지 무조건 따라 올라가기보다 사거리가 닿는 발판이나 난간 위치를 찾는다.
- 작업자도 잠깐 난간 쪽으로 나와 분사를 받는 식으로 협력한다.
- 짧게 씻어준 후 분사 담당자가 체결·인양 준비 등 다른 작업을 도울 시간이 있어야 한다.
- 조종사를 제독하려면 조종석으로 분사가 도달하거나 조종사가 안전하게 잠깐 나올 수 있어야 한다. 밀폐 유리 너머로 분사하는 모순은 피한다.
- 분사 담당자도 오염될 수 있다. 동료에게 도구를 넘기거나 고정식 제독 설비를 이용할 대안을 마련한다.

### 초기 테스트값

| 항목 | 시작 가설 | 확인할 것 |
| --- | --- | --- |
| 안전 상태에서 위험까지 | 일정 강도의 연속 노출 45~60초 | 제독 요청과 도구 전환에 충분한 여유가 있는가 |
| 집중 제독 시간 | 주의 수준의 오염 제거 약 3~5초 | 오래 붙어 있지 않고 작업으로 복귀할 수 있는가 |
| 분사 사거리 | 인접 작업층의 동료에게 닿는 수준 | 이동의 의미를 유지하면서 사다리 왕복을 줄이는가 |
| 안전 구간 | 첫 인양·체결 학습 동안 확보 | 첫 시도부터 새 조작과 위협이 겹치지 않는가 |

지속 노출 중 제독의 순감소량, 분사 폭, 중첩 분사, 오염 구역 이탈 후 상태 등은 상세 설계에서 수치화한다. 위 값은 실측 결과가 아니다.

<a id="section-11"></a>

## 예상 진행 흐름

### 초반: 지구 장비 학습

1. 지구에 불시착하고 발사장과 로켓 조립 목표를 확인한다.
2. 컨테이너, 크레인 승강기 후보, 체결 도구와 분사 장비를 발견한다.
3. 첫 컨테이너를 열고 낮은 작업 높이에서 인양 연결과 3축 조작을 익힌다.
4. 동료의 안내로 첫 파츠를 배치하고 체결한다.
5. 작은 오염 상황에서 몸의 오염 표시와 제독 방법을 배운다.

### 중반: 높아지는 작업과 역할 교대

6. 다음 컨테이너를 열어 파츠를 들어 올리고, 작업자는 사다리를 옮겨 설치한 뒤 발판으로 이동한다.
7. 조종사에게 보이지 않는 접합면을 가까이서 확인하며 안내한다.
8. 크레인이 받치는 동안 체결한다.
9. 오염이 발생하면 분사 담당자가 이동해 작업 중단을 줄인다.
10. 체결과 하중 해제를 확인한 뒤 다음 작업으로 넘어간다.

### 후반: 조립 확인과 탈출

11. 최상단 파츠를 배치하고 남은 연결부를 확인한다.
12. 크레인의 와이어와 로켓을 분리하고 발사 경로를 확보한다.
13. 완성된 로켓으로 탈출한다.

탑승·발사 조작, 필수 체결 완료 조건, 발사 실패 여부, 엔딩 연출은 미정이다. 연료·배선·별도 발사 암호를 자동으로 필수 콘텐츠에 추가하지 않는다.

## 인원수·실패·복구·멀티플레이

### 인원수별 작업 제안

| 인원 | 기본 진행 |
| --- | --- |
| 1명 | 크레인 위치 유지 후 내려가 확인·체결, 고정식 제독 설비 사용 |
| 2명 | 조종 / 안내·체결로 나누고 필요할 때 제독 역할로 전환 |
| 3명 | 조종 / 안내·체결 / 이동 제독·지원 |
| 4명 | 조종 / 체결 / 인양 연결·안내 / 제독·지원, 상황에 따라 교대 |

- 솔로의 오염 강도·발생 간격은 완화하는 방향으로 검토한다.
- 여러 사람이 버튼을 계속 누르고 있어야만 가능한 단계를 필수로 두지 않는다.
- 2명일 때 인양한 물체를 안전하게 유지하고 조종사가 잠시 제독을 도울 수 있어야 한다.
- AI 동료는 별도 실험 기능이다. AI가 크레인·사다리·제독을 수행한다고 가정해 인원수 부족을 해결하지 않는다.
- 조종사의 사각지대로 생기는 솔로 왕복이 지나치게 길면 솔로 전용 보조 방식을 추가 검토한다.

### 실패와 복구 제안

- 핵심 로켓 파츠와 필수 도구는 소모되어 사라지지 않는다.
- 떨어진 파츠는 다시 인양하고, 잘못된 체결은 풀어 재배치한다.
- 크레인이 닿지 않는 곳으로 유실된 파츠에는 복구 수단이 필요하다. 복귀 위치·조건·물리 정지 처리 방식은 미정이다.
- 도구가 높은 층이나 파츠 사이에 끼어도 회수가 가능해야 한다.
- 오염으로 행동 불능인 동료는 제독과 구조를 통해 복구하는 방향으로 검토한다. 제독만으로 자동 기상하는지는 미정이다.
- 전원 행동 불능, 낙상, 솔로 자동 복구는 현재 게임의 공통 규칙을 확인한 뒤 확정한다. 과거 1장 초안의 수치를 그대로 복사하지 않는다.

### 멀티플레이 요구사항

- 동시 조종석 진입을 처리하고 크레인 조종 권한은 한 명에게만 부여한다.
- 크레인의 회전·반경·와이어 길이, 파츠 연결과 하중 상태를 참여자들이 일관되게 본다.
- 볼트의 체결·해제, 오염 누적·제독·행동 불능 판정을 공통 권한 기준으로 처리한다.
- 조종사의 연결 종료 시 하중과 크레인이 위험하게 방치되지 않고 다른 사람이 조작을 이어갈 수 있어야 한다.
- 분사 시각 효과와 실제 제독 대상의 불일치를 검사한다.
- 컨테이너의 개방 상태, 승강기의 위치·문·탑승 상태, 사다리의 운반·설치·점유와 방독면 획득 충돌을 동기화한다.
- 구체적인 동기화 방식은 구현 전에 [네트워크 동기화 정책](../network-sync-policy.md)을 기준으로 설계한다. 이 문서는 현재 해당 기능이 구현되어 있다고 주장하지 않는다.

## 결정 사항

- 1장에서 완성한 우주선은 운석에 맞아 손상되고 지구에 불시착한다.
- 지구는 멸망한 환경이며, 탐사대는 인류의 로켓을 조립해 탈출한다.
- 견인 장치를 크레인으로 치환한다.
- 크레인은 축이 고정되어 있고 회전·작업 반경·인양 높이를 조절한다.
- 크레인 팔 때문에 조종사의 정면 아래 시야가 가려져 동료의 안내가 중요하다.
- 저중력 빔으로 작업자를 띄우지 않고 사다리로 올라가 작업한다.
- 용접 대신 나사·볼트·너트와 체결 도구를 사용하는 방향이다.
- 도구는 총 같은 형태보다 수동 공구 형태를 우선하고, 클릭한 채 마우스를 원형으로 움직여 체결한다.
- 사다리는 들고 다니며 작업 위치에 배치한다. 고정 작업 타워는 이전안이다.
- 파츠는 보관함·컨테이너 안에 있고, 먼저 열어야 크레인으로 꺼낼 수 있다.
- 최신 맵 시각 방향은 유독 가스가 퍼진 폐허 발사장이다.
- 위협은 방사능 또는 유독물질 계열이며 최종 세부 규칙은 미정이다.
- 방망이의 위협 대응 역할은 물대포 형태의 분사 장비로 대체한다.
- 분사기를 든 동료가 현장을 오가며 오염된 팀원을 씻어주는 협동을 중심으로 한다.

- 발사 중 부실 체결에 따른 실패 연출
- 더 강한 하중 흔들림, 다중 걸이, 크레인 파손
- 체크포인트와 재도전 시 초기화 범위
- 2장 컷신, 성공 후 다음 장 연결

### 현재 초기 범위에서 제외

- 새 적이나 보스, 복잡한 자원 경제
- 강제 고정 직업과 전원 동시 버튼 입력
- AI 동료의 신규 장비 조작을 기본 진행의 전제로 삼는 설계
- 실제 물리 기반의 고난도 크레인 시뮬레이터 수준 조작

## 최소 시험판과 완료 조건

### 최소 시험판

- 고정식 크레인 1대
- 발사대와 고정된 로켓 하단 1개
- 인양할 상단 파츠 1개
- 이동식 사다리와 작업 발판 1개
- 수동 렌치 1개와 접합부 체결 지점 3개 가설, 마우스 회전 입력
- 상부 개방 컨테이너 1개와 크레인 조종석 승강기 블록아웃 후보
- 제독 분사기 1개
- 켜고 끌 수 있는 오염 구역 1곳
- 솔로 복구·제독 대안의 임시 장치

### 검증 순서

| 단계 | 구성 | 핵심 질문 |
| --- | --- | --- |
| 1 | 크레인 + 파츠, 오염 없음 | 2명이 조종·안내로 위치를 맞추는 것이 재미있는가? |
| 2 | 컨테이너 + 이동식 사다리 + 수동 체결 | 꺼내기·사다리 설치·원형 체결이 협동을 돕고 반복 노동이 되지 않는가? |
| 3 | 오염 + 제독 추가 | 지원 담당자의 이동과 우선순위 판단이 생기는가? |
| 4 | 1~4인 진행 + 복구 | 솔로 완주와 인원별 역할 교대가 가능하고 실수에서 복구할 수 있는가? |

### 플레이 테스트 확인 항목

1. 목표와 새 장비의 용도를 긴 설명 없이 이해하는가.
2. 조종사가 큰 이동을 스스로 판단하고 정밀 배치 때 동료의 안내를 활용하는가.
3. 안내하는 사람이 파츠의 움직임과 접합 간격을 읽을 수 있는가.
4. 방향 전달의 혼란이 적절한 대화로 이어지는가, 조작을 포기하게 만드는가.
5. 크레인 팔·컨테이너 뚜껑·사다리·로켓·작업자가 상시 충돌하거나 끼이지 않는가.
6. 사다리 왕복과 도구 회수보다 실제 협동 작업에 충분한 시간을 쓰는가.
7. 체결 상태와 하중 해제의 결과를 이해하고 잘못된 연결을 복구하는가.
8. 분사 담당자가 누구를 먼저 도울지 판단할 수 있는가.
9. 제독이 끝난 뒤 다른 행동을 할 시간이 있는가.
10. 인접 층 제독이 가능하고 벽을 관통하는 판정 불일치가 없는가.
11. 분사 담당자 자신이 오염됐을 때도 복구 방법이 있는가.
12. 2인에서 조종·체결·제독을 무리 없이 교대하고 솔로도 막히지 않는가.
13. 여러 클라이언트에서 파츠 위치·체결·오염·제독 결과가 일치하는가.
14. 전체 경험이 1장의 외형 교체를 넘어 새로운 협동으로 느껴지는가.
15. 승강기의 고정 승강장과 회전 조종석 사이를 안전하게 오가고 다시 호출할 수 있는가.
16. 사다리에 사람이 있을 때 이동·접기로 추락시키지 않는가.
17. 회전 체결 때 시점이 함께 돌지 않고 마우스가 화면 끝에 막히지 않는가.
18. 방독면을 채택하면 예방과 제독의 차이를 이해하고 어느 한 도구가 다른 도구를 무의미하게 만들지 않는가.

## 2026-09-18 추가 시험 요소 — 배수 압력 역류

사용자 요청으로 가스 외의 작업 방해 요소를 추가한다. 배수로·폐산업 시설의 노후 펌프에서 고압 물줄기가 통로를 가로지른다. 누적 오염/제독 역할과 겹치지 않도록 오염·직접 피해는 추가하지 않고 짧은 물리 밀침만 준다. 조립 진행과 볼트 체결량은 보존한다.

- 첫 부품 체결 전에는 비활성. 이후 42초 주기로 펌프 한 대만 선택한다. 주기 0~12초 준비, 12~18초 경고, 18~21초 분출, 나머지 휴지기. 세 대를 순환한다. 수치는 테스트값이다.
- 경고등, 압력계, 바닥 분출선, HUD로 위치와 대응을 알린다. 8m 길이의 좁은 물줄기는 벽에 차폐되며, 뒤쪽·먼 곳·높이 벗어난 작업자는 맞지 않는다.
- 감압 손잡이 E로 해당 펌프를 45초 억제한다. 도구·동료 상시 배치를 요구하지 않아 솔로도 대응한다. 호스트가 거리·시선·기절 여부를 확인한다.
- 조종석/사다리에서 이동이 잠긴 작업자와 이미 기절한 작업자는 밀지 않는다. 물로 가스를 씻거나 오염을 제거하지 않는다. 제독 분사기/고정 샤워의 역할은 유지한다.
- 조립 통로 진입, 동측 작업 통로, 배수로 인접 정비 구역에 배치한다. 준비·리스폰·고정 샤워 구역과 필수 발사 집결 지점은 피한다.
- 서버가 주기/감압/밀침을 계산한다. 기존 Stage2 상태 스냅샷에 주기와 감압 잔여 시간을 포함하여 도중 합류도 같은 경고·분출을 본다. 클라이언트는 시각 효과만 재생한다.
- 최종 멀티 실측에서 2.4m/s 충격은 보행 제동으로 약 7cm에 그쳐 4.5m/s로 보정했다. 호스트에서 0.6초 동안 약 28cm 밀침을 확인했다. 같은 대상의 재피격 간격은 0.65초로 유지하며 계속 테스트할 밸런스 값이다.
