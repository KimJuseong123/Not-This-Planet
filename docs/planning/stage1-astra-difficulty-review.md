# Astra ver2 물리 레벨 난이도 검토

대상: `METAGAME/Assets/Scenes/Stage1_Astra_ver2.unity` — 180 × 150m 탐사 기지 배치의 후속 보완.

## 참고와 적용 범위

[Human: Fall Flat 공식 판매 소개](https://www.nintendo.com/us/store/products/human-fall-flat-switch/)는 여러 경로와 탐색·창의적 해결을 강조한다. 여기서는 그 원칙을 참고했다. 아래 난이도 판단과 배치 처방은 Astra의 기존 코드·충돌체·시설 동선을 검토한 자체 설계이며, HFF의 내부 난이도 수치나 구현을 인용한 것이 아니다.

## 진단

기존 확장 맵은 시설의 존재 이유와 넓은 화물 귀환로가 명확하지만, 도구가 많다는 사실만으로 학습 순서가 생기지는 않았다. 가벼운 물건에서 익힌 조작을 핵심 파츠에 적용할 공간, 높은 곳에서 실패했을 때 쉬고 재시도할 자리, 위험 지역 진입 전 준비할 자리가 부족했다.

| 권장 진행 | 기존 부담 | 보완과 의도 |
|---|---|---|
| 물류장 / 입문 | 처음부터 무거운 파츠와 고정못을 조작 | 옆의 낮은 하역대 두 개, 4kg 연습 상자, 7kg 널판지, 지렛대·롤러로 작은 물건부터 실험. 주 통로를 막지 않는 선택 과제 |
| 관측소 / 초중급 | 연속 점프 실패 후 아래부터 재시도 | 중간 높이 3.4m·5.6m 유지보수 발판 두 곳. 옆으로 떨어졌을 때 머물고 다음 돌부리로 복귀. 자동 체크포인트나 모든 추락을 막는 구조는 아님 |
| 정비소 / 중급 | 도구를 바깥에서 가져와야 좁은 공간에서 회전 가능 | 실내 뒤쪽에 짧은 롤러 두 개와 지렛대·받침 추가. 바닥 회전 궤적으로 자세를 바꿀 위치 암시 |
| 격리실 / 협동 심화 | 탐색·다이얼·발판·반출이 겹침 | 지뢰 바깥 준비 구역과 운반 가능한 경로 표식 여섯 개. 탐색 결과를 동료와 공유. 안쪽에는 열린 문 유지용 안전 받침 두 개 |

2026-09-15 사용자 요청으로 **휴식 / 선택 실험 항목을 제외**했다. 파츠 회수와 직접 연결되지 않는 축구·비치볼·볼링·운석 농구·도미노·샌드백·시소·트램펄린·대관람차와 전용 코트·탑승 대기 시설은 씬에서 제거한다. 널판지·롤러·지렛대·썰매·경사판·쌓기 상자는 운반 도구로, 대포·로켓·그래플링은 탐사 이동 수단으로 유지한다. 실제 파츠 운반 조작을 연습하는 물류장은 유지한다.

진행 순서를 강제하지 않는다. 색상 광선으로 목적지를 선택하고, 익숙한 팀은 바로 어려운 시설로 갈 수 있다. 대포·로켓·그래플링은 선택 해법이다. 귀환은 기존 넓은 도로와 화물 승강기를 활용하며, 견인장치나 연료를 필수화하지 않았다.

## 추가 오브젝트

씬 루트 `Expedition physical learning and recovery` 아래에 증분으로 배치했다.

- 물류 연습장 (-22, -28): 상자 1, 널판지 1, 지렛대 1, 롤러 2 = 동적 물체 5. 낮은 하역대 2와 접근 계단. 다리 사이에 빠져도 평지다.
- 관측소 (-64.4, 37.4), (-62.4, 46): 외측 턱이 있는 휴식 발판 2와 지지대. 기존 돌부리·승강기·정상 진입을 유지한다.
- 격리실 외부 (39, 24.6): 준비 원형 표시, 무게 중심이 낮은 중공 깃발 6. 깃발은 탐지 결과를 자동 판정하지 않는다. 사용자가 확인한 곳을 직접 표시하는 물건이다.
- 격리실 내부 (43.1, 37.2 / 38.4): 안전 받침 2. 문 가장자리 (45.6 / 50.4, 35)의 주황 표시로 배치 위치를 암시한다.
- 정비소 내부 (47.1, -40) 부근: 지렛대 1, 짧은 롤러 2 = 동적 물체 3. 실내 회전 궤적과 지렛대 받침.

총 동적 물체 16개. 기존 Grabbable, Rigidbody, AstraV2CargoTool 경로를 사용하므로 서버 물리 동기화 수집과 맵 밖 물체 복구에 포함된다. 새로운 프레임 루프나 별도 기믹 동기화 시스템을 추가하지 않았다.

## 보존한 난이도와 주의할 해석

격리실 최초 개방은 기존처럼 회로 해결 + 살아 있는 플레이어의 발판 점유가 필요하다. 안전 받침은 이미 열린 문이 화물에 닫히지 않도록 하는 기존 안전 센서를 활용한다. 발판을 대신 밟거나 닫힌 문을 강제로 여는 물건이 아니다. 따라서 이 방의 최초 접근은 여전히 협동 과제이고, 전체 스테이지의 1인 클리어 가능성을 새로 보장한 변경은 아니다. 한 번 열린 뒤에는 받침을 넣어 역할을 바꿀 수 있다.

지뢰를 무해하게 만들거나 안전한 길의 답을 자동으로 그려주지 않았다. 탐색 중 이동 불가, 빠른 동심원과 빨간 LED, 글자 없는 경고 표지는 유지한다. 휴식 발판도 낙사 도랑을 없애거나 모든 실패를 무효화하지 않는다.

핵심 파츠의 색상 광선, 조립대 요구 색, 고정못과 파츠의 끈, 다이얼 목표 눈금, 발판 발자국·배선은 그대로 둔다. 새 바닥 표식은 물건과 같은 색·형태로 대응시켰다.

## 검증과 다음 관찰

자동 검증은 씬의 운반·보행 여유, 물리적 지지, 새 물체의 안정성, 안전 받침의 제한을 확인한다. 실제 초보자 완주 시간이나 체감 난이도는 이 검증으로 확정할 수 없다. 후속 사람 플레이에서는 시설별 최초 성공 시간, 관측소 추락 후 재진입 시간, 경로 표식 사용률, 정비소 회전 정체 시간, 발판 담당자의 대기 시간을 관찰하는 것이 적절하다.
