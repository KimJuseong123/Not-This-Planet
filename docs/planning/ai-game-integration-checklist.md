# AI 게임 통합 작업표 (2026-09-22)

## 목표 / 유지 사항
- V를 누르고 말하고 놓으면 방장 PC의 로컬 STT → LLM → 검증된 행동 로직으로 전달.
- 참가자는 모델 불필요. 방장의 추가팩 준비 상태를 사용. 유료 API 사용 없음.
- develop의 기존 HUD/태블릿/설정/로비를 제거하지 않음.
- 추가팩 설치/AI 사용 설정은 유지. 실험용 명령 버튼·텍스트 입력·대기 AI 테스트는 게임 UI에서 제거.
- 음성/인식 문장을 디스크에 기록하지 않음. 오픈 마이크는 근접 음성 채팅, V 구간만 AI 처리. 메뉴/포커스 상실/음소거 시 마이크 중지.

## 후속 고도화 / 별도 결정
- STT 인식 정확도 및 한국어 명령 변형 평가는 기능 연결 완료 후 진행.
- 폭풍 세기 자체는 기본 게임 밸런스이므로 이번 통합에서 임의 변경하지 않음.
- 복잡한 3D 항로, 특정 접합만 절단, 완전 자동 정답 조립은 완료로 간주하지 않음.
- 모델 팩 배포 URL/릴리스 승인과 다른 PC 다운로드 검증은 별도. 로컬 패키지가 있어도 공개 배포가 완료된 것은 아님.
- 실제 모델 검사 종료 후 Ollama 하위 llama-server 프로세스가 남는 현상 확인. 이번 검사 잔여 프로세스는 정리했지만, 종료 시 하위 프로세스 회수 강화는 후속 작업.
- 커밋/push/MR은 별도 요청 시 진행.

## 실행 / 작업 위치
- Unity: `S15P21B202-ai-integration-20260920/METAGAME`. 기존 로비로 실행 후 방장이 AI 사용 설정.
- 현재 팩: `artifacts/ai-pack/p3`. 이전 팩: `artifacts/ai-pack/p3-before-voice-20260922` (삭제하지 않음).
- 현재 p3는 최종 voice-v3 빌드. 실행기 의존성 self-test 통과. 중간 v1 백업은 `p3-voice-v1-20260922`와 `p3-voice-v1-residual-20260922`에 나뉘어 보존됨(이동 중 모델 프로세스 잠금 발생). 원본 pre-voice 백업은 별도로 그대로 보존.
- 공유 마이크에서 V 구간만 AI용으로 수집, 놓으면 전송. 최대 8초. 기존 설정의 마이크 장치/감도 사용.
- 추가 참가자는 자신의 음성을 소유한 NetPlayer를 통해 청크 전송. 방장 로컬에서만 모델 실행. 다른 명령 처리 중이면 쌓아두지 않고 다시 말하도록 안내.
- 이름/색/인원 지정은 LLM 계획을 사용. V 시작 시 20m 내 AI만 후보, 그중 가장 가까운 AI가 기본 대상. 상세: `docs/records/2026-09-22-proximity-voice.md`.
- 음성 접수 성공은 작업 완료가 아님. 실행 도중 물리 작업 실패는 남아 있을 수 있음.
- 종전 실행 파일은 자동으로 바뀌지 않으므로 새 게임 빌드가 필요. 배포 PC는 새 runtime 추가팩 필요.
- 오래된 별도 `AICompanionExperiment` 씬은 참고용으로 유지. 일반 게임 UI에서 실험 패널을 호출하지 않음.

## 2026-09-22 실제 모델 점검
- 기존 로컬 Whisper 및 Qwen3:1.7b 사용. 모델 다운로드/유료 API/사용자 마이크 녹음 없음.
- `나 따라와` → follow, `견인 장치에 타` → board_tractor, `못 다 뽑아줘` 및 `저기 남은 고정못 전부 빼줘` → pull_all_pins.
- 첫 요청 약 9.4초, 이후 2.1~2.2초. 소수 문장의 분류 검사이므로 전체 명령 정확도/실제 행동 성공을 보장하지 않음.
- 일반 행동에 부적절하게 붙는 approach 플래그는 해제하고, 유효하지 않은 계획은 실행하지 않으며 전체 AI 서버를 실패 상태로 바꾸지 않도록 수정.
- 분류 예시 4개를 프롬프트에 추가했으며 키워드 분기 대신 실제 LLM 판단 유지.
- 게임에서 우선 확인할 순서: 방장 AI 준비 → V로 따라오기 → 멈추기 → 못 전부 뽑기 → 견인 탑승. 이후 두 PC에서 참가자의 V 입력과 동시 요청 확인.
