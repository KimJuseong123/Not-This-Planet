## 실제 씬에서 발견한 문서와의 차이

- 원본에는 SpaceshipPart 4개, PartClamp 16개, PartSocket 8개, ShipAssembly 1개, SpaceBootstrap 1개가 있다.
- `PartTractorActivator.cs` 주석은 Part_1을 설명하지만 **실제 원본 씬의 컴포넌트는 Part_4에 있다**. ver2에서도 이 실제 연결을 유지한다.
- 실제 씬에는 PartPush가 없다. ver2는 `AstraV2ManualPart`를 통해 각 파츠에 PartPush를 연결한다. Part_4의 원본 활성화 과정이 PartPush/Grabbable을 끄므로, ver2에서만 미탑승 상태의 수동 조작을 되살린다. 탑승하면 수동 밀기는 비활성화한다.
- 원본의 색상 기둥은 모든 방향을 비추는 실제 직사광선 4개가 아니라 **발광 메시 기반 시각 안내**이다. 원본의 방향광 2개와 국소 점광 5개는 별도의 조명이다.
- 원본 태블릿 설명의 견인 파츠 표현과 실제 배치가 어긋나는 부분은 ver2에서만 새 파츠 설명으로 보완한다. 원본 씬용 정의는 변경하지 않는다.

## 새 맵의 접근과 반출

| 구역 | 실제 파츠 | 접근 | 견인 없이 중앙까지 반출 |
|---|---|---|---|
| A / 주황 | Part_1, 주 추진 모듈 | 시작 구역 옆 열린 공터 | 고정못 해제 → 수동 밀기 또는 롤러 → 평탄한 주황 경로 → 조립대 |
| B / 청록 | Part_2, 부양·안정화 모듈 | 7개의 돌출 바위, 단차 약 0.8m | 못 해제 → 정상 화물대에 밀기 → 정상에서 잠금 해제 → 브레이크 손잡이를 잡아 하강 → 지면 높이 하역 → 청록 경로 |
| C / 보라 | Part_3, 조종석 캡슐 | 회전 바늘 3개를 목표 홈에 정렬 → 발판 출현 → 살아 있는 동료가 밟아 문 개방 | 넓고 문턱 없는 출입구 → 롤러/지렛대 또는 수동 밀기 → 문 밖 대기 공간에 완전히 반출 → 발판 담당 합류 → 보라 경로 |
| D / 연두 | Part_4, 상단 조립·견인 모듈 | 열린 낮은 입구, 굽은 통로 | 파츠를 눕힌 상태로 못 해제 → 함께 밀고 방향 조정 → 회전 여유 공간 → 낮은 통로 → 연두 경로. 견인 탑승은 필수가 아님 |

컨셉 아트의 같은 캡슐 모양을 네 번 쓰지 않고 원래 모델/충돌체를 유지했다. D는 실제 Part_4의 눕힌 높이가 세운 높이보다 작다는 점을 사용한다. C의 동료 발판 조건은 원안대로 남아 있으므로 전체 스테이지를 1인 전용으로 바꾼 것은 아니다.

## 새 장치의 배려 요소

- 다이얼: 회전 바늘과 고정 목표 홈으로 방향을 읽게 하고, 맞춘 홈의 색이 변한다. 놓았다 다시 잡아 한 단계 회전한다. 완성 상태는 유지된다.
- 발판: 퍼즐을 해결하기 전에는 지면 아래에 있고 해결하면 올라온다. 발자국 문양과 연결선으로 서 있어야 하는 위치를 나타낸다.
- 문: 발판을 떠나면 닫히되, 출입구에 플레이어나 파츠가 있으면 닫힘이 멈춘다. 안전 센서만으로 닫힌 문이 열리지는 않는다.
- 화물대: 원래 파츠의 필수 못이 남아 있으면 정상 해제가 되지 않는다. 손잡이를 잡으면 천천히 내려가고 놓으면 멈춘다. 밑에 사람/화물이 있으면 하강이 멈춘다. 비어 있을 때만 복귀한다.
- 낮은 밀실: 몸은 들어갈 수 있지만 세운 파츠는 천장에 걸리는 차이를 이용한다. 넓은 회전 공간과 연속된 수평 바닥으로 막다른 운반 상태를 피한다.
- 롤러와 지렛대: 모든 구역에 물리 도구를 배치하고 기존 잡기 조작으로 다룬다. 움직이는 도구에는 WorldSync 추적 표식을 붙인다.
- 조립대: 반출로와 같은 높이의 원형 면. 경로는 원형 면 앞에서 끝나 조립대와 상태 색을 덮지 않는다.
- 장식의 충돌은 반출로 밖에 두고, 경로등과 연결선·발자국은 충돌을 만들지 않는다.

## 검증 기록 위치

### 지형·도구 확장 (2026-09-14)

물리 놀이터 추가: 서쪽 공놀이 공간의 장식 간섭을 정리하고, 축구골대·볼링 핀·도미노처럼 외형으로 사용법을 읽을 수 있는 물품을 배치했다. 파랑/주황 그래플은 갈고리와 케이블 릴, 초록 송풍기는 큰 팬 몸체로 구별한다. 들었을 때 클릭 유지·해제 안내를 제공한다. 트램펄린은 파란 면과 주황 테두리로 표시한다. 기존 핵심 파츠 색상과 요구 색상은 변경하지 않았다.

기존 안내 요소를 유지하며 주 운반 경로 밖에 붉은 테두리의 치명적인 도랑을 추가했다. Terrain은 조립대·밀실·반출 경로에서 평탄하게 유지한다. 도구 거점의 청록 로켓, 검보라 먹물, 노란 모서리 연료통으로 기능을 구별하고, 손에 든 도구의 클릭 안내와 연료 잔량을 표시한다. Part_4의 노란 주유 표시와 빈 탱크 문구로 연료가 필요함을 알린다. 별과 은하수는 기존 파츠 조명·조립대 색상을 대체하지 않는다. 추가 검증은 `docs/records/2026-09-14-astra-expansion.md`에 기록했다.

실제 컴파일·플레이 모드·그림·시험 결과는 `docs/records/2026-09-14-astra-ver2.md`에 기록한다. 컨셉 이미지나 코드 검사만으로 협동 플레이·완주가 검증됐다고 보지 않는다.

### 지뢰밭 추가 (2026-09-14)
Part 3 앞의 기존 다이얼/압력 발판/문과 운반 길을 유지하고, 지뢰 사이의 보행 경로 및 발판 분기를 확보했다. 경고는 글자 없는 삼각형 느낌표이며, 입구와 귀환 방향에 탐색기를 제공한다. 파츠는 지뢰를 작동시키지 않으며 플레이어는 감지 속도와 빨간 LED를 이용해 접근·귀환 경로를 찾는다. 상세: `docs/records/2026-09-14-astra-minefield.md`.

### 탐사 기지 확장 (2026-09-14)
맵을 180×150m로 넓히고 파츠별 직업/작업 시설을 부여했다. 하역·충전장, 대기 관측소, 시료 격리실, 채굴 정비소로 재배치하되 색 광선·조립대 요구 색·고정못 끈·회로선·발판 발 모양과 반출 기믹은 유지한다. 생활권의 숙소/식당/운동 시설과 산책로를 연결하고 위험 탐사 장비는 작업장 쪽으로 옮겼다. 태블릿 단서는 ver2 씬의 시설·사고 원인을 설명하도록 변경했다. 설계 분석: `docs/planning/stage1-astra-expedition-layout.md`.
