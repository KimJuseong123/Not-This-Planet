## 연결 및 검증 메모

- 별도의 조립 테스트 이름의 .unity는 찾지 못했다. 조립용 곡은 작업 목적에 따른 공용 제안이다. AICompanionTest는 메뉴 카메라와 AI Test Menu가 있는 테스트 진입 씬으로 확인했다.
- 현재 확인한 컷씬에 한정했다. Stage2 전용 엔딩 컷씬은 씬 목록에서 확인되지 않아 구현된 것으로 가정하지 않았다.
- Stage1_Ending 앞부분은 인원별 탑승 8~14초 + 발사 5초 + 사진 5초 + 타이틀 3초. 불시착은 그 뒤 23초다. 타이밍은 DemoEnding.cs, DemoEndingView.Arrival.cs 기준이다.
- 입장 운석 접근 6.8초·충돌 9초는 Stage1CutsceneScene.cs, 입장 총 18초와 공세 총 8초·공세 활성 5초는 Stage1Sequence.cs 기준이다.
- 컷씬 시간·루프 경계를 음악 생성기가 정확히 따르는 것은 보장되지 않는다. 편집과 실제 청취로 맞춘다. 곡 간 동일 모티프·조성 연결은 공통 참조 음원 또는 편곡으로 맞춘다.
- 로비/탐색에 이미 곡이 있으므로 해당 프롬프트는 교체·변주가 필요할 때 사용한다. 모든 테스트 씬에 별도 곡을 만들 필요는 없고 연습/조립 곡을 공유해도 된다.
- 소리 자체의 오류를 검사할 때는 BGM을 꺼서 효과음 누락·중복·클리핑을 분리해 확인한다.
- 기존 GameMusicPlayer의 페이드·5초 대기 재생과 제안한 무봉합 루프는 다르다. 컷씬 전환, 기존 곡 중복 재생, 음악·전체 음량, 늦은 참가자의 연출 시각, 반복 리셋 정리를 연결 시 검증한다. 테스트에서 Stage1 공용 AudioManager 자산을 바꾸면 본 게임에도 영향이 갈 수 있으므로 용도별 설정을 분리한다.
- 문서만 추가했다. 화면 조작·씬 변경·코드 변경·실행·빌드·청취 테스트는 하지 않았다.
