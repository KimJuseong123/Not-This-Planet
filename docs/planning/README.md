# 1장 기획 안내

[문서 안내](../README.md) → **1장 기획**

1장은 우주선 파츠를 찾아 조립하고 행성을 탈출하는 과정을 배우는 튜토리얼입니다. 기획 문서는 플레이 경험을 설명하는 기본 기획과, 이를 구현하기 위한 상세 기획으로 나눕니다.

| 읽는 순서 | 문서 | 목적 |
| --- | --- | --- |
| 1 | [기본 기획](chapter-1-plan.md) | 배경과 핵심 루프, 탐색·운반·적층·접합의 역할, 파트별 산출물 |
| 2 | [상세 기획](chapter-1-detailed-design.md) | 조작·장비·조립·용접·운석·기절·복구·발사 규칙과 초기 테스트값 |
| 3 | [작업 기록](../records/README.md) | 실제 구현, 기획과의 차이, 검증 결과와 후속 작업 |
| 참고 | [성공 컷신 초안](chapter-1-success-cutscene-draft.md) | 탈출 성공 연출의 초안. 확정 사양이 아니므로 상세 기획과 어긋나면 상세 기획을 따릅니다 |

기본 기획은 2026-08-26 초안, 상세 기획은 2026-08-29 작성 이후 보완된 문서입니다. 기본 기획의 미정 항목이 상세 기획에서 구체화된 경우가 있으므로 구현 전에는 상세 기획을 확인합니다. 상세 기획에서도 확정 규칙과 조정 가능한 초기 테스트값을 구분합니다.

에셋은 [카탈로그](../asset-catalog.md), 코드 구조는 [Unity 작성 규칙](../unity-convention.md), 플레이 검증은 기능별 [작업 기록](../records/README.md)으로 이어집니다.
