# 전체 도구·기믹과 모델 제작 명세

## 1. 공통 제작 목표

장기 체류 탐사대의 장비다. 기능을 먼저 드러내는 둥근 공업 형태, 두꺼운 손잡이, 큰 노즐, 모서리 보호대, 단순한 판독창을 사용한다. 움직이는 부품과 잡는 부분은 구분한다. 글자·숫자·알파벳을 텍스처에 굽지 않는다.

주황 손잡이, 노란 연료통 외곽, 빨간 위험 LED, 파츠별 기존 색은 유지한다. 색만으로 구분하지 않도록 로켓은 날개·배기구, 송풍기는 팬, 그래플링은 갈고리·릴, 탐색기는 탐지 코일, 연료통은 주입구·운반 손잡이, 먹물총은 액체 탱크를 보여준다.

아래 치수는 **미터**다. 휴대 도구는 현재 충돌체의 설계 공간을 먼저 제시한다. 외장 장식은 그 안에 가급적 넣는다. 부품 장식·그림판을 포함한 시각적 전체 범위와 충돌체 크기는 서로 다르다. 회전된 오브젝트의 `collider_world_size`는 축 정렬 바운딩박스이므로 FBX의 가로·세로·길이로 그대로 복사하지 않는다.

휴대 장비는 `Model`이 1인칭용으로 별도 복제·변형된다. 효과 발사점과 물리 루트는 메시와 별개다. FBX를 붙일 때 원래 장착 루트, `Muzzle`, 스크립트 참조를 삭제하지 않는다.

## 7. FBX와 분리할 효과

유지 대상: 로켓 배기, 그래플링 케이블, 송풍 방향선, 먹물 탄/자국, 탐색 동심원과 LED, 고정못의 끈, 회로 배선, 대포 도화선·불씨, TNT 케이블·폭발·파편, 지뢰 폭발·흔적, 게이지 채움, 파츠 안내 광선·조립대 요구 색.

이 효과들을 한 덩어리 메시나 고정 애니메이션으로 굽지 않는다. 렌즈·노즐·표시창·파편 메시를 제공하고 움직임과 수명·네트워크 상태는 기존 Unity 동작을 연결한다. 현재 없는 기믹 애니메이션을 FBX에 추가해도 게임 로직에 자동 연결되는 것은 아니다.
