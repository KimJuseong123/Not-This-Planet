# Astra ver2 — Blender 제작 인계

기준: 2026-09-15, `METAGAME/Assets/Scenes/Stage1_Astra_ver2.unity`.

이번 인계는 **현재 씬에 남아 있는 물품과 기믹**을 기준으로 한다. 삭제된 축구·농구·볼링·도미노·샌드백·시소·트램펄린·대관람차는 제작 대상이 아니다. 이 문서는 FBX 자체가 아니라, 외부에서 FBX를 제작하기 위한 기능·치수·분리 구조 명세다.

1. [전체 도구·기믹 및 모델 명세](model-brief.md): 무엇을 만들고, 어떤 조작·반응을 지원해야 하는지.
2. [직관성 검토와 적용 내용](interaction-audit.md): 글자를 대신하는 형태·배치·그림·피드백.
3. [제작 목록 CSV](asset-manifest.csv): 제작 단위별 ID, 수량, 우선순위, 분리 부품.
4. [씬 실측 CSV](scene-instance-inventory.csv): 개별 상호작용 오브젝트·제어부·위험 구역의 현재 위치, 루트 배율, 메시 범위, 충돌체 범위, 질량, 하위 이름. **FBX 개수와 행 수는 다르다.**
5. [FBX 제작·반입 규칙](fbx-handoff.md): 크기, 방향, 피벗, 노드, 재질, 반입 확인.
6. `reference/`: 현재 Unity 렌더와 글자 없는 아이콘 원본. 아이콘은 모양을 설명하는 참고이며 최종 제품 아트 수준의 완성 모델은 아니다.

권장 제작 순서는 휴대 도구 6종 → 발판·다이얼·승강기 제어부 → 대포·TNT → 수동 운반 물품 → 시설 외장이다. 기존 핵심 파츠와 방망이·용접기는 재사용 가능하므로 별도로 표시했다.

체감 직관성은 초보자 관찰로 최종 확인해야 한다. 그림을 추가했다는 이유만으로 모든 사용자가 설명 없이 이해한다고 단정하지 않는다.
