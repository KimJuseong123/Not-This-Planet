# 처음 하는 플레이어 관점의 직관성 검토

## 판단 기준

물건을 보기 → 잡거나 누를 곳 찾기 → 행동의 방향 알아보기 → 반응 확인 → 실패 원인 구분의 다섯 단계를 확인했다. 글자를 아이콘으로 치환하는 데 그치지 않고 실제 조작부 가까이에 그림을 놓고, 상태를 읽는 창을 추가했다.

월드의 기존 TextMesh 27개는 화면에서 숨기고 필요한 참조는 보존했다. 시설명·알파벳·동작 문장·TNT 글자·차량 연료 문장을 그림이나 게이지로 대체했다. 이 씬에서 Astra 휴대 도구의 문장형 HUD도 마우스·행동 그림과 게이지로 바뀐다. **기존 게임의 메뉴, 태블릿 선택 설명, 진행 상황·공통 조작 UI까지 모두 제거한 것은 아니다.** 처음 탐색하는 데 긴 설명문을 읽어야 하는 의존도를 줄이는 범위다.

## 검토 및 반영

| 대상 | 처음 볼 때의 문제 | 이번에 준비한 단서 | 검증/남은 관찰 |
|---|---|---|---|
| 파츠 목적지·조립대 | 색을 기억해야 하고 시설명이 영문 | 기존 색상 광선·요구 색·끈 보존. 파츠와 귀환 경로에 일치하는 모양 및 우주선 그림 추가 | 실제 파츠 식별과 조립 규칙 유지. 모든 색각 조건에서의 사용자 검증은 미실시 |
| 개방 파츠·운반 연습 | 무거운 파츠에 바로 힘을 써 실패 이유를 모름 | 작은 상자·받침·널판지·롤러를 가까이 배치한 기존 연습장 유지. 손→상자→다리→이동 그림 | 물리 연습은 선택 사항. 무거운 파츠가 가벼운 상자와 같은 힘으로 움직인다는 뜻은 아님 |
| 고정못 | 파츠를 당겨도 안 움직이는 이유가 보이지 않을 수 있음 | 기존 고리·발광·끈 유지. 승강기 해제부에 못 제거 그림 추가 | 못 해제와 파츠 이동의 인과관계를 사용자 관찰로 확인할 것 |
| 관측소 | 정상에 도착해도 다음 행동을 모름 | 돌부리 착지 색과 재시도 발판 유지. 위쪽 해제부, 하강 손잡이, 아래 복귀 조작을 서로 다른 그림으로 표시 | 승강기 동작과 하강·정지 조건은 그대로 |
| 화물대 | 해제·누름 유지·빈 상태 복귀가 혼동됨 | 못→손, 누르는 마우스→하강, 놓는 마우스→정지, 빈 상자/복귀 그림과 실제 해제/이동 게이지 | 그림 위치가 움직이는 데크를 따라가도록 부모 유지 |
| 3개 다이얼 | 다이얼 돌리기와 발판 생성의 관계가 문장에 의존 | 손·회전 다이얼→발자국→문 순서. 기존 바늘/목표 눈금과 회로선 유지 | '회전시키면 목표 눈금이 맞는다'가 초보자에게 보이는지 관찰 필요 |
| 협동 발판 | 상자를 올리거나 혼자 뛰어 들어갈 수 있다고 오해 | 사람+발자국, 상자+금지 그림. 발자국이 있는 실제 발판 유지 | 최초 개방은 플레이어 점유 필요. 솔로 해결을 새로 보장하지 않음 |
| 문 안전 받침 | 열쇠인지 웨이트인지 역할이 불명확 | 안쪽 받침 가까이 열린 문·받침·정지 그림. 기존 주황 가장자리 놓임 표시 유지 | 이미 열린 문만 유지. 닫힌 문을 여는 도구로 표시하지 않음 |
| 정비실 | 누운 파츠를 들어 올리려다 낮은 천장에 걸림 | 안쪽 지렛대·롤러와 바닥 회전 궤적, 두 사람·굴림·회전 그림 | 기존 실제 통과 규격 유지. 파츠를 바르게 세우는 그림을 쓰지 않음 |
| 로켓 | 먹물총과 비슷하여 탄환 발사를 예상 | 원통·핀·배기 구조와 사람+로켓 그림. 분리된 도구별 안내, 추진/냉각 HUD 게이지 | 실제 플레이어가 함께 비행하는지 유지 검사. 첫 사용의 비행 감각은 사람 테스트 필요 |
| 먹물총 | 전투나 파괴 도구로 오해 | 액체 탱크·물방울·시계로 임시 자국 표현 | 자국은 약 20초. 지뢰 표식은 장기 표시용 깃발을 사용 |
| 연료통·주입구 | 통·차량이 연결되는 대상인지, 빈 상태인지 모름 | 노란 외곽 보존, 주입 노즐, 양쪽 연료 그림, 통 잔량 창·차량 연료 게이지 | 실제 소비량과 표시 일치 확인. 차량 전체 주유 판정은 유지 |
| 그래플링·송풍기 | 둘 다 총처럼 보여 결과 방향이 혼동됨 | 갈고리·릴과 팬을 구분. 각 도구 위에 독립적인 누름 유지/당김/밀기 그림 | 고정 파츠나 조립체를 해제하는 기능은 없음 |
| 탐색기 | 이동이 멈추는 현상을 오류라고 생각할 수 있음 | 원형 코일·LED 유지. 멈춘 발자국+마우스 유지+위험 감지 그림. 들었을 때 HUD에도 발자국 | 원이 빠를수록 위험한 기존 반응 유지. 지뢰 없는 상태와 도구 미사용 상태의 구별은 후속 관찰 대상 |
| 경로 표식 | 깃발이 지뢰를 제거하는 도구처럼 보일 수 있음 | 탐색 후 깃발을 놓는 순서로 배치. 탐사 준비 구역에 표식 묶음 | 자동 판정·해제 기능 없음. 표식은 플레이어 판단의 공유 수단 |
| 대포 | 입구와 점화부의 역할, 다른 사람 필요 여부가 불명확 | 앞은 손·사람→대포, 뒤는 사람·손·시계→비행. 뒤쪽에 실제 탑승/도화선 게이지 | 최초 탑승 후 다른 사람이 점화. 원격 표시도 수신된 대포 상태를 사용 |
| TNT·바위 | 어느 바위가 파괴 가능한지, 어디 놓을지 모름 | 해당 바위와 TNT에 같은 폭발 문양, 바닥 설치 표시, 연결 케이블 유지. 설치 유효 범위에서 준비 LED | 준비 여부는 실제 거리와 손에서 놓인 상태를 읽음. 주변 지형 전체가 파괴 가능하다는 인상은 피함 |
| 낙사 도랑 | 평범한 지형 굴곡으로 오해 | 기존 깊이·지질 파손·경고 경계를 유지. 안전 귀환로는 분리 | 별도 퍼즐 답이나 새로운 낙사 규칙은 추가하지 않음 |
| 방망이·용접기 | 기존 장비와 새 장비의 시각 언어가 다를 수 있음 | 기존 모델과 조립/타격 기능 유지, Blender 인계에 재사용 대상으로 명시 | 공통 손잡이·노즐 디자인을 적용하는 것은 후속 모델 제작 범위 |

## 그림의 오해를 줄이기 위한 조정

첫 렌더에서 사각형 마우스가 창문처럼 보이고 발자국이 두 사람처럼 보일 여지가 있어, 둥근 마우스 외곽과 발바닥·발가락 형태로 수정했다. 여러 도구를 한 문장처럼 이어 놓은 안내는 분리해 '로켓 다음에 먹물과 연료를 써야 한다'는 오해를 줄였다.

폭파 위치 그림은 바위의 실제 앞면보다 앞으로 옮겨 가림을 해소했다. 기존 방망이·용접기는 도구 선반 앞에서 로켓을 가리지 않도록 옆에 배치하고 각각의 타격·용접 그림을 붙였다. 잔량 창은 플레이 시작 전에도 초기 잔량으로 표시되도록 맞췄다.

검증 가능한 것은 그림이 렌더되는지, 조작부를 따라 움직이는지, 잔량·준비 표시가 실제 상태를 읽는지, 물리·운반 동선을 방해하지 않는지다. **'설명 없이 이해했다'는 판단은 초보자 플레이 관찰 전까지 미확정**이다.

권장 관찰: 설명하지 않은 상태에서 각 도구를 집어 첫 유효 행동까지 걸린 시간, 잘못 누른 조작부, 지뢰 탐색 중 이동 정지를 오류로 오해했는지, 빈 연료통을 알아봤는지, 대포 입구와 뒤 점화부를 구분했는지를 기록한다. 답을 말해준 뒤의 성공은 직관성 성공으로 세지 않는다.
