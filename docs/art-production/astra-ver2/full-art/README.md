# Astra 전체 모델 제작·씬 적용

기준: 2026-09-15, `Stage1_Astra_ver2.unity`. 요청한 T01–T08, P02–P10, M01–M18, E01–E09 **44개 항목**을 검토했다.

## 제작 결과

- Blender 제작 모듈 90개, 총 72,166 삼각형(라이브러리 원본 기준).
- 기존 씬 대상 327곳에 외형 적용. 새 경고판을 포함하면 이 라이브러리를 사용하는 MeshRenderer 349개.
- M18: 기존 Terrain·낙사 트리거를 유지하고, 도랑 접근부에 양면 낙사 그림 경고판 11개 추가. 경고판에는 충돌체가 없다.
- 기존 그림 설명·귀환선·발자국·연료 잔량·탐색기 LED·퍼즐 상태 재질을 유지했다. 대포 탑승 그림판은 입구를 가리지 않도록 옆으로 옮겼다.
- P01 롤러 19개와 기존 핵심 파츠·방망이·용접기를 유지했다.

## 검증과 한계

저장 후 씬을 다시 열어 메시·재질·스크립트 누락이 없음을 검사했다. 23개 휴대 도구의 실제 `FirstPersonToolVisual` 복제·표시 전환과 3개 탐색기 LED 속성 복제를 Editor에서 확인했다. 원본 YAML 12,553개 레코드의 삭제는 없으며, 충돌체·질량·스크립트·상호작용 참조는 그대로다. 의도한 기존 Transform 이동은 대포 안내판 1개뿐이다.

- [기존 EditMode 테스트 결과](unity/editmode-results.xml): 66/66 통과. 기믹·운반 도구·지뢰·탐사장·안내·1인칭 도구 표시 관련 9개 테스트 클래스.
- [화물·보행 경로 검사](unity/routes.txt): 화물 hull/지지 718개 지점, 보행 캡슐/지지 1,152개 지점, 지뢰 안전 경로 2개 통과.
- [적용 목록](unity/integration.txt), [저장 후 재검사](unity/reload.txt), [1인칭 복제 검사](unity/first-person.txt), [전체 씬](unity/settlement-overview.png).

실제 플레이어의 조작감, 초보자의 그림 이해도, 다중 클라이언트 플레이는 별도 실플레이 확인 대상이다. 기존 지형과 건물 장식의 겹침, 일부 도구의 배치 겹침을 전면 재배치하지 않았다.

검수 중 장식 면의 겹침을 수정하고, 갱신한 파생 메시가 저장되도록 명시적으로 dirty 처리했다. 남는 그림자 경계의 계단 현상은 현재 씬 조명 설정에서 보이는 현상이며, 비교 렌더로 형상 겹침과 구분했다. 전역 조명 설정은 변경하지 않았다.

## 재현

`tools/build_astra_full_art.py`를 Blender MCP에서 실행하면 FBX·원본·매니페스트를 만든다. `tools/render_astra_full_art.py`는 Blender 검수 이미지를 만든다. Unity `Metagame.EditorTools.AstraFullArt.Apply`는 **전체 아트 적용 전의 씬**에 한 번 실행한다. 적용 마커가 있으면 중복 실행을 거부한다. 검증 스크립트는 격리 프로젝트에서 실행했으며 최종 에셋과 씬을 원래 프로젝트로 반영한다.
