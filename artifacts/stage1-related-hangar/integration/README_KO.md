# Stage1_Astra Hangar 주변 모델 교체

## 반영 결과

대상: `METAGAME/Assets/Scenes/Stage1_Astra.unity`

씬의 `Hangar Related - Concept Models` 아래에 13종 FBX를 25개 배치했다. 원래 통로·데크·교량·연석·계단 블록 15개와 해당 렌더러·충돌체는 제거했다. 새 충돌체는 Ground 레이어의 BoxCollider 28개다.

| 구성 | 수량 |
|---|---:|
| 남쪽 통로, 동쪽 랜딩, 경사로, 기초 데크 | 각각 1 |
| 파손 교량 0·1·2·5·6 | 각각 1 |
| 모듈 연석 | 10 |
| 화물 플랫폼 4단 계단 | 1 |
| 높이 조정 지지대 | 2 |
| 안내 표지 | 3 |

## 배치 보정

- FBX의 앞뒤 축을 보정하고 기본 미터 크기로 배치했다.
- 경사로는 원래의 낮은 진입점에서 데크 앞쪽으로 연결했다. 상단이 데크 아래에 묻히지 않도록 길이를 줄였고, 입구를 가로막던 연석에는 개구부를 확보했다. 기울기는 모델에 이미 들어 있으므로 중복 적용하지 않았다.
- 경사로 충돌체는 비균등 스케일이 걸린 모델과 분리하여 실제 보행 경사를 맞췄다.
- 파손 교량은 경사로와의 충돌을 피하도록 동쪽으로 2m 옮겼다. 번호별 간격은 유지했다. 5·6번은 기존처럼 이후에 덧댄 데크 아래의 잔존 구조로 놓인다.
- 화물 계단은 실제 플랫폼 외곽을 측정해 중심을 `(-9.5, 4.936, 18.940)`으로 이동했다. 기존 중심에서 남쪽으로 약 3.38m 이동했으며, 높이는 지면과 외곽 보행면에 맞춰 조절했다. 실제 네 단 높이는 약 5.072 / 5.179 / 5.286 / 5.393m다.
- 지지대는 지면이 검출되는 기초 데크 뒤쪽과 파손 교량 아래에 배치했다. 안내 표지는 진입부·경사로 상단·동쪽 연결부에 놓았다.

## 검증

- Unity 6000.5.4f1의 별도 프로젝트 복사본에서 가져오기·직렬화·렌더링을 수행했다.
- 통로 188개 지점에서 지면과 반지름 0.33m, 상단 높이 1.93m의 통과 공간을 확인했다.
- 경사로 39개 지점의 목표 높이 오차는 최대 약 0.0000013m였다.
- 저장한 씬을 다시 열어 계단 네 단, 렌더러 25개, BoxCollider 28개, 재질·텍스처 연결과 누락 스크립트 0개를 확인했다.
- 원본과 비교해 기존 GameObject 15개(직렬화 블록 75개)만 제거했다. 기존 블록 수정은 부모의 자식 목록과 SceneRoots뿐이다. 삭제한 오브젝트를 가리키는 잔여 참조와 새 자산 GUID 누락은 없다.
- 플레이 시작 검사는 현재 대피소 시작점 기준으로 플레이어 생성 및 기존 파츠 4개를 확인했다. 전체 경로를 실제 입력으로 주행하거나 멀티플레이·성능·빌드를 검증한 것은 아니다.

기존 `Stage1AstraIntegration.PlaySmoke`는 예전 시작점 `(-22, 0.4, -29)`을 기대해 최초 실행에서 실패했다. 검사용 복사본에서만 현재 저장된 시작점 `(-31.8, 0.346, -24)`으로 기대값을 맞춘 후 통과했다. 원본 프로젝트의 검사 코드는 변경하지 않았다. Unity Editor 검색 인덱스의 `SearchDatabase.EnumerateAll` 예외는 변경 전·후 씬 모두에서 동일하게 발생했고, 양쪽 모두 플레이어 생성과 파츠 4개 검사는 통과했다. 따라서 플레이 로그 전체가 오류 없이 실행되었다고 주장하지 않는다.

## 파일

- `hangar-overview.png`, `hangar-approach.png`, `hangar-entrance.png`, `cargo-entry-stairs.png`: Unity에서 촬영한 최종 씬.
- `placement-report.txt`: 제거·배치 내역.
- `saved-scene-validation.txt`: 저장 후 재열기 검사.
- `serialization-audit.json`: 원본·최종 해시 및 변경 범위 검사.
- `Stage1_Astra.before.unity`: 교체 전 백업. 복원이 필요하면 씬 파일만 교체하고 기존 `.meta`를 유지한다.
- `apply-6.log`, `play-smoke-current-spawn.log`, `play-smoke-baseline.log`: 최종 배치 및 플레이 비교 기록. 앞선 번호 로그는 연결부 간섭을 발견·수정한 중간 검사 기록이다.

원본 Unity 창을 강제로 닫지 않고 검증된 씬 파일을 반영했다. 기존 화면에 이전 상태가 남아 있다면 디스크 변경을 다시 불러오거나 `Stage1_Astra`를 다시 열면 된다.
