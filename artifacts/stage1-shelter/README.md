# Astra Shelter — Blender MCP 모델 패키지

Stage1_Astra의 Part1 옆 Shelter 컨셉 이미지들을 참고하여 Blender MCP에 연결된 Blender 5.2.1 LTS에서 제작했습니다. 모델 에셋 제공 단계이며 Unity 씬 교체는 수행하지 않았습니다.

## 파일

- `AstraShelter.fbx`: 부위별 19개 메시와 루트. 미터 단위, -Z Forward / Y Up.
- `AstraShelter.fbm/`: 2048×2048 PNG PBR 텍스처 6종. FBX와 같은 위치에 두는 텍스처 폴더입니다.
- `AstraShelter.blend`: 864개 세부 메시와 편집 가능한 bevel modifier, 재질·카메라·조명을 포함한 원본. 재질에서 사용하는 텍스처 5개는 packed 상태이며 URP용 추가 맵은 `.fbm`에 있습니다.
- `preview-*.png`: 외관, 정면, 오른쪽, 왼쪽, 후면, 위, 실내, 지붕을 숨긴 내부 구조.
- `validation.json`: FBX 재불러오기 및 기하 검사 결과.

## 모델링 상세

1. 낮고 넓은 곡면 지붕, 분할된 흰색 외피 패널, 앞뒤 아치형 지붕 프레임.
2. 지붕 아래 연속된 단열 라이너와 전후면 상부 마감으로 실내 천장을 구성했습니다.
3. 4개 코너 기둥과 넓은 하부 받침, 라벤더 인서트, 가스켓, 주황 상태 조명.
4. 정면의 큰 개방 출입구, 문틀, 문 포켓, 수납된 좌우 문짝, 문 레일, 제어판.
5. 출입 캐노피의 흰색 외피·라벤더 상판·청록 라이트와 모서리 상태등.
6. 경사 진입 램프, 바닥 패널 접합부, 미끄럼 방지 스트립과 가장자리 보호대.
7. 정면 창 2개, 좌우 측면 창 각 2개, 뒤쪽 창 2개. 입체 창틀·실링·금속 안쪽 테두리·청록 상단 조명.
8. 측면 서비스 패널, 분할 이음매, 전원 소켓, 상태등, 체결 나사.
9. 뒷면 라벤더 외장, 중앙 보강대, 두 개의 환기구와 실제 루버 메시.
10. 지붕 곡률을 따라 배치한 태양광 뱅크 2개: 총 108개 셀과 216개 금속 버스바, 외곽 프레임·실링·나사.
11. 뒤쪽 공조 설비: 정비 상판, 양면 흡배기 루버, 측면 패널, 상태등, 체결 나사.
12. 뒤쪽 왼편의 높이가 다른 안테나 2개, 마운트·소켓·발광 표시부·끝단.
13. 내부 바닥 타일 42개, 길 안내 표시, 가장자리 배수 그레이팅.
14. 실내 벽 보강대, 창턱, 범퍼, 하부 배관과 클램프, 후면 설비 제어판, 천장·벽 작업등.

큰 중앙 실내 공간은 비워 두었습니다. 창유리는 짙은 청록색의 불투명 PBR 재질 표현입니다. 좌우 문짝은 별도 정적 메시이며 실제 문 개폐 로직·애니메이션은 포함하지 않습니다. 수납된 문짝 형상은 열린 상태 기준이며, 닫힘 애니메이션을 만들 때에는 문짝 폭과 이동 거리를 추가 설계해야 합니다.

## 크기 및 메시

| 항목 | 값 |
| --- | --- |
| 본체 기준 | 약 14 × 12m |
| 전체 폭 × 깊이 × 높이 | 14.590 × 14.953 × 8.920m |
| 전체 크기 포함 항목 | 코너 받침, 출입 램프, 뒤쪽 돌출부, 안테나 |
| 지붕 중앙 높이 | 약 7.05m, 상부 설비 제외 |
| 입구 폭 | 약 4.4m |
| 바닥 높이 | 기초 0.32m / 타일 약 0.38m |
| 원본 세부 메시 | 864개 |
| FBX 부위 메시 | 19개 |
| FBX 정점 / 삼각형 | 108,512 / 213,704 |
| 재질 | 공통 PBR atlas 1개 |
| UV | UVMap: 재질 atlas 공유 / LightmapUV: 부위별 자동 전개 |

세부 곡면·프레임·태양광 부품의 베벨을 포함한 상세 모델입니다. 실제 게임의 LOD, 충돌체 단순화와 성능 튜닝은 별도 작업입니다. 건물 전체를 단일 볼록 충돌체로 감싸면 입구가 막히므로, 바닥·벽·램프를 나눠 충돌체를 구성해야 합니다.

## Unity URP Lit 재질 연결

FBX의 재질 참조는 포함돼 있으나 URP 자동 변환은 프로젝트 설정에 따라 달라질 수 있습니다. 아래 맵을 연결합니다. 주요 장식은 실제 메시이며 Normal 맵은 미세 표면 질감용입니다.

| 텍스처 | 연결 및 설정 |
| --- | --- |
| `AstraShelter_BaseColor.png` | Base Map, sRGB 켬, Base Color 흰색 |
| `AstraShelter_Normal.png` | Normal Map, Texture Type=Normal map, 강도 약 0.35 |
| `AstraShelter_MetallicSmoothness.png` | Metallic Map, sRGB 끔, R=Metallic / A=1−Roughness, Smoothness Source=Metallic Alpha, Smoothness 1 |
| `AstraShelter_Emission.png` | Emission Map, sRGB 켬, Emission 활성화. 흰색 배수부터 장면에 맞게 조정 |
| `AstraShelter_Metallic.png` | 다른 PBR 프로그램용 개별 Metallic, Non-Color |
| `AstraShelter_Roughness.png` | 다른 PBR 프로그램용 개별 Roughness, Non-Color |

Blender Emission Strength는 2.3입니다. 팔레트/트림 atlas 방식이므로 UVMap을 임의로 다시 펼치면 색 구획이 바뀝니다. Blender 원본의 촬영용 바닥, 카메라, 조명은 FBX에 포함하지 않았습니다.

## 검증

- Blender 원본을 별도 프로세스에서 다시 열어 확인: 모델 메시 864개, 내장 이미지 5개, 누락 이미지 0개.
- FBX 실제 재불러오기: 통과. 메시·정점·삼각형 수 유지.
- 재불러오기 크기 차이: 0.00001m 미만.
- 모든 FBX 메시에서 UV 2채널 유지, 참조 텍스처 누락 0건.
- 메시별 비매니폴드 에지와 극소 면적 면 검사: 0건. 다수의 폐쇄 부품으로 조립한 모델입니다.
- 태양광 버스바의 얇은 베벨에서 발견한 극소 면은 베벨 폭 조정 후 재검사했습니다.
- 입구 x=-1.7, 0, 1.7m, 높이 2m의 레이 검사: 출입구와 실내를 지나 후면 벽/설비에 도달.
- 외관·측면·후면·위·실내·지붕을 숨긴 내부 렌더를 확인했습니다.
- Unity 씬 배치, 콜라이더, 실제 플레이 및 성능은 이번 작업에서 검증하지 않았습니다.

제작 스크립트: 저장소 `tools/blender/build_astra_shelter.py`, `tools/blender/export_astra_shelter.py`. 출력 위치는 스크립트의 `BASE`에서 조정할 수 있습니다.
