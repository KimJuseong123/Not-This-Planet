# Stage2 최종 멀티플레이 검증 — 2026-09-18

기준: `246770f8`, 시작 시 깨끗한 603 브랜치. Unity 6000.5.4f1, Windows 개발 빌드, Mirror Telepathy / 127.0.0.1. 화면 직접 조작 없이 배치 빌드와 별도 호스트·클라이언트·도중 합류 관찰자 프로세스를 실행했다.

## 발견 및 수정

기존 검사는 경고/분출/감압 상태 복제를 확인했지만 원격 플레이어의 실제 이동량은 측정하지 않았다. 측정 검사를 추가하자 첫 실행에서 클라이언트의 0.4초 이동량이 0.034m였다. 서버를 별도 측정한 후속 실행에서는 분출 시작 후 0.6초에 0.072m였고, 시선 차폐 없음/분출 내부/조종석 잠금 없음이 확인됐다. 클라이언트에서도 1초 후 0.103m 이동하여 복제 누락과 구분했다.

보행 제동은 30m/s²이고 초기 2.4m/s 물줄기 충격은 빠르게 소거됐다. 해당 기믹에만 4.5m/s 충격을 적용했다. 일반 보행, 권한 모델, RPC, 오염, 조립 규칙은 변경하지 않았다. 감압을 위한 시험용 위치 이동은 서버 측 밀침 측정 0.6초와 클라이언트 측 측정 1초가 끝난 뒤에만 수행하도록 분리했다.

최종 서버 이동량은 분출 시작 후 0.6초에 **0.283m**, 클라이언트는 1초에 **0.365m**다. 두 값은 측정 구간이 다르며 둘의 차이를 위치 오차로 해석하지 않는다. 첫 실패의 원시 로그는 로컬 `pressure/`, 추가 진단 로그는 `pressure-measured/`에 남겼다. 위 수치와 실패 경위는 이 문서로 보존한다. 최종 통과만을 위해 검사 기준을 낮추지 않았다.

실제 인터넷 지연/패킷 손실, 4인 장시간 완주, 호스트 이전은 이번 실행 범위에 포함하지 않았다. 로컬 독립 프로세스 검증을 외부망 검증으로 간주하지 않는다.

## 재현

`Stage2Validation.BuildNetworkSmoke`로 빌드 후 `tools/validation/stage2-pressure-smoke.ps1 -Mode pressure`를 실행한다. 기존 작업 루프는 `-Mode yard`로 실행하며 동일 포트를 사용하므로 순차 실행한다. `-OutputFolder`로 결과 폴더를 지정할 수 있다. 임시 테스트 실행용 씬은 빌드 뒤 자동 제거한다. 빌드/테스트가 변경한 렌더 설정과 기존 문서 이미지는 원복한다.
