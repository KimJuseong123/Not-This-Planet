# NOT THIS PLANET — 알파 테스트 웹사이트

게임 소개, 트레일러·GIF 갤러리, 다운로드 안내와 플레이 후기 설문을 제공하는 정적 사이트입니다. Unity 프로젝트와 독립적이며 npm 설치나 빌드 과정이 없습니다.

## 파일 구조

- `index.html`: 유일한 HTML 진입점
- `release.css`, `gallery.css`, `feedback.css`: 스타일
- `release.js`: 갤러리·확대 화면·다운로드·설문 링크 연결
- `release-config.js`: 공개 다운로드 주소, 버전, 용량, 설문 주소
- `site.webmanifest`, `assets/`: 아이콘과 실제 사용하는 미디어 11개

## Git에서 받기 — Git LFS 필수

이미지·GIF·MP4는 저장소의 기존 Git LFS 규칙을 따릅니다. GitLab 소스 ZIP에 실제 미디어가 포함됐다고 가정하지 마세요. 배포 전 LFS 실파일을 받아야 합니다.

저장소 루트에서:

```sh
git lfs pull --include="website/assets/**" --exclude=""
```

LFS 포인터(몇 줄짜리 텍스트)만 배포하면 이미지·영상이 깨집니다. 트레일러는 약 88MB이며 실제 파일인지 확인하세요. 이 폴더에는 게임 실행 파일이 없습니다.

## 로컬 확인

저장소 루트에서 다음 명령을 실행하고 `http://127.0.0.1:8788`을 여세요.

```sh
python -m http.server 8788 --bind 127.0.0.1 --directory website
```

`index.html`을 직접 열어도 기본 화면을 확인할 수 있으나 배포 전에는 HTTP로 확인하세요.

## 다운로드·설문 링크 변경

`release-config.js`에서 다음 값을 수정합니다.

- `downloadUrl`: 비로그인으로 접근 가능한 전체 게임 ZIP 주소. 현재 미정이므로 비어 있으며 '다운로드 준비 중'을 표시합니다.
- `version`, `fileSize`: 실제 배포 버전과 ZIP 용량. 미정 값은 빈 문자열로 둡니다.
- `feedbackUrl`: 구글폼의 공개 **응답용** HTTPS 주소. 현재 알파 후기 설문이 연결되어 있습니다.

인증 토큰·비밀번호·개인용 만료 링크는 넣지 마세요. 설정 파일은 방문자에게 공개됩니다. 다운로드 ZIP에는 실행 파일뿐 아니라 데이터 폴더와 DLL도 함께 있어야 합니다. 실파일 업로드는 별도 배포 담당 작업입니다.

설문은 새 탭으로 열립니다. 설정이 없거나 유효하지 않으면 HTML의 기본 설문 링크를 사용하므로, 설문 자체를 교체할 때에는 `index.html`의 `data-feedback-link` 두 곳도 같이 변경하세요. 설문 편집 URL은 공개하지 마세요.

## 서버 배포 담당자 안내

1. LFS 실파일을 받은 뒤 **website/를 웹 루트**로 설정하거나 그 내용물을 정적 서버에 복사합니다.
2. HTML·CSS·JS·manifest·assets를 함께 배포합니다. README는 공개 파일에서 제외해도 됩니다.
3. 하위 경로 배포도 가능합니다. 모든 로컬 파일 경로는 상대 경로입니다. 디렉터리 URL은 끝에 `/`가 있어야 합니다.
4. MIME 유형을 HTML/CSS/JavaScript/PNG/GIF/MP4에 맞게 제공하고, MP4 탐색을 위해 서버의 Range 요청 지원을 확인합니다.
5. `release-config.js`는 변경이 바로 반영되도록 짧은 캐시 또는 재검증 정책을 사용하세요.
6. 비로그인 환경에서 다운로드·설문 접속을 최종 확인합니다.

이번 변경은 소스 등록과 배포 인계입니다. 서버·도메인·CI/CD 자동 배포 설정은 변경하지 않습니다. 원래 발표 사이트와 백업은 이 폴더에 포함하지 않습니다.

## 확인 항목

- 대표 이미지/트레일러/썸네일 전환, GIF 확대·닫기
- 다운로드 미설정 안내 및 설정 시 버튼 활성화
- 위·아래 설문 버튼이 같은 응답용 주소를 새 탭으로 여는지
- 모바일 화면 줄바꿈, 키보드 포커스, 이미지·영상 로딩
- 실제 ZIP 다운로드·압축 해제는 최종 다운로드 URL 확정 후 별도 확인
